# プレイヤーの見た目の差し替えガイド

プレイヤーの見た目(モデル・アニメーション)は、ゲームロジックから完全に分離されています。本番アセットが来たら、以下の手順で差し替えられます。**C#の変更は基本的に不要**です。

## 仕組み

```
CS_Player / CS_PlayerAttack / CS_PlayerSpecialAttack / CS_PlayerHealth
        │ 状態(isGrounded, isDead …)とイベント(onJumped, onStepStarted …)
        ▼
CS_PlayerVisual ── Animatorのパラメータを更新 ──▶ Animator Controller ──▶ モデル
```

- ゲームロジック側は`CS_PlayerVisual`を知らない(外してもゲームは動く)
- `CS_PlayerVisual`はAnimatorを子オブジェクトから自動で探す(`_animator`が空でも可)
- Animator Controllerに**存在しないパラメータは無視される**。全部揃っていなくてよい

## Animatorパラメータ(コードとの約束)

定義: [`CS_PlayerAnimatorParams.cs`](../Assets/Programmer/Script/Entity/Player/CS_PlayerAnimatorParams.cs)

| 名前 | 型 | 内容 |
|---|---|---|
| `Speed` | float 0〜1 | 移動の速さ(通常移動速度で割った値) |
| `MoveX` | float -1〜1 | 体から見た左右の移動(右が+) |
| `MoveZ` | float -1〜1 | 体から見た前後の移動(前が+) |
| `Grounded` | bool | 接地しているか |
| `Dead` | bool | 死亡中か |
| `Jump` | trigger | ジャンプした瞬間 |
| `Dash` | trigger | ダッシュ開始の瞬間 |
| `Attack` | trigger | 通常攻撃の各段の開始(直前に`ComboStep`がセットされる) |
| `ComboStep` | int | 何段目か(0始まり) |
| `Special` | trigger | 必殺技の開始 |
| `Hit` | trigger | HPが減った(死亡時を除く) |

## 差し替え手順

1. 新しいモデルをインポートする(Humanoidを推奨。アニメーションを使い回せる)
2. `Player.prefab`を開き、子の`Model`を新しいモデルのプレハブに入れ替える
   - 足元がカプセルの底(ローカルY = -1)に来るようにする
   - モデルに`Animator`が付いていること
3. 新しいAnimator Controllerを作り、上の表のパラメータで遷移を組む(既存の`PlayerTempAnimator.controller`を複製して、モーションだけ差し替えるのが早い)
4. `Model`の`Animator`にControllerを割り当てる
5. `CS_PlayerVisual`の`Animator`欄が新しい`Model`のAnimatorを指しているか確認(自動検索されるので空でも可)
6. `Tools/Player/仮の見た目を組み込む`は**もう実行しない**(実行すると仮アセットに戻る)。不要になったら`Assets/Editor/Player/CSED_PlayerTempVisualBuilder.cs`と`Assets/Programmer/TempAssets`ごと削除してよい

## 注意点

- **ルートモーションは使わない**(移動はRigidbodyが行う。`CS_PlayerVisual`が強制的にオフにする)
- 攻撃の長さ・判定タイミングは`CSO_AttackData`(`Duration`、`Hit Delay`)が決める。モーション側をそれに合わせる(仮Controllerは再生速度をDurationに自動調整している)。段数を増やす場合は`Attack Steps`と`ComboStep`の遷移を増やす
- 攻撃・ジャンプ・ダッシュ・必殺技の再生は「操作している本人が再生+RPCで他クライアントへ通知」。途中参加のクライアントには過去の単発動作は再生されない(死亡は状態から判定するので反映される)
- アイテム使用のモーションは未対応(`CS_PlayerItemSlot`の所持状態がサーバー側にしかないため。対応するときはスロットの同期とセットで行う)
- 新しい動作(例: しゃがみ)を足すときは、ゲームロジック側にイベントを追加し、`CS_PlayerVisual`の`ActionType`とパラメータを増やす
