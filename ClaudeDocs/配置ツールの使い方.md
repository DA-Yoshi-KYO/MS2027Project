# 📋 概要
SAObject・ハイドポイント・新しい種類のSAポイント(信号機・グラップル・動くSAポイント)と、**敵・警察・ドローン・レーザー・ライト**を、**Sceneビューをクリックして**置けるツールです。
置いた物は、Ctrl+Zで戻せます。置く物の作りは、配置ツール(`CSED_FieldMultiLayoutGenerator`)が置く物と同じです。

- 開き方: `Tools > 配置 > 配置ツールを開く`
- スクリプト: `Assets/Programmer/Script/Entity/Police/Editor/CSED_Placement*.cs`
- 参考: [SAポイントの使い方](SAポイントの使い方.md)(SAポイントの種類・動くSAポイント・グラップル) / [巡回エディタの使い方](巡回エディタの使い方.md)(悪人の巡回)

# ✅ 使い方
1. ウィンドウで、置く物(道具)を選ぶ
2. Sceneビューの、置きたい所を**左クリック**(マウスの位置に、置いた時の形が出る。青 = 置ける / 赤 = 置けない)
3. `Esc` で、取り消し・道具を外す(ふつうのSceneビューの操作に戻る)

置き方は、3種類あります。

| 置き方 | 道具 | 操作 |
| :--- | :--- | :--- |
| 1クリック | SAObject + ハイドポイント / ハイドポイントだけ / 信号機 / グラップル / 敵 | クリックした所に置く |
| 続けてクリック | 動くSAポイント / 警察のグループ / 巡回ドローン / ストリートライト | 最初のクリックで作り、クリックするたびに、点を足す。`Enter`(または`Esc`)で確定 |
| 2クリック | 防犯レーザー | 1回目が始点、2回目が終点(Escで、始点を取り消し) |

# 🧱 SAポイント
| 道具 | クリックで置かれる物 | 置けない所 |
| :--- | :--- | :--- |
| SAObject + ハイドポイント | 柱 + 頭の箱(SAObject)と、その頭の上へ飛ぶハイドポイントを、セットで置く(柱の高さは、地上 8m / 屋上 4m の自動。変えられる) | 壁(傾いた面) |
| ハイドポイントだけ | クリックした面の上に立って隠れる、ハイドポイントだけ(屋根など、すでにある物の上に置く) | 壁 |
| 信号機 | `TrafficLight`(飛ぶだけのSAポイント) | 壁 |
| グラップル | `GrapplePoint`。クリックした場所が的。引っ張られる位置は、Sceneビューのカメラ側に向く | なし |
| 動くSAポイント | 後述 | なし |

## SAできる範囲(足元の箱)
ハイドポイントの `SAReachBox` は、置いた根元から、頭の上までを含む箱が、自動で付きます(水平は、飛べる距離の22mに合わせた広さ)。
屋上に置いたSAObjectに、**下の道から**飛んで来させたい時は、ウィンドウの「SAできる範囲を下へ(m)」を大きくします(既定 0.5m。飛べる距離は22mまで)。

## グラップル
置く前に、ウィンドウで値を決めます。置いた後は、グラップルを選んで「選んでいるグラップルへ、この値を入れる」で、変えられます。

| 項目 | 内容 |
| :--- | :--- |
| `PullSpeed` | 引っ張られる速さ(m/秒) |
| `ReleaseDistanceRate` | 飛び始めの距離のこの割合まで引っ張られるか、着いたら放す(0.05〜1) |
| `ReleaseDrag` | 放した後の水平の勢いの減速率 |

## 動くSAポイント(パスに沿って自走)
1. 「動かすSAポイント」(信号機 / ハイドポイント / グラップル)と「動き方」(`Once`: 一方向 / `Loop`: 周回 / `PingPong`: 往復)を決める
2. 最初のクリックで、動くSAポイント(`CS_PathFollower` + SAポイント + 制御点の親)が作られ、最初の制御点が置かれる
3. 続けてクリックするたびに、制御点が足される(パスの曲線が緑で出る)
4. `Enter` または `Esc` で確定する(**制御点は2つ以上必要**)

制御点の待ち時間(`Wait Time`)・次の点までの速さ(`Speed To Next`)は、ウィンドウの値が、新しい制御点に入ります。
置いた後の編集(点の移動・追加・削除・プレビュー)は、`CS_PathFollower` を選んで、これまでどおり(Shift+クリックで点を追加)行います。

# 🛡️ 敵・警備
| 道具 | 置かれる物 | 置けない所 |
| :--- | :--- | :--- |
| 敵(悪人の出現点) | `VillainSpawnPoint`。区画分けの図から、置く先の犯罪完遂エリア(`CrimeArea_01〜03`)が自動で決まる | 壁 |
| 警察のグループ | `PoliceSquad`(巡回ポイントを、クリックで足す) | なし |
| 巡回ドローン | `SecurityDroneSpawner`(巡回ポイントを、クリックで足す) | なし |
| 防犯レーザー | `SecurityLaser`(始点と終点) | 壁 |
| ストリートライト | `SecurityLight`(経路の点) | 壁 |

## 敵(悪人の出現点)
- クリックした地面に、出現点を置きます。出現点は、地面から「出現点の高さ」(既定 6.2m。犯罪完遂ゲージが見えるようにするため。既存の出現点と同じ)だけ浮いて置かれます
- 置く先の犯罪完遂エリアは、区画分けの図の、区画1 → `CrimeArea_01` / 区画2 → `CrimeArea_02` / 区画3 → `CrimeArea_03` です(ウィンドウで、手動にもできる)
  - 図の向き: **図の上 = ワールドの -Z、図の右 = ワールドの -X** です(Sceneビューを、真上から、Z軸が下向き・X軸が左向きにすると、図と同じ向きに見えます。街の細かい格子が左上、大きな斜めの建物が左下に来ます)
  - 街のモデルの向きが変わったら、`CSED_FieldMultiLayoutGenerator.Sector.cs` の `ToSectorFrame` を直します
- 巡回パターン(`DB_VillainPatrol_*`)と、最初のルート(最初のポイント = クリックした地面)も、自動で作られます
- **置いた後は、既存の巡回エディタに引き継ぎます。** 続けてクリックすると、巡回ポイントが足せます(`Esc`で終了)。悪人の人数・動き方・隊列などは、巡回エディタで決めます
- 出現点は `NetworkObject` を持つため、置いた後は、MainSceneを、一度保存してください

### 悪人の分布の表示(過疎が見える)
「敵(悪人の出現点)」を選んでいる間、Sceneビューに、悪人の分布が重なって出ます(ウィンドウの「分布を色で表示」でオン・オフ)。

| 表示 | 意味 |
| :--- | :--- |
| 地面の色 | 一番近い(地上の)悪人グループの**影響範囲**までの距離。影響範囲は、「巡回ルートで測る」がオンなら、巡回ルート(巡回パターンのルートの線。パターンが無ければ、往復の線)で、オフなら、出現点からの円です(下の説明)。緑 = 足りている(半径以内) / 黄緑 / 橙 / **赤 = 過疎**(半径の1.6倍より遠い)。半径は「足りている半径」(既定 60m)で変えられる |
| 悪人の印 | 地上 = 区画の色の丸と、足りている半径の輪 / 屋上 = ひし形。出現点を、地面へ下ろした位置に出す |
| `!` と白い線 | 親の犯罪完遂エリアが、位置の区画と合わない出現点(例: 区画1の位置なのに `CrimeArea_03` の下) |
| 区画の境界線 | 区画分けの図の線(緑・赤・黄)。区画ごとの個数と、歩ける広さ1万㎡あたりの密度が出る。**平均の半分より少ない区画は「過疎」** |
| 白い輪「空き」 | 悪人から遠い場所の候補(最大5か所。50m以上離して出す) |
| 左上の文字 | 悪人の合計(地上・屋上)と、区画ごとの個数 |

- **影響範囲(巡回ルートで測る)**: 悪人グループは、出現点だけでなく、巡回ルートに沿って動きます。そこで、ウィンドウの「巡回ルートで測る」(既定はオン)がオンの間は、地面の色と「最寄りの悪人まで」を、**巡回ルート(線)からの距離**で測ります。細長いルートは、その線に沿って、細長く緑になります。ルートごとの線は、パターンの色で、Sceneビューに描かれます(周回は、最後から最初へもつなぐ)。オフにすると、出現点を中心にした円で測ります(輪も出ます)
  - 隊列の人数(付いてくる人)や、悪人の強さは、数に入れていません(ルートの線だけで測ります)
- 置く前の予告には「最寄りの悪人まで ○○m」が出ます(空きの確認に使えます)
- 屋上の悪人は、地面の色には数えません(地上の過疎だけを見ます)。区画ごとの個数・密度には数えます
- ウィンドウにも、区画ごとの個数・密度・過疎・親が合わない数の一覧が出ます

### 警察・巡回ドローンの分布の表示
「警察のグループ」「巡回ドローン」を選んでいる間も、同じ分布の表示が出ます(種類ごとに、ウィンドウの「分布を色で表示」でオン・オフ。「足りている半径」も、種類ごとです)。

| 項目 | 内容 |
| :--- | :--- |
| 影響範囲 | **巡回ルート(線)**。警察のグループは、巡回ポイントを順につないだ、周回するルート。巡回ドローンも、巡回ポイントをつないだ周回するルートです(飛んでいる高さに関わらず、水平の距離で測ります) |
| 地面の色 | 一番近い、同じ種類のルートまでの距離。緑 = 足りている(半径の半分以内) → 赤 = 過疎。「足りている半径」の既定は 50m(悪人は 60m) |
| ルートの線 | グループごとに別の色で描きます。ルートの最初の点には、区画の色の丸が付きます |
| 区画の境界線 | 区画ごとの個数と密度(歩ける広さ1万㎡あたり)。平均の半分より少ない区画は「過疎」。数える位置は、ルートの点の真ん中(重心)です |
| 白い輪「空き」 | 同じ種類のルートから、遠い場所の候補(最大5か所) |

- 置く前の予告には「最寄りの警察のグループのルートまで ○○m」(ドローンは「巡回ドローンのルートまで」)が出ます
- 警察・ドローンの分布は、それぞれ、そのグループ(種類)だけを数えます。悪人・警察・ドローンを重ねて見ることは、できません(道具を切り替えて見ます)


## 警察のグループ
- 最初のクリックでグループを作り、クリックするたびに、巡回ポイント(`RoadPatrolPoint_NNN`)を足します。周回するルートです(最後の点から最初の点へ戻る)
- ステータスは、今あるグループ(`Field_Solo1` の中の最初のグループ)から写します。人数は、ウィンドウの設定(1〜3人)で、離れて巡回します
- 巡回ポイントは、クリックした点の近く(3m以内)の、歩ける場所(NavMesh)に合わせます(設定でオフにできる)

## 巡回ドローン
- 最初のクリックでドローンを作り、クリックするたびに、巡回ポイント(`PatrolPoint_N`)を足します。周回するルートです
- 巡回ポイントは、クリックした面から、設定の高さ(既定 4m)だけ上に置きます(プレハブに入っている、仮の巡回ポイントは、消えます)

## 防犯レーザー
- 始点をクリックし、終点をクリックします。始点の位置(足元から1m上)から、終点まで往復します(上限50m)
- 置いた直後に、マウスを動かして、棒の向きを決めます(Sceneビューに、棒の線と、標準の向きからの角度が出ます)。もう1回クリックで確定します。`Shift` を押している間は15度刻み、`Esc` は標準の向き(往復する向きに直角)に戻して終えます。往復する向きは、向きを変えても変わりません
- 回す軸は、`Y`(縦軸。棒を水平に回す。標準)と `Z`(往復する向きの軸。棒を立てたり斜めにしたりする)のキー、またはウィンドウの「置いた後に回す軸」で切り替えます。`Z` の時は、マウスの位置の方向へ棒が向き、0度が水平、90度が真上です。棒の長さは、置いた時の通路の幅のままなので、立てた時は、必要に応じて長さを変えてください
- 棒は、往復する向きに直角に伸びます。長さは「長さを自動」なら、通路の左右の壁までの幅(往復する間の一番狭い所)+ 0.6m です。壁が無い所では、設定の長さを使います
- 棒の太さは、ウィンドウの「太さ(m)」で決めます(標準は0.3m。次に置くレーザーから反映されます)。当たり判定も、この太さです

## ストリートライト
- 最初のクリックでライトを作り、クリックするたびに、経路の点を足します(2つ以上)。`Enter`(または`Esc`)で確定します。ライトは、点を順につないだ線の上を動いて、床を円で照らします(曲がり角も通れます。ドローン・悪人・警察と同じ、複数経路です)
- 「最後から最初へ戻って周回」がオフなら、最後の点で折り返して往復します。オンなら、最後の点から最初の点へ戻って周回します
- 円の直径は「直径を自動」なら、全区間の道幅の一番狭い所 - 1m(8〜20m)です。測れない区間があれば、設定の直径を使います
- 経路の点は、ライトの子の `RoutePoints` の、さらに子(`RoutePoint_N`)です。後から、点を動かしたり足したりして直せます(`CS_SecurityLight` の「周回」の設定も、インスペクターで変えられます)
- 点が1つだけの時は、その場に留まります。経路が無い従来のライト(`動く向き`・`動く距離`)も、そのまま動きます

# 🗑️ 消す
- 「消す」を選んで、置いた物をクリックします
- SAObjectを消すと、同じ根元のハイドポイントも、ハイドポイントを消すと、同じ根元のSAObjectも、一緒に消えます
- 警察のグループ・巡回ドローン・悪人の出現点は、見えない(当たり判定が無い)ので、マウスの近く(画面上28ピクセル以内)の物が、赤く光って、選ばれます(巡回ポイントの近くでも選べます)
- 「消す」を選んでいる間は、見えない物を、建物の向こうでも見えるように、色分けして出します(警察のグループ = 青の点と線 / 悪人の出現点 = 橙の点と、地面までの線 / 巡回ドローン = 紫の点と線)。点は、遠くても小さくなりすぎません。選ばれる物は、赤く光ります

# 📁 置かれる場所
`Field_Solo1` の中の、次のグループに置かれます(無ければ作ります)。`Field_Solo1` が無い時は、シーンの `配置ツール` の中です。

| 置く物 | 親 |
| :--- | :--- |
| SAObject | `SAObjects` |
| ハイドポイント | `HidePoints` |
| 信号機・グラップル・動くSAポイント | `ActionObjects` |
| 敵(悪人の出現点) | `Villain/VillainSpawnPoints/CrimeArea_0N` |
| 警察のグループ | `Police`(名前は `PoliceSquad_M`。手で置いた物の目印) |
| 巡回ドローン | `SecurityDrones` |
| 防犯レーザー | `SecurityLasers` |
| ストリートライト | `SecurityLights` |

アクティブなシーン(プレハブ編集中は、そのプレハブ)の中の `Field_Solo1` が優先されます。

## プレハブへ反映
MainScene(`Field.prefab` のインスタンス)の上に置いた物は、**シーンの上書き**として残ります。他のシーンでも使うには、ウィンドウの「置いた物を `Field_Solo1.prefab` へ反映する」を押します(このツールで置いた物だけが対象です)。
反映した後は、`Field_Solo1.prefab` のコミットに入ります。

# ⚠️ 注意
- 置いた物の一覧は、スクリプトの再読み込み(コンパイル)で空になります。「プレハブへ反映」は、置いた後、コンパイルする前に押してください
- 消す道具は、プレハブから引き継いだ物(`Field.prefab` のインスタンスの、もとからある物)も消せます(シーンの「削除」の上書きになります)
- クリックした先の地面・壁は、コライダーで調べます。コライダーの無い物には、置けません
- 配置ツール(`マルチのフィールドを配置し直す`・`レーザーだけを配置する` など)を流すと、レーザー・ライト・ドローン・SAObject・ハイドポイントは、作り直しで消えます(警察・悪人は、作り直しの対象外ですが、`PoliceSquad_A` で始まる物は消えます。このツールの物は `PoliceSquad_M` なので残ります)
- 敵・警察・ドローンの数は、エリアごとの数(仕様書「フィールド」のリスク・リターン)に影響します。置いた後は `Tools/Police/エリアごとの配置の数と、何も無い場所を調べる` で、数を確かめてください
