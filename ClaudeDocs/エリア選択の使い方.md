# エリア選択の使い方(マルチの開始地点)

マルチでは、本編の前に **各プレイヤーが3つのエリアから開始地点を選びます**(Issue #342、Confluence「プレイヤー」のスポーン、「ゲームループ」の1プレイの流れ)。
ソロは今まで通りエリア選択を通らず、`Field_Solo1` の `PlayerSpawner` の子から始まります(Issue #341)。

```
RoomConnection → WaitingforaMatch(ロビー) → AreaSelect(エリア選択) → MainScene(本編) → ResultScene
                                              │
                                              └ 決まったエリアを CS_SpawnAreaStore に入れて持ち越す
                                                 → MainScene の CS_PlayerSpawner が読んで、そのエリアの開始地点から生成する
```

---

## 決まり事(仮)

| 項目 | 今の決まり | 変える場所 |
| --- | --- | --- |
| 選べる時間 | 15秒 | `CS_AreaSelectController` の `Select Seconds` |
| 同じエリアを選べる人数 | 何人でも | - |
| 本編へ移るタイミング | 接続中の全員が選んだ時、または時間切れの時 | - |
| 選ばなかった人のエリア | ランダム | - |
| NPCのエリア | ランダム(生成する時に `CS_PlayerSpawner` が決める) | - |
| 選び直し | 締め切りまで何度でもできる | - |

---

## スクリプト

| クラス | 役割 | 場所 |
| --- | --- | --- |
| `CS_AreaSelectController` | 選択をサーバーで集め、締め切ったら本編へ移る。NetworkBehaviour | `Script/NetWork/` |
| `CS_UIAreaSelectModel` / `Presenter` / `View` | エリア選択の画面(MVP)。Controller は Model に書くだけ | `Script/UI/MVP(〜)/UI_AreaSelect/` |
| `CS_SpawnAreaStore` | 決まったエリアをシーンをまたいで持つ(static。`CS_GameModeStore` と同じ形) | `Script/GameController/` |
| `CS_PlayerSpawner` | `Area Spawn Roots` が設定されていれば、選んだエリアの開始地点から生成する(選んでいない人・NPCはランダムなエリア) | `Script/Entity/Player/` |

- 選択はクライアントからサーバーへ RPC で送り、エリアごとの人数と締め切りの時刻を NetworkList / NetworkVariable で全員へ同期します
- MainScene を直接再生した時はソロで始まり、`Field_Solo1` の `PlayerSpawner` の子から生成します(`CS_GameModeStore` の初期値がソロのため)
- マルチの確認は `MultiplayerDebugBoot` から始めます。エリア選択を通らないので `CS_SpawnAreaStore` は空になり、全員ランダムなエリアから生成します
- AreaSelect シーンを直接再生した時(オフライン)は、選んだらすぐ MainScene へ移ります

## 開始地点の置き場所

```
Field_Multi
 ├ PlayerSpawner        (CS_PlayerSpawner。子は無い。開始地点は下の Area を使う)
 └ AreaSpawnPoints
    ├ Area0  (中央から +Z 方向に100m)   └ SpawnPoint_0〜3
    ├ Area1  (中央から右回りに120°)     └ SpawnPoint_0〜3
    └ Area2  (中央から右回りに240°)     └ SpawnPoint_0〜3
```

- `PlayerSpawner` の `Area Spawn Roots` に `Area0〜2` を順番に入れてあります(配列の番号 = エリアの番号 = 画面のボタンの番号)
- 同じエリアを選んだ人は、`SpawnPoint_0` から順に使います(子の数を超えたら最初に戻る)
- **フィールドがまだ3エリアに分かれていないので、位置は仮です。** 各エリアの場所が決まったら `Area0〜2` を動かしてください
- `Area` の向きは中央を向けてあり、プレイヤーは開始地点の向きで生成されます

## AreaSelect シーンの作り方

1. `Assets/Programmer/Scene/InGame/NetWork/` に `AreaSelect.unity` を作る
2. 空の GameObject `AreaSelectController` を作り、以下を付ける
   - `NetworkObject`
   - `CS_AreaSelectController`
   - `CS_SceneTransitioner`(`Next Scene Name` は `MainScene`)
3. Canvas の下に画面を作り、ルートに `CS_UIAreaSelectView` と `CS_UIAreaSelectPresenter` を付ける
   - `Area Buttons`: エリアのボタン3つ(エリア0〜2の順。ボタンの文字にエリアの名前を書く)
   - `Area Count Texts`: エリアごとの人数を出す TMP_Text 3つ(同じ順)
   - `Selected Marks`: 自分が選んだエリアの目印(同じ順。無ければ空でよい)
   - `Remaining Time Text`: 残り秒数を出す TMP_Text
4. `CS_AreaSelectController` の `Scene Transitioner` と `View` に、2 と 3 で作った物を入れる
5. EventSystem を置く(ボタンを押すため)
6. `File > Build Profiles`(Build Settings)のシーン一覧に `AreaSelect` を追加する
7. `WaitingforaMatch` の開始ボタンの遷移先(`CS_SceneTransitioner` の `Next Scene Name`)を `MainScene` から `AreaSelect` に変える
