# 📋 概要
プランナー向けの、プレイヤーのレベルデザイン用ウィンドウです。プログラマーに頼まなくても、次のものを調整できます。

- 4キャラ(ギロ・アブ・キース・イシュ)それぞれの基礎数値・必殺技・必殺技を使った後の効果
- 全キャラ共通の数値(必殺ゲージ・スキャン(自動スキャンを含む)・ブリンク・奇襲・SA・無敵時間など)
- 通常攻撃(5段コンボ)の各段

開き方：メニューの `Tools > プレイヤー調整`
スクリプト：`Assets/Programmer/Script/Entity/Player/Editor/CSED_PlayerTuningWindow.cs`

> 再生しながら「編集前／編集後」を選んで保存したい時は、別のツール `Tools > レベルデザイン`([レベルデザインツールの使い方](レベルデザインツールの使い方.md))を使ってください。
> 2つのツールは同じ共通のデータ(`DB_PlayerStats`・`DB_PlayerSpecial`)を編集するので、どちらで変えても結果はそろいます。

# ✅ 使い方
## キャラクタータブ
- 左の一覧でキャラクターを選ぶと、右にそのキャラクターの設定が出ます
- 一覧の左の ○ は「テストで使うキャラクター」です。キャラクター選択の画面ができるまでは、再生すると**全員がこのキャラクター**になります
- 下の「キャラクターの比較」で、全キャラクターの主な数値を並べて見られます

| 項目 | 内容 |
| :--- | :--- |
| 表示名・アイコン・キャラクターの色 | UIで使う予定のもの(アイコンは未設定でもよい) |
| 基礎数値 | 最大HP・攻撃力・移動速度・ジャンプ力・ブリンクの速さ・スプリントの速さ・必殺ゲージの最大・必殺技の威力 |
| 必殺技の攻撃 | ダメージ・当たるまでの時間・モーションの長さ・判定の大きさ・カメラの揺れ |
| 使った後の効果 | 必殺技が当たった瞬間から、効果時間のあいだ続く効果(下の表) |

### 共通のデータと「このキャラ専用にする」
- 最初は、4キャラとも**共通の基礎数値・必殺技の攻撃**を使っています(青い説明が出ます)。ここで数値を変えると、共通を使っている全キャラクターに反映されます
- キャラクターごとに数値を変えたい時は「**このキャラ専用にする**」を押してください。共通のデータをコピーして、そのキャラクター専用にします
- 黄色の警告「○人のキャラクターで使っています」が出た時も、同じボタンで専用にできます

### 必殺技を使った後の効果
| 効果 | 内容 | 仕様書のキャラ |
| :--- | :--- | :--- |
| 正面から奇襲 | 奇襲の「背後か上」の条件を見ない(気づかれていない・距離の条件は残る) | ギロ |
| 身体能力の強化 | 移動速度・スプリント速度・ジャンプ力・攻撃力・コンボの速さに「強化の倍率」を掛ける(暗躍ボーナスとも掛け合わせる) | アブ |
| 全員が見える | 全ての悪人グループ・警察・巡回ドローンが、スキャンと同じ表示で見え続ける(使った本人の画面のみ) | キース |
| 警察に見つからない | 警察の視界に入っても見つからない | イシュ |
| なし | 必殺技の攻撃だけ | - |

### キャラクターを増やす・外す
- 「複製」: 選んでいるキャラクターを、専用の基礎数値・必殺技ごとコピーして一覧に足します
- 「一覧から外す」: 一覧から外すだけで、データ(ファイル)は消えません

## 共通の数値タブ
全キャラクター共通の数値です(`Player.prefab` に保存されます)。項目にマウスを乗せると説明が出ます。

| 区切り | 主な項目 |
| :--- | :--- |
| 必殺ゲージ | 毎秒溜まる量・悪人を倒した時に溜まる量(満タンまでの時間も表示) |
| スキャン | 範囲・見え続ける時間・**自動スキャン**(オン/オフ・間隔・開始時にスキャン・手動で使ったら数え直す) |
| ブリンク | ブリンクの時間・クールタイム(ブリンクの距離も表示) |
| ブリンクの反撃(パリー) | 受付時間・反撃のダメージ・スタンの時間など |
| 奇襲 | 奇襲できる距離・背後の角度・上の高さ・飛び込む速さ・巻き込む範囲など |
| SA | 飛ぶ速さ・見えている割合・隠れていても見つかる距離 |
| 被弾・復活 | 被弾後の無敵・復活までの時間・復活後の無敵 |
| スタンのコマンド入力 | 1周で短くなる秒数 |
| 暗躍ボーナス | ボーナスが付く人数・1段階ごとの倍率 |
| 攻撃の補正 | エイムアシストの距離・角度・踏み込む距離 |

### 自動スキャン
- 仕様書「スキャン」の試してみたいこと(ゲーム開始時含め20秒ごとに自動でスキャン)です。最初はオンで20秒にしています
- 手動でもいつも通り使えます(波が出ている間は使えないのも同じ)
- 「手動で使ったら数え直す」がオンだと、手動で使った時も次の自動スキャンまでの時間が最初からになります(続けて2回出ないように)

## 通常攻撃タブ
5段コンボの各段のダメージ・時間・判定の大きさ・溜まるゲージ・カメラの揺れを変えられます。全キャラクター共通です。

# ⚠️ 注意
- 値はCtrl+Zで戻せます。保存はCtrl+S、またはウィンドウ右上の「保存」
- **再生中に変えた値もそのまま保存されます**。基礎数値・キャラクターは、次に再生した時(スポーンした時)から反映されます
- 項目に「見つかりません。プログラマーに連絡してください」と出た時は、スクリプトの項目名が変わっています。プログラマー(秋野)に連絡してください
- キャラクター選択の画面はまだありません。作る時は `CS_PlayerCharacter.SetCharacterIndex`(サーバー)で番号を決めます
