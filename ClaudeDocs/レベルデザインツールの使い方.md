# 📋 概要
レベルデザイン(数値調整)用のレイアウトとステータス調整ウィンドウです。
再生しながらプレイヤー・悪人・警察の値を変えて試し、再生を止めた時に「編集前／編集後」のどちらを保存するか選べます。

- 開き方：`Tools > レベルデザイン > ソロ用` / `マルチ用`
- スクリプト：`Assets/Editor/LevelDesign/`

| レイアウト | 並び |
| :--- | :--- |
| ソロ用 | Gameビュー(左) ＋ ステータス調整(右)。操作キャラ1人分を表示 |
| マルチ用 | Gameビュー ＋ Play Mode Status ＋ ステータス調整(右)。P1〜P4を4分割で表示 |

# ✅ 最初に1回だけ：レイアウトの登録
レイアウトファイル(`Assets/Editor/LevelDesign/Layouts/LD_Solo.wlt` / `LD_Multi.wlt`)がまだ無い時は、メニューを押すと必要なウィンドウだけ開きます。
1. ウィンドウを上の表のとおりにドラッグして並べる
2. `Tools > レベルデザイン > 今の配置を保存 > ソロ用`(またはマルチ用)を押す
3. できた `.wlt` ファイルをコミットする(以降は全員がメニューから同じレイアウトを開けます)

# ✅ 使い方
## タブ
| タブ | 調整するもの |
| :--- | :--- |
| プレイヤー | 再生中のキャラの値(HP上限、攻撃力、移動速度など)。再生中だけ編集できる |
| 悪人 | `DB_VillainStatsA/B`、`DB_VillainTimeScaling` |
| 警察 | `DB_PoliceA/B`、`DB_PoliceWantedLevel` |

- 編集した項目は太字、データは「(編集中)」と表示されます。項目にマウスを乗せると編集前の値が見えます
- 「初期状態に戻す」で編集前の値に戻ります(プレイヤーはウィンドウに最初に表示した時、データは再生開始時の値)
- マルチではホスト(メインエディタ)から4人全員の値を変えられます。2〜4人目の画面はMultiplayer Play Modeの各ウィンドウで見てください
- 悪人・警察の値は全プレイヤー共通です

## 再生を止めた時
値を変えていた場合、「調整値の保存」ウィンドウが出ます。
- 項目ごとに「編集前」か「編集後」を選びます(マルチのプレイヤーの値は P1〜P4 のどれを保存するか選びます)
- プレイヤーの値は `DB_PlayerStats` に保存されます
- **すべての項目を選んで「決定」するまで、ウィンドウは閉じられず、次のPlayもできません**
- 保存した値はいつも通りコミットしてください

# ⚠️ 注意
- 再生していない時に悪人・警察タブで変えた値は、Inspectorで変えた時と同じくそのまま残ります(保存選択は出ません)
- ステータス調整ウィンドウを閉じた状態で再生した場合は、保存選択の対象になりません
