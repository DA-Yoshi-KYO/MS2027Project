# ソロの調整の仕方（DBとフィールド）

ソロは **マルチと同じ MainScene を通信なしで遊ぶ** 作りです。
フィールドは、共通の部分(`Field_Common`)と、遊び方ごとの部分(マルチ用 `Field_Multi`・ソロ用 `Field_Solo1`)に分けて、
それを切り替え役ごと1つのプレハブ `Field` にまとめています。MainScene には `Field` を1つ置くだけです。
プレハブはどれも `Assets/Programmer/Prefab/Field/` にあります。

```
MainScene
 └ Field (Field.prefab)
    ├ GameModeSwitcher
    ├ Field_Common  (建物・道路・NavMesh・路地裏。共通)
    ├ Field_Multi   (マルチ用: 開始位置 / Villain(出現点も) / Police / Item / Event)
    └ Field_Solo1   (ソロ用:   開始位置 / Villain(出現点も) / Police / Item / Area。普段は非表示)
```

ソロを増やす(Solo2など)時は、`Field.prefab` の中に足すだけで、シーンは触らずに済みます。

```
RoomConnection で「Solo」を押す
  → CS_GameModeStore に Solo を入れて、通信せずに MainScene を読み込む
  → Field の中の GameModeSwitcher(CS_GameModeSwitcher)が
       ・Multi Only Objects(Field_Multi)を無効にする
       ・Solo Objects(MainScene に置いた Field_Solo1)を有効にする
  (マルチの時は逆に Field_Solo1 を無効にする)
  → ランキングUIの Score は、付いている CS_HideInSolo が自分で無効にする
```

**ソロだけを調整したい時は、`_Solo` が付いたDBと `Field_Solo1` だけを触ってください。**
元のDB・`Field_Multi` を触るとマルチが変わります。`Field_Common`(建物・道路)を触ると両方が変わります。

## 触る場所の早見表

| 変えたいもの | 触る場所 | 種類 |
| --- | --- | --- |
| 悪人の人数・HP・犯罪完遂時間の時間変化 | `Database/Villain/DB_VillainTimeScaling_Solo` | DB |
| 悪人の基本の強さ(HP・移動速度・攻撃力・臨戦範囲・犯罪完遂時間) | `Database/Villain/DB_VillainStatsA_Solo` | DB |
| 悪人の攻撃(ダメージ・判定の大きさ・タイミング) | `Database/Attack/DB_VillainAttack_Solo` | DB |
| 巡回警察・増援の強さ(速度・視野角・視野距離) | `Database/Police/DB_PoliceA_Solo` | DB |
| 手配度ごとの増援の人数・速さ・視野・攻撃の溜め | `Database/Police/DB_PoliceWantedLevel_Solo` | DB |
| 悪人グループの数・追加の間隔・同時に攻撃する人数 | `Field_Solo1` > `Villain` > `VillainSpawner` | Inspector |
| 増援が湧く距離・確認の間隔 | `Field_Solo1` > `Police` > `PoliceWantedManager` | Inspector |
| アイテムの最初の数・出る種類・再出現の間隔 | `Field_Solo1` > `Item` > `ItemManager` | Inspector |
| 悪人の出現位置 | `Field_Solo1` > `Villain` > `VillainSpawnPoints` の子 | 配置 |
| アイテムの生成位置 | `Field_Solo1` > `Item` > `ItemSpawnPoints` の子 | 配置 |
| 巡回警察の部隊・巡回ルート・警備範囲 | `Field_Solo1` > `Police` > `PoliceSquad_1〜4` | 配置 |
| 遊べる範囲 | `Field_Solo1` > `Area` > `PlayArea` | 配置 |
| プレイヤーの開始位置 | `Field_Solo1` > `PlayerSpawner` の子(1つ目を使う) | 配置 |

パスは `Assets/Programmer/` から。`Field_Solo1` は `Field.prefab` の中のプレハブ(`Assets/Programmer/Prefab/Field/Field_Solo1.prefab`)です。

### Field_Solo1 の直し方

1. `Field.prefab` をダブルクリックしてプレハブモードで開き、`Field_Solo1` を選んで Inspector 左上のチェックを入れて表示する
   → フィールドと重なって見えるので、Scene ビューで出現点や範囲を直接動かせます
2. 直し終わったら、`Field_Solo1` の `Overrides` から `Apply All` して、`Field_Solo1.prefab` に保存する
3. チェックを外して非表示に戻し、`Field.prefab` を保存する

非表示に戻し忘れても、マルチで再生すると最初に非表示になるので、マルチの動きは変わりません。
MainScene は触らないので、シーンの変更は出ません(出現点など、NetworkObjectの付いた物を足した時だけ、MainScene を開いて一度保存してください)。

`DB_VillainStatsB_Solo` / `DB_VillainStatsBoss_Solo` / `DB_VillainBossAttack_Solo` も作ってありますが、
今のソロでは使われていません(B型の悪人とボスはソロで出ないため)。

## DBの調整

### 悪人

- **時間変化** `DB_VillainTimeScaling_Solo`
  経過時間ごとの段階(Stage)のリストです。段階ごとに「始まる時間(秒)」「1グループの人数」「HP上限」「犯罪完遂までの時間」「攻撃力」を決めます。
  HP・完遂時間・攻撃力は **0以下なら下の基本の値のまま** になります。
- **基本の強さ** `DB_VillainStatsA_Solo`
  最大HP、移動速度(プレイヤーの通常移動を1とした倍率)、攻撃力、臨戦態勢になる範囲(m)、犯罪完遂までの時間(秒)。
- **攻撃** `DB_VillainAttack_Solo`
  ダメージ、攻撃開始から判定が出るまでの時間、モーションの長さ、判定の位置と半径。

ソロの悪人は `Prefab/Entity/Villain/Villain_Solo.prefab`(`Villain.prefab` のプレハブバリアント)です。
能力値と攻撃のDBだけをソロ用に上書きしています。**見た目やコンポーネントを変える時は元の `Villain.prefab` を変えれば、ソロにも反映されます。**

### 警察

- **巡回・増援の強さ** `DB_PoliceA_Solo`
  巡回速度倍率、追跡速度倍率、視野角度、視野距離。攻撃力はプレイヤーを一撃で倒す前提の値なので、基本は触りません。
  巡回警察の4部隊と、手配度の増援の両方がこれを使います。
- **手配度ごとの増援** `DB_PoliceWantedLevel_Solo`
  手配度ごとの段階のリストです(0番目が手配度1)。「増援の人数(プレイヤー1人あたり)」「追跡速度倍率(上のDBにさらに掛ける)」「視野距離(上のDBの代わりに使う)」「攻撃の溜め時間」を決めます。
  **ソロで「見つかった時のリスクを重くする」なら、まずここの人数・速さ・視野を上げるのが手軽です。**

### DBになっていない値(Inspectorで直接変える)

- `Field_Solo1` > `Villain` > `VillainSpawner`(`CS_VillainSpawner`)
  - `Extra Group Count`: プレイヤーの数に加えて、常にいるグループの数(ソロはプレイヤー1人として数えます)
  - `Spawn Interval` / `Max Group Count`: 時間でグループを足す間隔と上限
  - `Max Attackers Per Group`: 同時に攻撃してくる人数
  - `Respawn Cooldown`: 全滅・完遂した場所に次を出さない時間
- `Field_Solo1` > `Item` > `ItemManager`(`CS_ItemGenerator`)
  - `Init Generate Num`: フィールドに置いておくアイテムの数
  - `Init Generate Item Kinds`: 出るアイテムの候補。**ソロで出さないアイテムはここから外します**
  - `Respawn Interval`: 拾われた後に補充する間隔(0なら補充しない)
- 見つかった時の減点(`_foundByPolicePenalty` = 50)は `Player.prefab` の `CS_PlayerScoring` にあり、マルチと共通です。ソロだけ変えるにはコードの変更が必要です。

## フィールド(配置)の調整

### 遊べる範囲

`Field_Solo1` > `Area` > `PlayArea` の BoxCollider(Is Trigger)の大きさが、ソロで遊べる範囲です。
今は仮でフィールド全体(中心 (0,25,0)、大きさ 260×60×260)になっています。

- 範囲は **水平方向(XとZ)だけ** で判定します。高さは見ません。
- 範囲の外には **手配度の増援が湧かなくなります**。
- 範囲は **プレイヤーを閉じ込めません**。閉じ込めるには、範囲の縁に見えない壁(BoxCollider付きの空オブジェクト)を `Field_Solo1` > `Area` の中に置いてください。
  - 壁がNavMeshの外側にあると警察や悪人が抜けることがあるので、壁に `NavMeshObstacle`(Carve)を付けておくと安全です。

### 出現位置・生成位置・巡回ルート

範囲を狭めたら、範囲の外にある物をソロで使わないようにしてください。

次の物は **`Field_Solo1` の中から消すか、範囲内へ動かしてください**。

- 悪人の出現点 `Villain` > `VillainSpawnPoints` の子(`VillainSpawnPoint_01〜29`)
- アイテムの生成点 `Item` > `ItemSpawnPoints` の子(タグ `ItemGeneratePoint`)
- 巡回警察 `Police` > `PoliceSquad_1〜4` の巡回ポイント(`RoadPatrolPoint_xxx`)と `GuardArea`

足りなければ、既存の点を複製して範囲内に置けば増やせます。
`Field_Multi` 側の点は、ソロでは無効になるので気にしなくて大丈夫です。

## 確認のしかた

1. `RoomConnection` シーンから Play し、`Solo` を押す
2. MainScene がソロで始まり、悪人が `Villain_Solo(Clone)` として出ていることを Hierarchy で確認
3. 調整した値が効いているかを遊んで確認

MainScene を直接 Play した時はマルチ扱い(通信なしのテスト)になり、`Field_Solo1` は無効になります。**ソロの確認は必ず RoomConnection から** 始めてください。

## ツールとの関係

- **レベルデザインツール**: 悪人・警察のタブには `_Solo` のDBも出てきます(型で探しているため)。名前で見分けてください。
  ただし悪人の攻撃は名前(`DB_VillainAttack`)で探しているので、`DB_VillainAttack_Solo` はツールに出てきません。Inspectorで直接変えてください。
- **仕様データ同期ツール**: Confluenceから書き込む先は `SpecSyncMapping.json` に決まっていて、マルチのDBだけです。`_Solo` には同期されません。

## 注意

- ソロではランキング(UICanvas の `Score`)を消しているので、自分のスコアも画面に出ません。
- ソロではNPC・ランダムイベントは出ません。
- マルチ専用の物を新しく足す時は、`Field_Multi` の中に置いてください(ソロでは自動で無効になります)。
- シーンのUIなど、`Field` の外にあってソロで消したい物には `CS_HideInSolo` を付けてください。
- 悪人の出現点は、路地裏(`BackAlley.prefab`)とは別に、`Field_Multi` と `Field_Solo1` の `Villain` > `VillainSpawnPoints` に直接置いています。
  スポナーは、有効になっている出現点を全部使います。
  **路地裏を足したり動かしたりした時は、両方のプレハブの出現点も足す・動かす必要があります。**
  出現点を路地裏の中に置けば、見張り役はその路地裏を巡回します(真上から見て出現点を含む路地裏を自動で探します)。
- 出現点(`VillainSpawnPoint.prefab`)を新しく置いたら、MainScene を開いて一度保存してください(NetworkObjectのシーン配置の値が入ります)。
