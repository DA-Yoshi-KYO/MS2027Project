# スコアの使い方（プレイヤー製作者向け）

プレイヤーのスコアを持ち、リザルトまで届ける方法です。
プレイヤー側でやることは次の2つだけです。

1. スコアを持つ（`CS_ResultData` を作り、`NetworkVariable` で同期する）
2. ゲーム終了時に、タイマーから全員分の `CS_ResultData` を取り出せるようにする

```
サーバー：点数を加算 ──▶ NetworkVariable<Score> ──(同期)──▶ 各クライアント
各クライアント：OnValueChanged ──▶ CS_ResultData.SetScore
ゲーム終了：CS_TimerController ──▶ CS_ResultDataStore.Save(全員の CS_ResultData) ──▶ ResultScene
```

> ※ PR 176（`元浪梨緒/スコアとリザルトの修正`）の内容が前提です。マージ前は develop にクラスがありません。

## 使うクラス

| クラス | 役割 | プレイヤー側がやること |
|---|---|---|
| `CS_ResultData` | プレイヤー1人分のリザルトデータ | 番号と一緒に `new` して持つ。同期された値を `SetScore` で入れる |
| `CS_ResultData.Score` | 同期する struct（4項目の **点数** と **回数**） | `NetworkVariable<CS_ResultData.Score>` にして、サーバーが書き込む |
| `CS_ResultDataStore` | シーンをまたいでデータを運ぶ | 触らなくてOK（タイマーが `Save` する） |

### Score の中身

| 項目 | 点数 | 回数 |
|---|---|---|
| 悪人撃破 | `defeatVillainScore`（＋） | `defeatVillainCount` |
| 警察に発見 | `foundByPoliceScore`（−） | `foundByPoliceCount` |
| 犯罪完遂 | `crimeCompletedScore`（−） | `crimeCompletedCount` |
| 他プレイヤー撃破 | `defeatPlayerScore`（＋） | `defeatPlayerCount` |

- **点数はプレイヤー側で計算して、加算済みの値を入れます。** 1回あたり何点か（暗躍ボーナス・悪人の種類による差も含む）はデータ表に合わせてください。`CS_ResultData` に点数の定数はありません。
- 回数はリザルトの内訳表示（「倒した悪人 : 5人 (+500点)」）に使われます。
- 合計点は `CS_ResultData.totalScore` で取れます（4つの点数の合計。0未満にはなりません）。

## コード例

プレイヤーのプレハブに付けるコンポーネントにする想定です。
タイマー側の TODO コメントが `CS_PlayerResultDataHolder` の `resultData` を読む形で書かれているので、名前はそれに合わせています。

```csharp
using Unity.Netcode;
using UnityEngine;

/// <summary>
/// プレイヤーのスコアを持ち、リザルトに渡す
/// ・点数を変えるのはサーバーだけ（NetworkVariable で全員に同期）
/// ・各クライアントは届いた値を CS_ResultData に入れる
/// </summary>
[RequireComponent(typeof(CS_Player))]
public class CS_PlayerResultDataHolder : NetworkBehaviour
{
    // 同期する点数と回数（書き込みはサーバーだけ）
    private readonly NetworkVariable<CS_ResultData.Score> _score = new NetworkVariable<CS_ResultData.Score>(
        default,
        NetworkVariableReadPermission.Everyone,
        NetworkVariableWritePermission.Server
    );

    private CS_Player _player;
    private CS_ResultData _resultData;

    // タイマーがゲーム終了時に読む
    public CS_ResultData resultData => _resultData;

    private void Awake()
    {
        _player = GetComponent<CS_Player>();
    }

    public override void OnNetworkSpawn()
    {
        // playerNumber は Spawn 後でないと確定しないので、ここで作る
        _resultData = new CS_ResultData(_player.playerNumber);

        // 途中で Spawn したクライアントも 0 から始まらないよう、同期済みの値を最初に入れる
        _resultData.SetScore(_score.Value);

        _score.OnValueChanged += HandleScoreChanged;
    }

    public override void OnNetworkDespawn()
    {
        _score.OnValueChanged -= HandleScoreChanged;
    }

    // 値が届いたら CS_ResultData に入れる
    private void HandleScoreChanged(CS_ResultData.Score previous, CS_ResultData.Score current)
    {
        _resultData.SetScore(current);
    }

    // ---- 加算（サーバーで呼ぶ）----

    /// <summary>悪人を倒したとき。point はボーナス込みの点数</summary>
    public void AddDefeatVillain(int point)
    {
        if (!IsServer) return;

        // struct は「取り出す → 変える → 入れ直す」でないと同期されない
        var s = _score.Value;
        _score.Value = new CS_ResultData.Score(
            s.defeatVillainScore + point, s.foundByPoliceScore, s.crimeCompletedScore, s.defeatPlayerScore,
            s.defeatVillainCount + 1,     s.foundByPoliceCount, s.crimeCompletedCount, s.defeatPlayerCount);
    }

    // AddFoundByPolice / AddCrimeCompleted / AddDefeatPlayer も同じ形で書く
}
```

> オフライン（NetworkManager が動いていないテストシーン）でも動かしたい場合は、`CS_PlayerHpUI` と同じように `Start` で初期化してください。

## 注意

### 同期まわり
- **書き込めるのはサーバーだけ** です。クライアントで攻撃が当たった場合などは、サーバー側の処理（または ServerRpc）から加算メソッドを呼んでください。
- `Score` のプロパティは読み取り専用です。`_score.Value.defeatVillainCount++` のような書き方はできないので、コード例のように **新しい `Score` を作って `_score.Value` に入れ直して** ください。
- 同期されるのは `Score`（点数と回数）だけです。`CS_ResultData` 自体と称号（`title`）は同期されません。称号はリザルト側で決めます。

### ゲーム終了時の受け渡し
- `CS_TimerController` の時間切れ処理に、全プレイヤーの `resultData` を集めて `CS_ResultDataStore.Save(...)` する TODO があります。
  **プレイヤー側ができたら、ここを有効にしてください**（全プレイヤーの一覧の取り方はプレイヤー側の作りに合わせる）。
- `Score` は全クライアントに同期済みなので、**各クライアントが自分の手元のプレイヤー全員分を集めれば足ります**（RPC は不要）。
- 保存は **シーンを移動する前**（プレイヤーが消える前）に行う必要があります。

## 追記：シーン移動のネットワーク同期（ネットワーク担当として判断をお願いします）

### 今の状態
- 時間切れの判定は **サーバーだけ** が行い、サーバーだけが `CS_SceneTransitioner.StartTransition()` を呼びます。
- `CS_SceneTransitioner` は `SceneManager.LoadScene` で **その端末だけ** を移動させるため、**クライアントは MainScene に残ったまま** になります。
- また、通信を続けたまま ResultScene に移動しているので、NetworkManager や Spawn 済みのオブジェクトがどうなるかも決まっていません。

### 決めてほしいこと（どちらか）

| 案 | 内容 | ResultDataStore への保存 |
|---|---|---|
| A | ホストが `NetworkManager.SceneManager.LoadScene` で全員をまとめて移動させる | 全員がシーン移動の前に保存する必要がある（ClientRpc で「保存して」を送る、またはシーン切り替えのイベントで保存するなど） |
| B | ホストが全員に終了を通知 → 各自が保存してから通信を終了（`Shutdown`）→ 各自で移動 | 各自が `Shutdown` の前に保存する |

- どちらの案でも、**移動を始める前に `CS_ResultDataStore.Save(...)` しておく** ことは変わりません（移動するとプレイヤーが消えるため）。
- リザルトの後にロビーやタイトルに戻るとき、通信をどう扱うかとも関係するので、あわせて考えてください。
- 決まったら、`CS_TimerController` の時間切れ処理（TODO の部分）と `CS_SceneTransitioner` をその方針に合わせて直します。

## API 早見表

| メソッド / プロパティ | 説明 |
|---|---|
| `new CS_ResultData(playerNumber)` | 1人分のリザルトデータを作る |
| `CS_ResultData.SetScore(score)` | 同期された `Score` を入れる |
| `CS_ResultData.totalScore` | 合計点（0未満にならない） |
| `CS_ResultData.score` | 今の `Score`（点数と回数） |
| `new CS_ResultData.Score(点数×4, 回数×4)` | `Score` を作る（悪人撃破・警察発見・犯罪完遂・他P撃破の順） |
