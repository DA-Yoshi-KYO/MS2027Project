# 📋 概要
レベルデザイン(数値調整)用のレイアウトとステータス調整ウィンドウです。
再生しながらプレイヤー・悪人・警察の値を変えて試し、再生を止めた時に「編集前／編集後」のどちらを保存するか選べます。

- 開き方：`Tools > レベルデザイン > 開く`
- 終わり方：ステータス調整ウィンドウ上部の「調整を終了」(確認で「はい」を押すと、開く前のレイアウトに戻ります)
- スクリプト：`Assets/Editor/LevelDesign/`
- レイアウト：Gameビュー(左) ＋ ステータス調整(右)。操作キャラ1人分を表示

# ✅ 最初に1回だけ：レイアウトの登録
レイアウトファイル(`Assets/Editor/LevelDesign/Layouts/LD_Layout.wlt`)がまだ無い時は、メニューを押すと必要なウィンドウだけ開きます。
1. ウィンドウを上のとおりにドラッグして並べる
2. `Tools > レベルデザイン > 今の配置を保存` を押す
3. できた `.wlt` ファイルをコミットする(以降は全員がメニューから同じレイアウトを開けます)

# ✅ 使い方
## タブ
| タブ | 調整するもの |
| :--- | :--- |
| プレイヤー | ステータス(HP上限、攻撃力、移動速度など。再生中は操作キャラの値、再生していない時は `DB_PlayerStats`)と、攻撃のデータ `DB_PlayerAttack1〜3`、`DB_PlayerSpecial` |
| 悪人 | `DB_VillainStatsA/B`、`DB_VillainTimeScaling`、`DB_VillainAttack` |
| 警察 | `DB_PoliceA/B`、`DB_PoliceWantedLevel` |

- 項目名と単位はConfluence(データ表ページ)にそろえています。名前は仕様データ同期ツールの対応表 `Assets/Editor/SpecSync/SpecSyncMapping.json` の列名を使い、移動速度(5倍)や時間(分⇔秒)はConfluenceの数字で表示・入力して、データには換算して入ります。Confluenceに無い項目(攻撃データ、ダッシュ継続速度など)は `CSED_LevelDesignLabels.cs` の日本語名です
- 編集した項目は太字、データは「(編集中)」と表示されます。項目にマウスを乗せると編集前の値が見えます
- 「初期状態に戻す」でデータごと、各項目の「戻す」でその項目だけ、編集前の値に戻ります(プレイヤーはウィンドウに最初に表示した時、データは再生開始時の値)
- 悪人・警察の値は全プレイヤー共通です

## 再生を止めた時
値を変えていた場合、「調整値の保存」ウィンドウが出ます。
- 項目ごとに「編集前」か「編集後」を選びます
- プレイヤーの値は `DB_PlayerStats` に保存されます
- **すべての項目を選んで「決定」するまで、ウィンドウは閉じられず、次のPlayもできません**
- 保存した値はいつも通りコミットしてください

# ⚠️ 注意
- 再生していない時に悪人・警察タブで変えた値は、Inspectorで変えた時と同じくそのまま残ります(保存選択は出ません)
- ステータス調整ウィンドウを閉じた状態で再生した場合は、保存選択の対象になりません
