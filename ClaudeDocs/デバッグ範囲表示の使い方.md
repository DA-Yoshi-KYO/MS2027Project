# 📋 概要
警察・悪人・プレイヤー・防犯装置(巡回ドローン)の視界や攻撃判定を、Game画面に線で表示するデバッグ機能です。
表示する要素を、ウィンドウでタブごとにまとめて切り替えられます。

- 開き方：`Tools > DebugRangeDrawer`
- スクリプト：`Assets/Programmer/Script/Debug/CS_DebugRangeDrawer.cs`(表示)、`Assets/Programmer/Script/Debug/Editor/CSED_DebugRangeWindow.cs`(ウィンドウ)

# ✅ 準備
1. シーンに空のオブジェクトを置き、`CS_DebugRangeDrawer` を付ける
2. `Line Material` に `MT_DebugRange` を割り当てる

# ✅ 使い方
## 表示全体のON/OFF
- 再生中に `F3`(Inspectorの `Toggle Key` で変更可)で切り替えます
- ウィンドウ上部の「表示する」でも同じものを切り替えられます
- 「全部ON」「全部OFF」で、全タブの要素をまとめて切り替えます

## タブ
| タブ | 要素 |
| :--- | :--- |
| 警察 | 巡回視界(青) / 発見視界(黄色。追跡中は赤) / 背後で気付く距離 / 攻撃範囲 |
| 悪人 | 臨戦態勢範囲 / 反撃の索敵範囲 / 追跡限界 / 攻撃判定(攻撃中だけ、黄色い球) |
| プレイヤー | 通常攻撃の判定(攻撃中だけ、今出している段を黄色い球) / 必殺技の判定(出している間だけ、紫の球) |
| 防犯装置 | ドローンの高さの視界 / 真下の地面の視界(縦の線を含む) |

- 各タブの「このタブを全部ON」「このタブを全部OFF」で、そのタブの要素をまとめて切り替えます
- 攻撃判定は、攻撃していない時は表示しません
- 同じ項目は `CS_DebugRangeDrawer` のInspectorにもあります

# ⚠️ 注意
- 再生中に切り替えた内容は、再生を止めると元に戻ります(Inspectorで変えた時と同じ)。ずっと使う設定は、再生していない時に切り替えてシーンを保存してください
- シーンに `CS_DebugRangeDrawer` が無い時は、ウィンドウに「CS_DebugRangeDrawerがシーンにありません」と出ます
- 判定はサーバー(ホスト)で行われるため、クライアントでは他人の攻撃中表示や警察が出ないことがあります(悪人の攻撃判定はホストの画面にだけ出ます)
