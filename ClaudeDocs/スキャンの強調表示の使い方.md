# スキャンの強調表示の使い方（`CS_PlayerScanHighlight` / `SH_ScanHighlight`）

スキャン（`CS_PlayerScan`）で「見えている」悪人・警察・巡回ドローンのモデルを、**縁が光る半透明のシルエット**（壁越しでも見える）に差し替える仕組みです。

```
CS_PlayerScan（見えている悪人グループ・警察・ドローンの一覧を持つ）
        │ 毎フレーム読むだけ（CS_PlayerScanはこのクラスを知らない）
        ▼
CS_PlayerScanHighlight（Player.prefabに付いている。自分のプレイヤーだけ動く）
        │ 新しく見えた相手 → Renderer のマテリアルを差し替える（元のマテリアルは控える）
        │ 見えなくなった相手 → 元のマテリアルへ戻す
        ▼
SH_ScanHighlight（縁を光らせ、内側は薄く。ZTest Always なので壁越しでも描かれる）
```

3Dモデルの見た目の処理でUIではないため、MVPにはしていません（波の輪の `CS_PlayerScanEffect` と同じ扱い）。
目印のUIは今まで通り `CS_UIScanMarker*`（MVP）が出します。

---

## 差し替えの動き

- 差し替えるのは、相手の下の **MeshRenderer / SkinnedMeshRenderer だけ**です（LineRenderer・パーティクル・UIには触りません）
- 元のマテリアルは差し替える時に控え、次の時に元へ戻します
  - 見える時間（`CS_PlayerScan._revealDuration`）が過ぎた
  - 倒された・消えた
  - `CS_PlayerScanHighlight` が無効になった
- 悪人・警察・ドローンのプレハブは変更していません
- 自分のプレイヤーの画面だけの演出です。通信はしません

## マテリアル

| 相手 | マテリアル | 仮の色 |
|---|---|---|
| 悪人 | `MT_ScanHighlightVillain` | 赤 |
| 警察 | `MT_ScanHighlightPolice` | 青 |
| 巡回ドローン | `MT_ScanHighlightDrone` | 青 |

色・濃さを変えたい時は、**マテリアル**を触ってください（`Assets/Programmer/Material/`）。警察とドローンは今は同じ青ですが、分けられるようにマテリアルを別にしてあります。

| プロパティ | 内容 |
|---|---|
| `_ScanColor`（HDR） | 色。明るさ（Intensity）で縁の光り方も変わる |
| `_FillAlpha` | 内側の濃さ（0 = 透明、既定 0.15） |
| `_RimAlpha` | 縁の濃さ（既定 0.9） |
| `_RimPower` | 大きいほど縁が細くなる（既定 2.5） |

## Player.prefab の設定

`CS_PlayerScanHighlight` の3つのマテリアル欄に、上の3つを入れてあります（空欄の種類は差し替えません）。

## 注意

- シェーダーは元のマテリアルの `_BaseColor` などを使わないので、他のスクリプトの MaterialPropertyBlock（悪人の犯罪演出、警察のパトランプなど）とはぶつかりません
- `ZTest Always` のため、手前に別の物があっても、その上にシルエットが描かれます
- 強調表示をやめたい時は、Player.prefab から `CS_PlayerScanHighlight` を外すだけです（スキャンは今まで通り動きます）
