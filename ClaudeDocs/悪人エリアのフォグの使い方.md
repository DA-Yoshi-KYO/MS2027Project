# 悪人エリアのフォグの使い方（`VillainSpawnPoint` の `VillainAreaFog`）

悪人が湧くエリアに、薄いフォグ（HDRP の **Local Volumetric Fog**）を出す仕組みです。
仕様: Confluence「フィールド > 悪人エリアの処理」（悪人が湧くエリアには薄いフォグを追加する）

```
VillainSpawnPoint.prefab（悪人の出現点）
  └ VillainAreaFog（Local Volumetric Fog）… 出現点の周りに箱型のフォグを出す
```

- フォグは **出現点のプレハブの子** に入っています。出現点を置けば、フォグも自動で付きます
- 出現点は `Field_Multi` / `Field_Solo1` に置かれていて、遊び方（マルチ/ソロ）ごとに有効になった方のフォグだけが出ます
- コードは使っていません。調整はすべて Inspector で行います

---

## 1. 全部の出現点の色・濃さを変える

`Assets/Programmer/Prefab/Field/FieldElement/Villain/VillainSpawnPoint.prefab` を開き、`VillainAreaFog` の **Local Volumetric Fog** を変えます。
プレハブを変えると、全部の出現点に反映されます。

| 項目 | 今の値 | 意味 |
|---|---|---|
| Single Scattering Albedo | (0.72, 0.62, 0.88) 少し紫 | フォグの色 |
| Fog Distance | 25 | **濃さ**。小さいほど濃い（m。この距離で見通しが約37%になる） |
| Size | 12 × 4 × 12 | 箱の大きさ（m） |
| Blend Distance | 1.5 | 箱の端をぼかす幅（m）。0だと箱の形がはっきり見える |
| Blending Mode | Additive | 全体のフォグ（Volume の Fog）に足す |

- 箱の中心は出現点から 1.35m 上（出現点が地面から 0.65m 上にあるので、地面から高さ 4m までを覆う）
- 薄すぎて見えない時は Fog Distance を小さく、濃すぎる時は大きくします

---

## 2. 1か所だけ大きさを変える

巡回の範囲が広くて、悪人がフォグからはみ出す出現点だけ、個別に変えます。

1. `Field_Multi` / `Field_Solo1` の中の出現点（`VillainSpawnPoint_xx`）の子の `VillainAreaFog` を選ぶ
2. Local Volumetric Fog の **Size** を変える（必要なら Transform で位置・向きも変える）

- これはプレハブの上書き（Override）になります。**Apply しない** でください（全部の出現点が同じ大きさに変わります）
- 色・濃さは個別に変えず、プレハブ側でそろえるのがおすすめです

---

## 3. 見えない時の確認

| 確認すること | 場所 |
|---|---|
| 全体の Fog が有効で、**Volumetric Fog** にチェックが入っているか | `Assets/Programmer/Volume/VO_InGameEnv` の Fog（今は有効） |
| HDRP アセットで Volumetrics が有効か | Quality の HDRP アセット。High Fidelity / Balanced は有効、**Performant は無効**（フォグが出ない） |
| カメラの Frame Settings で Volumetrics が切られていないか | カメラの HD Additional Camera Data |

- 画面に同時に出せる Local Volumetric Fog は 64 個まで（HDRP アセットの Max Local Volumetric Fog On Screen）。出現点は1つの遊び方で約30か所なので足ります
- Scene ビューで見えない時は、Scene ビュー上部の Effects（Fog）が有効か確認してください
