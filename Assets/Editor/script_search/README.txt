ScriptSearch Refactored UTF-8版
=====================================

今回の修正
-------------------------------------
・元ファイルをCSごとの文字コードで正しく読み直し
・全CSを UTF-8 BOM付き で統一
・日本語コメント / 日本語メッセージの文字化けを修正

UI変更
-------------------------------------
・「検索設定」と「検索結果」を同一画面に統合
・検索欄の直下に検索結果専用レイアウトを配置
・検索結果は Hierarchy / Prefab タブで切り替え
・Hierarchy / Prefab ともに ScrollView 対応
・Windowサイズに合わせて結果欄の高さを可変化

コード構成
-------------------------------------
GUI描画と検索処理をpartial classの別CSに分離しています。
今後GUI機能を追加する場合は、新しいCSを追加して拡張できます。

Project右クリック検索
-------------------------------------
・Assets内のアタッチ可能な .cs Script を右クリックすると
  「アタッチしているスクリプトを検索」
  を表示
・選択するとScriptSearchウィンドウを自動で開く
・右クリックしたScriptをTarget Scriptへ自動設定
・Hierarchy / Prefab検索を自動実行
・検索結果までそのまま表示
