# サウンドの使い方

SE・BGM・ジングルを **ID(enum)で鳴らす**しくみです。音の設定はデータベース(ScriptableObject)にまとめてあるので、**音素材を差し替える・音量を変えるだけならコードを触らずに `DB_xxxDataBase` を編集するだけ**で済みます。

```
ゲーム側のコード ──▶ CS_SoundManager.instance.PlaySe(ID, 位置)        自分にだけ鳴らす
              └──▶ CS_NetworkSoundPlayer.PlaySeForEveryone(ID, 位置) ─RPC─▶ 各クライアントの CS_SoundManager
                                                                         │
                                       DB_SeDataBase で ID → AudioClip・音量・2D/3D を引いて、プールの AudioSource で鳴らす

シーンに置いた CS_BgmPlayer / CS_InGameBgmController ──▶ CS_SoundManager.instance.PlayBgm(ID, フェード時間)
勝利などの演出 ─────────────────────────────────────────▶ CS_SoundManager.instance.PlayJingle(ID)
```

- 音そのものはネットワークで送りません。「鳴らして」というイベントを全員に届けて、各PCが自分の `CS_SoundManager` で鳴らします
- ソロでも同じコードで動きます(`CS_NetworkSoundPlayer` はオフラインならその場で鳴らすだけ)

---

## 登場するもの

| 名前 | 種類 | 役割 | 場所 |
|:--|:--|:--|:--|
| `CS_SoundManager` / `SoundManager.prefab` | MonoBehaviour(シングルトン) | 再生の窓口。SE用 AudioSource のプール(16個)、BGM用2つ(クロスフェード)、ジングル用1つを持つ。DontDestroyOnLoad | `Prefab/Sound/` |
| `CS_SoundVolumeController` | MonoBehaviour | Master・BGM・SE の音量を AudioMixer に反映して PlayerPrefs に保存。`SoundManager.prefab` に一緒に付いている | 同上 |
| `CSE_SeId` / `CSE_BgmId` / `CSE_JingleId` | enum | 音のID | `Script/Sound/ID/` |
| `CSO_SeDataBase` / `DB_SeDataBase.asset` | ScriptableObject | SEのID → 設定(AudioClip・音量・ピッチ・同時再生数・2D/3D) | `Database/Sound/` |
| `CSO_BgmDataBase` / `DB_BgmDataBase.asset` | ScriptableObject | BGMのID → 設定(AudioClip・音量・ループ) | 同上 |
| `CSO_JingleDataBase` / `DB_JingleDataBase.asset` | ScriptableObject | ジングルのID → 設定(AudioClip・音量・BGMの下げ方) | 同上 |
| `CS_BgmPlayer` / `BgmPlayer.prefab` | MonoBehaviour | シーン開始時にそのシーンのBGMを鳴らす | `Prefab/Sound/` |
| `CS_InGameBgmController` / `InGameBGMPlayer.prefab` | MonoBehaviour | インゲームで通常BGMと警戒BGMを切り替える | 同上 |
| `CS_NetworkSoundPlayer` / `NetworlSoundPlayer.prefab` | NetworkBehaviour | SEを全員に聞かせる。**シーンに1つ置く**(MainScene に置いてある) | 同上 |
| `MainAudioMixer.mixer` | AudioMixer | Master の下に BGM(子に Jingle)と SE | `Audio/Mixer/` |

- パスはすべて `Assets/Programmer/` から
- 音素材は `Assets/Programmer/Audio/BGM` / `Jingle` / `SE/(Event・Item・Player…)` に置く

### どのシーンに何が置いてあるか

| シーン | SoundManager | BGM |
|:--|:--|:--|
| RoomConnection | ○ | `BgmPlayer`(`RoomConnection`) |
| WaitingforaMatch | ○ | `BgmPlayer`(`WaitingForMatch`) |
| MainScene | ○ | `InGameBGMPlayer`(`InGameNormal` ⇔ `InGameAlert`)、`NetworlSoundPlayer` もここ |
| ResultScene | ○ | `BgmPlayer`(`Result`) |

`CS_SoundManager` は2つ目以降が自動で消えるので、各シーンに置いておいて問題ありません(テストで1シーンだけ再生しても鳴るようにするため)。

## SEを鳴らす

### 呼び方は3つ

```csharp
CS_SoundManager.instance.PlaySe(CSE_SeId id);                       // 2D(どこにいても同じ大きさ)
CS_SoundManager.instance.PlaySe(CSE_SeId id, Vector3 position);     // 3D(その場所で鳴る)
CS_SoundManager.instance.PlaySe(CSE_SeId id, Transform follow);     // 3D(follow について動く。サイレン・エンジン音など)
CS_SoundManager.instance.StopAllSe();                               // 全SEを止める
```

- **2D か 3D かはデータベースの `3D設定 > Is 3D` で決まります。** 呼び方では決まりません
  - Is 3D が OFF のSEを位置つきで呼んでも 2D で鳴ります
  - Is 3D が ON のSEを位置なしで呼ぶと、警告ログを出して 2D で鳴ります
- 同じSEが `最大同時再生数` を超えたら、一番古いものを止めて鳴らします。プール(16個)が埋まった時も一番古いものを止めます
- `None` や未登録のIDは鳴りません(未登録・AudioClip 未設定は警告ログが出る)

### 2D と 3D の使い分け

| 種類 | 例 |
|:--|:--|
| 2D | UI(決定・カーソル)、自分にだけ出る通知(被弾、アイテム取得、手配度アップなど) |
| 3D | 爆発、攻撃、足音、サイレンなど、ワールドで鳴って他人にも聞こえる音 |

3D のSEは `Min Distance`(ここまでは最大音量)と `Max Distance`(ここより遠いと聞こえない)で聞こえる範囲を決めます。爆発は遠くまで、足音は近くだけ、のようにSEごとに調整してください。

### IDの番号帯

`CSE_SeId` は番号帯でカテゴリを分けています。`DB_SeDataBase` のIDの選択メニューもこのカテゴリで階層になります。

| 番号 | カテゴリ | 例 |
|:--|:--|:--|
| 100番台 | System | `SystemUIDecide`、`SystemGameStart` |
| 200番台 | Player | `PlayerFootstep`、`PlayerAttackHit`、`PlayerItemPickup` |
| 300番台 | Police | `PoliceSpotted`、`PoliceAttack` |
| 400番台 | Security | `SecurityLaserContact`、`PatrolDroneSpotted` |
| 500番台 | Villain | `VillainCrimeStart`、`VillainDefeat` |
| 600番台 | Raid Boss | `RaidBossSpawn` |
| 700番台 | Item | `ItemBomb`、`ItemSmokeBomb` |
| 800番台 | Event & Notification | `EventKillLog`、`EventTimeAnnouncement` |

### `DB_SeDataBase` の設定項目

| 項目 | 内容 |
|:--|:--|
| SEのID | 鳴らす時に指定するID |
| 再生するAudioClip | 複数入れると、鳴らすたびにランダムで1つ選ぶ(足音のバリエーションなど) |
| 基本設定 > Volume | 音量(0〜1) |
| 基本設定 > Pitch Random | ピッチのランダム幅。0.1 なら 0.9〜1.1 |
| 基本設定 > Max Concurrent | 同じSEを同時に鳴らせる数 |
| 3D設定 > Is 3D | ON で 3D |
| 3D設定 > Min / Max Distance, Rolloff | 3D の聞こえる範囲と減衰のしかた |

## 鳴らすまでの流れ(コード例)

どの例も、次の順で進めます。

1. `CSE_SeId` に使いたいIDがあるか見る。無ければ番号帯に合わせて足す(→「新しい音を足す」)
2. `DB_SeDataBase.asset` にそのIDを登録して、AudioClip・音量・2D/3D を設定する
3. コードから呼ぶ

### 例1: 自分にだけ鳴らす 2D SE(UIの決定音)

`DB_SeDataBase` で `SystemUIDecide` の Is 3D は OFF にしておきます。

```csharp
private void HandleDecide()
{
    if (CS_SoundManager.instance == null) return;

    CS_SoundManager.instance.PlaySe(CSE_SeId.SystemUIDecide);
}
```

- UI の Presenter などから呼ぶ想定です。自分の画面だけの音なので、ネットワークは使いません

### 例2: その場所で鳴らす 3D SE(爆弾の爆発)

`DB_SeDataBase` で `ItemBomb` の Is 3D を ON にして、Max Distance を広め(30〜50 くらい)にしておきます。

```csharp
private void Explode()
{
    // 爆発の処理 ...

    if (CS_SoundManager.instance == null) return;

    CS_SoundManager.instance.PlaySe(CSE_SeId.ItemBomb, transform.position);
}
```

- これは**このPCだけ**で鳴ります。他のプレイヤーにも聞かせたい時は例3の形にします
- 爆発のように、全員のPCで同じ処理(Rpc や NetworkVariable の変化)が走る場所で呼ぶなら、この形のままで全員に聞こえます

### 例3: 全員に聞かせる SE(攻撃の命中)

`DB_SeDataBase` で `PlayerAttackHit` の Is 3D を ON にしておきます。

```csharp
private CS_NetworkSoundPlayer _networkSoundPlayer;

private void Start()
{
    // シーンに1つ置いてあるものを探す
    _networkSoundPlayer = FindAnyObjectByType<CS_NetworkSoundPlayer>();
}

private void HandleAttackHit(Vector3 hitPosition)
{
    if (_networkSoundPlayer == null) return;

    // 全員のPCで、hitPosition から 3D で鳴る
    _networkSoundPlayer.PlaySeForEveryone(CSE_SeId.PlayerAttackHit, hitPosition);
}
```

- `PlaySeForEveryone(id)` で 2D、`PlaySeForEveryone(id, 位置)` で 3D です
- サーバー・クライアントのどちらから呼んでも全員(ホストを含む)で1回ずつ鳴ります。オフライン(ソロ)ならその場で鳴らすだけです
- 音の大きさは各PCのカメラ(AudioListener)からの距離で決まるので、近い人には大きく、遠い人には小さく、範囲外の人には聞こえません
- **同じ出来事について、1台のPCからだけ呼んでください。** 全員のPCで走る処理の中で呼ぶと、人数分重なって鳴ります
  - 例: 攻撃した本人(`IsOwner`)だけが呼ぶ、サーバー(`IsServer`)だけが呼ぶ

## BGM

```csharp
CS_SoundManager.instance.PlayBgm(CSE_BgmId id, float fadeTime = -1f); // fadeTime を省くと SoundManager の既定値(1秒)
CS_SoundManager.instance.StopBgm(float fadeTime = -1f);
CS_SoundManager.instance.currentBgmId;                                 // 今鳴っているBGM
```

- 前のBGMからクロスフェードで切り替わります。同じBGMを鳴らし直しても最初からにはなりません
- `PlayBgm(CSE_BgmId.None)` は `StopBgm` と同じです
- BGMはネットワークで同期しません。各PCがそれぞれ鳴らします

### シーンのBGMを決める(`BgmPlayer.prefab`)

シーンに `BgmPlayer.prefab` を置いて、インスペクターで設定します。シーン開始時(`Start`)に鳴ります。

| 項目 | 内容 |
|:--|:--|
| このシーンで再生するBGM | `CSE_BgmId` |
| フェード時間 | 前のシーンのBGMからの切り替え時間 |
| 開始時にBGMを停止する | ON にすると鳴らさずに止める(無音のシーン用) |

### インゲームの通常 / 警戒の切り替え(`InGameBGMPlayer.prefab`)

MainScene に置いてあります。開始時に通常BGM(`InGameNormal`)を鳴らし、登録した自分のプレイヤーの `CS_PlayerAlert` が警戒状態になったら警戒BGM(`InGameAlert`)にクロスフェードします。警戒が解けたら通常BGMに戻ります。

- 自分のプレイヤーは `CS_InGameBgmController.RegisterLocalPlayer(CS_PlayerAlert)` で登録します
- 切り替えに使うBGMのIDと切り替え時間はインスペクターで変えられます

### `DB_BgmDataBase` の設定項目

| 項目 | 内容 |
|:--|:--|
| BGMのID | `CSE_BgmId` |
| AudioClip | 鳴らす曲 |
| 音量 | 0〜1 |
| ループ再生 | 通常は ON |

BGMの音素材は、インポート設定の Load Type を **Streaming** にするとメモリを食いません。

## ジングル

勝利・敗北など、BGMに割り込む短い曲です。SEとは別に、専用の AudioSource 1つで鳴らします。

```csharp
CS_SoundManager.instance.PlayJingle(CSE_JingleId.GameClear);
CS_SoundManager.instance.StopJingle();
CS_SoundManager.instance.currentJingleId;
```

- 鳴っている間はBGMの音量を下げ(ダッキング)、終わったら元に戻します
- 新しいジングルを鳴らすと、前のジングルは止まります(重ならない)
- 常に 2D です

### `DB_JingleDataBase` の設定項目

| 項目 | 内容 |
|:--|:--|
| ジングルID | `CSE_JingleId` |
| AudioClip | 鳴らす曲 |
| 音量 | 0〜1 |
| BGMダッキング | ジングル中のBGM音量の倍率。0 でBGMを消す、1 で下げない(初期値 0.3) |
| Duck Fade Time | BGMを下げる・戻す時間(初期値 0.3秒) |

## 音量

`SoundManager.prefab` に付いている `CS_SoundVolumeController` で変えます。0〜1 の値を渡すと dB に変換して AudioMixer に反映し、PlayerPrefs に保存します(次に起動した時も同じ音量)。

```csharp
CS_SoundVolumeController volume = CS_SoundManager.instance.GetComponent<CS_SoundVolumeController>();

volume.SetMasterVolume(0.8f);
volume.SetBgmVolume(slider.value);
volume.SetSeVolume(slider.value);

float bgm = volume.bgmVolume; // スライダーの初期値に使う
```

| 音量 | AudioMixer の公開パラメータ名 | 効くグループ |
|:--|:--|:--|
| Master | `MasterVolume` | 全部 |
| BGM | `BgmVolume` | BGM とジングル(Jingle は BGM の子) |
| SE | `SeVolume` | SE |

- 個々の音の音量はデータベースの「音量」、全体のバランスは AudioMixer、プレイヤーの好みは `CS_SoundVolumeController`、と分けています
- 音量設定のUIを作る時は、ほかのUIと同じく MVP(Model / Presenter / View)で作ってください。Presenter から `SetBgmVolume` などを呼ぶ形です

## 新しい音を足す

### SE

1. 音素材を `Assets/Programmer/Audio/SE/(カテゴリ)/` に入れる
2. `CSE_SeId.cs` の該当する番号帯にIDを足す
   - **番号帯の途中に足す時は、すぐ下のIDの番号がずれないか注意してください。** enum は番号で保存されるので、ずれると `DB_SeDataBase` やインスペクターで選んでいたIDが別の音に変わります。末尾(次の番号帯の手前)に足すのが安全です
3. `DB_SeDataBase.asset` の「SEデータ一覧」の + で行を足し、IDを選んで AudioClip・音量・2D/3D を設定する
4. コードから `PlaySe` / `PlaySeForEveryone` で呼ぶ(→「鳴らすまでの流れ」)

### BGM・ジングル

1. 音素材を `Audio/BGM/` か `Audio/Jingle/` に入れる
2. `CSE_BgmId.cs` / `CSE_JingleId.cs` の**末尾に**IDを足す(番号を指定していないので、途中に足すと後ろのIDが全部ずれます)
3. `DB_BgmDataBase.asset` / `DB_JingleDataBase.asset` に行を足して設定する
4. BGM はシーンの `BgmPlayer` のIDを変えるか `PlayBgm` で、ジングルは `PlayJingle` で鳴らす

### 鳴らない時に見るところ

| 症状 | 見るところ |
|:--|:--|
| 「SEが未登録です」「BGMを再生できません」 | データベースにそのIDの行があるか、AudioClip が入っているか |
| 「CS_SoundManagerがありません」 | シーンに `SoundManager.prefab` があるか |
| 3D のはずが 2D で鳴る | データベースの Is 3D、位置つきで呼んでいるか |
| 3D の音が聞こえない | Max Distance が狭すぎないか、自分のカメラから遠すぎないか |
| 全員に聞こえない | `CS_NetworkSoundPlayer` 経由で呼んでいるか、シーンに `NetworlSoundPlayer.prefab` があるか |
| 人数分重なって鳴る | `PlaySeForEveryone` を全員のPCから呼んでいないか |
