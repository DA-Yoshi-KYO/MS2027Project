# 📋 概要
SA(ステルスアクション)で飛んで行ける場所(SAポイント)の作り方・置き方です。
SAポイントの共通部分は `CS_SAPoint`(基底クラス)にあり、種類ごとにこれを継承して作ります。

| 種類 | クラス | 内容 |
|:--|:--|:--|
| ハイドポイント | `CS_HidePoint` | 物陰・高所など。飛んで来た後、隠れられる箱(HideBox)の中にいる間は隠れている扱い |
| 信号機 | `CS_TrafficLightSAPoint` | 信号機の上など。飛ぶだけ(隠れている扱いにはならない) |
| グラップル | `CS_GrappleSAPoint` | ロープで的へ引っ張られる(鳴潮の鉤縄が参考)。飛び始めの距離の5割(既定)まで引っ張られるか、着いたら、早い方で自動で放して、勢いを残したまま自由落下する(着地はさせない)。飛ぶだけ(隠れている扱いにはならない) |

# ✍️ 置き方(共通)
プレハブをフィールドに置くだけです。置いた物の子に、次の空オブジェクトがあります。

| 子オブジェクト | 役割 |
|:--|:--|
| `StandPoint` | 着く位置と向き。着いた時の足元の位置(高さ込み)に置く |
| `SAReachBox` | SAできる範囲の箱。プレイヤーの足元がこの箱の中にある時だけSAでき、強調UIも出る。位置・回転・Scale(x: 幅, y: 高さ, z: 奥行 m)をそのまま箱にする |
| `HideBox`(ハイドポイントのみ) | 隠れられる箱 |

* SAできる範囲(SAReachBox)は、置いた物ごとに調整できます。シーンビューでSAポイントか子を選ぶと、箱が黄色の枠で見えます。
* 強調UIは、既存のハイドマーカーUI(`CS_PlayerHideMarkerUI`)をそのまま使います。種類ごとにUIは足しません。

# 🚦 信号機のプレハブ
`Assets/Programmer/Prefab/Field/FieldElement/TrafficLight/TrafficLight.prefab`
Cubeで作った仮の見た目です(柱 + 頭)。モデルができたら、`Pole`・`Head` を差し替えてください(`StandPoint` は頭の上、高さ8m)。

# 🪝 グラップル
`Assets/Programmer/Prefab/Field/FieldElement/GrapplePoint/GrapplePoint.prefab`
Cubeで作った仮の的です。操作はSAと同じで、飛べる時にダッシュボタンを押すとロープが飛び、的へ引っ張られます(スイング・ぶら下がりはありません)。

| 項目 | 内容 |
|:--|:--|
| `Target`(子) | 的。ロープの先になる(`_ropeEndPoint`) |
| `StandPoint`(子) | 引っ張られる先の位置。的の少し手前(既定は的から手前2m・下1m)に置く。着地はさせず、ここに着いた時点で放す |
| `SAReachBox`(子) | SAできる範囲。遠くから狙えるよう広めにしている(既定は 40×30×30) |

* 動き
  * 一定の速さで的(StandPoint)へ引っ張られる。放すボタンは無い(ジャンプボタンでは途中でやめられる。SA共通)
  * 飛び始めの距離の`_releaseDistanceRate`(既定0.5 = 5割)まで引っ張られるか、`StandPoint`に着いたら、早い方で自動でロープを放す(着いた時も、5割で放した時と同じ挙動)。放した後は飛んでいない。通常の状態に戻って自由落下する(位置は合わせない)。放した瞬間の速度(向き・高さ込み)をそのまま残す。水平の勢いは、グラップルごとの減速率`_releaseDrag`で弱まりながら、着地まで続く(`CS_Player.EndSAMotion`)。入力がある間は、水平の速度が入力の移動速度へ加速度`_airControlAccel`(`CS_Player`。既定25m/秒²)で近づくので、空中で曲げられる(逆向きに押せば約1秒で止まる)。着地・ダッシュ・倒れる・スタンで勢いは消える
  * 信号機・ハイドポイントは今まで通り、着いたら位置を合わせて速度を0にして、普通の状態に戻る(歩ける・ジャンプできる・重力あり)
  * SAで飛んでいる間の速度は、`Fly`/`Lunge`の残り時間とは別の、SA専用の速度(`CS_Player.SetSAVelocity`)で動かす。終わる時は`CS_Player.EndSAMotion(終わった時の速度)`で、専用の速度をクリアすると同時にその速度を通常の状態に渡す(着いた時は0、放した時は放した瞬間の速度)
  * 飛び始めの瞬間に重力と当たり判定を切って、すぐ動き出す。放した直後の約0.1秒(`CS_PlayerHide`の`_releaseGhostTime`)だけ当たり判定を切ったままにして、近くの物の角に引っかからないようにする(上向きに進んでいる時だけ・着く位置を通り過ぎない範囲だけ。壁抜け・床抜けはしない)
* ポイントごとに調整できる値(`CS_GrappleSAPoint`)
  * `_pullSpeed`: 引っ張られる速さ(m/秒。既定35。ふつうのSAは`CS_PlayerHide`の`_flySpeed`)
  * `_releaseDistanceRate`: 飛び始めの距離のこの割合まで引っ張られるか、着いたら放す(0.05〜1。既定0.5。1にすると着いた時に放す)
  * `_releaseDrag`: 放した後の水平の勢いの減速率(毎秒 e^(−減速率) の割合で弱める。既定0.5)。水平30m/秒の目安: 0 = 減速なし(着地まで) / 0.5 = 1秒後18m/秒・2秒後11m/秒 / 1.0 = 1秒後11m/秒・2秒後4m/秒 / 2.0 = 1秒後4m/秒(ほぼ1秒で止まる)
* 的(`Target`)には当たり判定を付けません(ロープの先を示すだけ)。
* ロープの表示は、プレイヤーに付ける `CS_PlayerGrappleRope` が行います(グラップルのポイントへ飛ぶ間だけ。仮の線)。**今は SATest の Player にだけ付けています。Player.prefab には付いていません**
* 飛ぶのは本人の手元だけなので、ロープも本人の画面にだけ出ます。

# 🛤️ 動くSAポイント(パスに沿って自走)
SAポイント(信号機など)を、決めた道(パス)に沿って自動で動かせます。動かせるのはSAポイントだけです。
サンプル: `SATest` の `MovingTrafficLight`(ゆるい曲線で往復する信号機)

## 置き方
```
MovingTrafficLight   ← CS_PathFollower を付ける(このオブジェクト自身は動かない)
  ├ TrafficLight     ← 動かすSAポイント(プレハブ。StandPoint・SAReachBoxも一緒に動く)
  └ PathPoints       ← 空のオブジェクト(名前は何でもよい)
      ├ Point_0      ← CS_PathFollowerPoint を付けた空オブジェクト(制御点)
      └ Point_1 …
```
* 制御点はSAポイントの**子にしないでください**(一緒に動いてしまいます)。`CS_PathFollower` の子に置きます
* 動かすSAポイントは `Sa Point` に入れます(空なら子から探します)

## 設定
| 場所 | 項目 | 内容 |
|:--|:--|:--|
| `CS_PathFollower` | `Mode` | `Once`: 一方向(最後の点で止まる) / `Loop`: 周回(最後から最初へもつなぐ) / `PingPong`: 往復 |
| 点(`CS_PathFollowerPoint`) | `Wait Time` | その点に着いてから動き出すまでの待ち時間(秒)。往復では、帰り道も途中の点で待つ(始点は周期の頭の1回、終点は折り返す前の1回) |
| 点(`CS_PathFollowerPoint`) | `Speed To Next` | 動き出す点から、次に向かう点までの速さ(m/秒)。行きは「その点から次の点まで」、往復の帰り道は「その点から1つ前の点まで」。最後の点の値は、周回(最後→最初)と往復(帰り道の最初の区間)で使う。一方向では使わない |

曲線は、点を必ず通るなめらかな曲線(Catmull-Rom)で、曲線の途中では速さが変わりません。

### 動き方のカーブ(イーズ)
区間の中の進み方(出発はゆっくり、到着はゆっくり、など)を、点ごとのカーブで決められます。既定は直線(一定の速さ)で、何も変えなければ今まで通りです。
* 横は区間にかかる時間の進み具合(0〜1)、縦は距離の進み具合(0〜1)です。カーブが端で0・1にならなくても、頭を0、終わりを1にそろえます(区間のつなぎ目で位置が飛びません)
* 区間の持ち主は、区間の始点の点です(点iのカーブは、点i→点i+1の動き)
* **カーブでは、区間にかかる時間(長さ÷速さ)も、待ち時間も変わりません。** 区間の中の進み方だけが変わります。`Speed To Next` は、その区間の平均の速さです

| 項目 | 内容 |
|:--|:--|
| 行きのカーブ | その点から次の点へ向かう時の進み方 |
| 帰りの動き(往復の時だけ) | 次の点からその点へ戻る時の進み方を選ぶ |

帰りの動き:
| 選択 | 動き |
|:--|:--|
| `Copy` | 行きと同じカーブを、帰りの進む向きにそのまま使う(行きの出発がゆっくりなら、帰りも出発がゆっくり)。既定 |
| `Inverse` | 行きの動きの逆再生(行きの出発がゆっくりなら、帰りは到着がゆっくり) |
| `Custom` | 帰り専用のカーブを使う(`Custom` を選んだ時だけ、帰りのカーブの欄が出る) |

* 一方向・周回では、帰りは使いません(欄も出ません)。最後の点の欄は、周回の時だけ行きのカーブが出ます(最後→最初の区間)
* **帰りの速さは、カーブとは違い、出発する点(次の点)の値**です。カーブ・帰りの動きは、区間の始点の点の値です

## シーンビューでの編集
`CS_PathFollower` を選ぶと使えます(全てUndo対応)。
* 点の球をクリック → 出てきた矢印をドラッグして移動
* `Shift + クリック`: クリックした場所に点を追加(物に当たればその面、無ければ最後の点の高さ)
* 左上の「選んでいる点を削除」「プレビュー」(プレビューは、再生しなくても、待ち時間・速さ・動き方どおりに動く黄色い球を見せる。SAポイント本体は動かさない)
* 各点の上に、待ち時間と次の点までの速さが出る。インスペクターの一覧では、値の変更と、区間ごとの長さ・かかる時間が見える
* 「動かす物を最初の点へ合わせる」で、SAポイントを最初の点に置ける

## 仕組み(マルチ)
* 位置は「共通の時刻からの経過時間」だけで決まります。位置の送信・`NetworkTransform` は使いません
* 基準時刻は、ネットワークにつながっている間はNetcodeのサーバーTime(`NetworkManager.ServerTime`)、ソロ・オフラインの間はUnityの時間です
* 全員のシーンに同じ物を同じ位置に置けば、同じ時刻には同じ位置にいます
* 構成: `CS_PathFollower` 1つに、曲線・時間→位置の計算と基準時刻・位置の反映をまとめています(MVPは使っていません)。エディタ拡張は `CSED_PathFollowerEditor`、点は `CS_PathFollowerPoint`
* SAで飛んでいる間、`CS_PlayerHide` は毎物理フレーム、動く的の立つ位置を読み直して追いかけます。動かない的の動きは変わりません

## 注意
* 点は再生を始める時に読み込みます(再生中に動かしても反映されません)
* 動かすのは位置だけです(向きは変わりません)
* 動くSAポイントに乗っている間は、プレイヤーも一緒に運ばれます(`CS_PlayerRideSAPoint`)。本人の手元だけで動き、位置は今まで通りNetworkTransformが他の人へ伝えます
  * 運ばれる条件: 接地していて、SAで飛んでいない間に、足元の真下が動くSAポイント(`CS_PathFollower`の動かす物)の一部(Collider)である時。ジャンプ・落下・SAで離れたら運ばれません。床や他の物の上は対象外です
  * 位置だけ運びます(向きには追従しません)。運び方は、位置を動かすのではなく、毎物理フレーム、足場の水平の速度をプレイヤーの速度に足します(位置を直接動かすと、Rigidbodyの補間が切れてカクカクし、歩きのアニメーションが揺れるため)。足場の上下の動きは、足場との接触で運ばれます
  * 歩きのアニメーション: 運ばれた分は歩きに数えません。`CS_PlayerVisual` が座標の変化から歩きの速さを求める時に、足場の速度(`CS_PlayerRideSAPoint.platformVelocity`)を引きます。立っていれば立ち、足場の上で歩けば歩きになります。他の人の画面でも同じです(足場の位置は全員が同じ時刻から計算するため)
  * **今は SATest の Player にだけ付けています。Player.prefab には付いていません**(全員に付けるかは相談)

# 🆕 新しい種類を足す時
1. `CS_SAPoint` を継承したクラスを作る(`CS_TrafficLightSAPoint` が最小の例)。
2. 隠れられる箱を持たせたい時だけ、`hasHideBox`・`Contains`・`GetHideBoxPoint` を上書きする(`CS_HidePoint` を参照)。
3. プレハブを作り、`StandPoint` と `SAReachBox` を子に置いて、スクリプトに割り当てる。
`CS_PlayerHide`・ハイドマーカーUIは、`CS_SAPoint` の一覧を見ているため、変更は要りません。
