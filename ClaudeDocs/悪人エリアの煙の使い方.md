# 悪人エリアの煙の使い方（`CS_VillainAreaSmoke` / `VEG_VillainAreaSmoke.vfx`）

悪人エリアの入口に、紫の瘴気の壁を出す仕組みです。瘴気はその場に漂い、入口の位置が一番濃く、大通り側と路地側に向かってグラデーションで消えていきます。
その出現点に悪人グループがいる間だけ瘴気が出て、グループがいなくなると自然に消えます。
仕様: Confluence「フィールド > 悪人エリアの処理」

```
Field.prefab
  └ VillainSpawnPoint_xx（VillainSpawnPoint.prefab）… CS_VillainAreaSmoke が瘴気を出す・止める。幅と高さもここ
      └ VillainAreaSmoke（VisualEffect 1つ）… この Transform が壁の中央と向き（赤い矢印の X 方向が壁の幅、青い矢印の Z 方向が前後）
```

- 瘴気を出す・止めるのは `CS_VillainSpawner`（サーバー）で、`NetworkVariable` で全クライアントに同期します
- VFX は `Assets/Programmer/Effect/VEG_VillainAreaSmoke.vfx` です

---

## 1. 手で置く

1. `Field.prefab` を開き、出現点（`VillainSpawnPoint_xx`）の子の `VillainAreaSmoke` を選ぶ
2. Scene ビューで **移動ツール** で壁の中央に、**回転ツール** で向きを変える（赤い矢印の X 方向を通路の幅に合わせ、青い矢印の Z 方向を大通りの方へ向ける）
3. 親の出現点の **CS_VillainAreaSmoke** で Width・Height を変える

| 項目 | 意味 |
|---|---|
| Width | 壁の幅（m）。端まで同じ濃さなので、通路の幅に合わせる |
| Height | 壁の高さ（m） |

- **狭い通路** は、Width を手で広げて両端を建物の中に入れると、通路を塞いだ壁に見えます
- 親の出現点を選択すると、Scene ビューに壁の範囲が紫の線で表示されます
- 変更は `Field.prefab` に保存します。シーン上で動かしただけだと、シーンの上書きになります
- **VillainSpawnPoint.prefab に Apply しない** でください（全部の出現点が同じ場所になります）
- Y 軸だけ回してください（傾けると壁も斜めになります）

---

## 2. 全部の出現点の見た目を変える

`VEG_VillainAreaSmoke.vfx` を開き、Blackboard の値を変えます。

| 変えたいもの | パラメータ |
|---|---|
| 前後の広がり | Depth（m。Z 方向の全体の長さ） |
| 前後の消え始める位置 | Depth Fade（0 で中心から消え始め、1 に近いほど端の近くまで濃い） |
| 上の消え始める高さ | Top Fade（0.5 なら高さの半分から薄くなり、Height で透明になる） |
| 明るさ | Glow |
| 量 | Spawn Rate |
| 色・濃さ・現れ方・消え方 | Color Over Life |
| 脈動 | Pulse Speed（速さ）、Pulse Amount（強さ。0 で脈動なし） |
| 粒の大きさ | Size Over Life |
| 寿命 | LifeTime |

揺らぎは、Update にある **Turbulence** ブロックの Intensity で変えます。
粒が生まれる位置は Initialize の **Wall Smoke**、発光と前後・上の透明は Output の **Glow Pulse**（どちらも Custom HLSL）で決めています。

> Width・Height は実行時に CS_VillainAreaSmoke の値で上書きされるので、VFX の値を変えても効きません。
> 幅が 6m より広い壁は、薄くならないように Spawn Rate を幅に合わせて増やします（最大 4 倍）。
> 幅が 6m より狭い壁は、粒の大きさ（Particle Scale）を幅に合わせて小さくします（下限 0.55 倍）。どちらも CS_VillainAreaSmoke がゲーム開始時に設定します。

カメラに映っていない間も瘴気が動くように、VFX の Culling Flags は「常に動かす」にしてあります（見た瞬間に瘴気が無い状態を防ぐため）。

---

## 3. エディタで確認する

Scene ビューのライティングをオフにしていると、VFX の色が描画されません。ライティングをオンにして、`VillainAreaSmoke` を選んで Visual Effect パネルの **Play()** を押します。

エディタでは出現点ごとの Width・Height が反映されず、標準の値で表示されます。発光は明るい背景で見えにくいので、最終確認は Play で行います。

---

## 4. 瘴気が出ない時の確認

| 確認すること | 場所 |
|---|---|
| 出現点に `CS_VillainAreaSmoke` が付いていて、Smoke が設定されているか | 出現点の Inspector |
| その出現点に悪人グループがいるか（いない時は出ないのが正しい） | プレイ中のゲージの表示など |
| 瘴気を出す場所が壁の中などになっていないか | 出現点を選択して Scene ビューで確認 |
| カメラが Bounds の外を向いて消えていないか（幅がとても広い壁） | `VEG_VillainAreaSmoke.vfx` の Bounds |
