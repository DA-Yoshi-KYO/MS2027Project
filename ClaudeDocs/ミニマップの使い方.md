# ミニマップの使い方（`CS_MiniMapController` / `CS_UIMiniMapModel`）

UI側は MVP 構成になっていますが、**プレイヤー・悪人・警察のスクリプトから触るのは `CS_MiniMapController` だけ** です。
Model（`CS_UIMiniMapModel`）は Controller が内部で `new` して持っているので、自分で生成する必要はありません。

```
Player / Villain / Police のスクリプト
        │ Register〇〇(id, transform) / Unregister〇〇(id)
        ▼
CS_MiniMapController（GameControllerManager に付いている）
        │ 0.05秒ごとに Transform の位置・向きを Model へ書き込む
        ▼
CS_UIMiniMapModel ──(OnDataChanged)──▶ Presenter ──▶ View（背景スクロール・アイコン表示）
```

やることはこれだけです。

1. 出現したら Controller に **Transform を登録** する
2. 消えるときに **登録解除** する
3. 位置の更新は Controller が自動でやるので、**毎フレーム何かを呼ぶ必要はない**

---

## 誰がどのメソッドを呼ぶか

| 対象 | ミニマップ上の種類 | 出現時 | 消えるとき |
|---|---|---|---|
| 自分のプレイヤー（`IsOwner`） | `Player`（中央固定・常に上向き） | `RegisterLocalPlayer(transform)` | 不要 |
| 他のプレイヤー（`!IsOwner`） | `MultiplayerAlly` | `RegisterAlly(id, transform)` | `UnregisterAlly(id)` |
| 悪人（Villain） | `Enemy` | `RegisterEnemy(id, transform)` | `UnregisterEnemy(id)` |
| 警察（Police） | `Police` | `RegisterPolice(id, transform)` | `UnregisterPolice(id)` |

---

## 準備（シーン側）

- `MainScene` の `GameControllerManager` に `CS_MiniMapController` が付いています
  - `_miniMapView` に `UICanvas` 配下の `MiniMap`（`CS_UIMiniMapView` + `CS_UIMiniMapPresenter` 付き）をセット済み
- `CS_UIMiniMapView` の Inspector で **アイコン Prefab（Enemy / Ally / Police）** がセットされていることを確認してください
  - Prefab が未設定の種類は **登録してもアイコンが出ません**（エラーも出ないので注意）

Controller の取得はシーンに1つしかないので `FindAnyObjectByType` で取れます。

```csharp
var miniMap = FindAnyObjectByType<CS_MiniMapController>();
```

---

## プレイヤー向け

プレイヤーは **自分（Owner）なら `RegisterLocalPlayer`、他人なら `RegisterAlly`** です。
`RegisterLocalPlayer` が一度も呼ばれていないと **ミニマップ全体が描画されません**（Presenter がプレイヤー基準で計算するため）。

```csharp
using Unity.Netcode;
using UnityEngine;

public class CS_Player : NetworkBehaviour
{
    private CS_MiniMapController _miniMap;
    private string _miniMapId;

    public override void OnNetworkSpawn()
    {
        _miniMap = FindAnyObjectByType<CS_MiniMapController>();
        if (_miniMap == null) return;

        if (IsOwner)
        {
            // ① 自分 → ミニマップの中心になる
            _miniMap.RegisterLocalPlayer(transform);
        }
        else
        {
            // ② 他プレイヤー → 味方アイコン
            _miniMapId = $"Player_{NetworkObjectId}";
            _miniMap.RegisterAlly(_miniMapId, transform);
        }
    }

    public override void OnNetworkDespawn()
    {
        // ③ 他プレイヤーだけ解除（自分は解除APIなし）
        if (_miniMap != null && _miniMapId != null)
            _miniMap.UnregisterAlly(_miniMapId);
    }
}
```

## 悪人（Villain）向け

悪人は `Enemy` として登録します。
NetworkObject はサーバーで生成されても全クライアントで `OnNetworkSpawn` が呼ばれるので、**各クライアントで自分のミニマップに登録** されます。

```csharp
using Unity.Netcode;
using UnityEngine;

public class CS_VillainMiniMapIcon : NetworkBehaviour
{
    private CS_MiniMapController _miniMap;
    private string _miniMapId;

    public override void OnNetworkSpawn()
    {
        _miniMap = FindAnyObjectByType<CS_MiniMapController>();
        if (_miniMap == null) return;

        _miniMapId = $"Villain_{NetworkObjectId}";
        _miniMap.RegisterEnemy(_miniMapId, transform);
    }

    public override void OnNetworkDespawn()
    {
        // 倒された・逃走したなど、消えるときに必ず解除
        _miniMap?.UnregisterEnemy(_miniMapId);
    }
}
```

## 警察（Police）向け

書き方は悪人と同じで、メソッドが `RegisterPolice` / `UnregisterPolice` になるだけです。

```csharp
using Unity.Netcode;
using UnityEngine;

public class CS_PoliceMiniMapIcon : NetworkBehaviour
{
    private CS_MiniMapController _miniMap;
    private string _miniMapId;

    public override void OnNetworkSpawn()
    {
        _miniMap = FindAnyObjectByType<CS_MiniMapController>();
        if (_miniMap == null) return;

        _miniMapId = $"Police_{NetworkObjectId}";
        _miniMap.RegisterPolice(_miniMapId, transform);
    }

    public override void OnNetworkDespawn()
    {
        _miniMap?.UnregisterPolice(_miniMapId);
    }
}
```

> ネットワークを使わない（MonoBehaviour の）オブジェクトなら、`OnNetworkSpawn` → `Start`、`OnNetworkDespawn` → `OnDestroy`、`NetworkObjectId` → `GetInstanceID()` に置き換えてください。

---

## 注意点

- **id は種類をまたいで重複させない**
  - View のアイコンは id だけで管理しているので、悪人と警察で同じ id を使うとアイコンが混ざります
  - `"Villain_" + NetworkObjectId` のように **種類のプレフィックスを付ける** のがおすすめ
- **消えるときは必ず Unregister する**
  - Transform が Destroy されると位置の更新は止まりますが、Model にデータが残るので **アイコンが最後の位置に残り続けます**
- アイコン表示範囲（`_mapRadius`）より外にいる相手は、**ミニマップの縁に小さく半透明で表示** されます
- Register は何度呼んでも上書きされるだけなので、二重登録しても問題ありません

## API 早見表（`CS_MiniMapController`）

| メソッド | 説明 |
|---|---|
| `RegisterLocalPlayer(transform)` | 自分のプレイヤーを登録。ミニマップの中心・回転の基準になる |
| `RegisterAlly(id, transform)` | 他プレイヤーを登録 |
| `UnregisterAlly(id)` | 他プレイヤーを削除 |
| `RegisterEnemy(id, transform)` | 悪人を登録 |
| `UnregisterEnemy(id)` | 悪人を削除 |
| `RegisterPolice(id, transform)` | 警察を登録 |
| `UnregisterPolice(id)` | 警察を削除 |
| `SetMapRadius(radius)` | アイコンを表示するワールド上の半径を変更 |
| `SetMapWorldSize(size)` | 背景マップ画像1枚分のワールドサイズを変更 |

### Inspector 設定

| 場所 | 項目 | 説明 |
|---|---|---|
| `CS_MiniMapController` | `_mapRadius`（50） | ミニマップに映るワールド半径 |
| | `_mapWorldSize`（240） | 背景PNGがカバーするワールドの一辺の長さ |
| `CS_UIMiniMapPresenter` | `_rotateWithPlayer` | プレイヤーの向きに合わせてマップを回転するか |
| | `_mapCenterX` / `_mapCenterZ` | 背景PNGの中心のワールド座標（地形の Position + サイズ / 2） |
| `CS_UIMiniMapView` | `_miniMapDisplayRadius`（75） | UI上のミニマップ半径（px） |
| | `_enemyIconPrefab` / `_allyIconPrefab` / `_policeIconPrefab` | 各アイコンの Prefab |

- **Model / Presenter / View のスクリプトは触らなくてOK**（Controller 経由で使ってください）
