# 透過処理の使い方（`CS_PlayerCameraOcclusion` / `SHG_DitherLit`）

カメラとプレイヤーの間に入った建物・小物を **アルファディザ** で透過させる仕組みです。

```
CS_PlayerCameraOcclusion（Player プレハブに付いている。自分の画面のプレイヤーだけ動く）
        │ カメラ → プレイヤー へ SphereCast、当たったものの「タグ」を親までたどって調べる
        ▼
タグごとの透過量（Building = 0 / Prop = 0.5）を、その下の Renderer へ MaterialPropertyBlock で渡す
        ▼
マテリアルの _DitherFade（SHG_DitherLit）が網目状に画素を抜く
```

やることは2つだけです。

1. 透過させたいオブジェクトに **タグ（`Building` / `Prop`）を付ける**
2. そのオブジェクトのマテリアルを **`SHG_DitherLit` で作る**（または自作シェーダーに `_DitherFade` を組み込む）

---

## 1. タグを付ける

| タグ | 遮っている間の `_DitherFade` | 用途 |
|---|---|---|
| `Building` | 0（全部抜ける。影は残る） | ビル・壁など大きいもの |
| `Prop` | 0.5（半分抜ける） | 看板・小物など |

- タグは **透過させたい単位の一番上（ルート）** に付けます。コライダーが子にあっても、親をたどって見つけます
- 見つかったタグ付きオブジェクトの **子の Renderer をまとめて** 透過します
- 入れ子になっている場合は、**コライダーから見て一番近いタグ** が使われます（`BackAlley` の中の `Bill` は `Bill` ごとに透過）
- 透過させたくなくなったら、タグを `Untagged` に戻すだけです
- `Bill` / `Wall` のプレハブには `Building` を付けてあります
- 足場になる `Floor` / `Road` / `Bridge` / `Stairs` には付けていません（プレイヤーの足元が抜けるため）

> Unity のタグは 1 つのオブジェクトに 1 つだけです。別のタグが必要なオブジェクトに付ける時は、子に空オブジェクトを作ってそちらに付けるなど工夫してください。

---

## 2. マテリアルを作る

`Assets/Programmer/Shader/ShaderGraph/SHG_DitherLit.shadergraph` を右クリック → **Create > Material** で作ります。
中身はデザイナーさんの `SHG_SampleTextureLit` と同じ（ColorMap / NormalMap / ORMMap など）で、次の2点だけ違います。

- `DitherFade`（`_DitherFade`）プロパティ … 1 = 不透明、0 = 全部抜ける。**通常は 1 のまま** にしておく（スクリプトが書き換える）
- **影はディザで抜けない**（Alpha Clip Threshold Shadow を別にしてある）

`_DitherFade` を持っていないマテリアル（HDRP 標準の Lit など）は、タグが付いていても **何も変わりません**（エラーも出ません）。

### 自作のシェーダーグラフに組み込む場合

`SHG_DitherLit` の左下にあるノードをコピーしてください。

```
DitherFade ──▶ Dither ──▶ Step(Edge) ──▶ Multiply(×2) ──▶ Add ──▶ Alpha Clip Threshold
                              In = 0                      ▲
                                    AlphaClipThreshold ───┴──────▶ Alpha Clip Threshold Shadow
```

- Graph Settings で **Surface Type = Opaque、Alpha Clipping = ON、Use Shadow Threshold = ON**
- プロパティの Reference は必ず **`_DitherFade`**（スクリプトはこの名前で値を渡す）

---

## 調整（Player プレハブの `CS_PlayerCameraOcclusion`）

| 項目 | 既定 | 内容 |
|---|---|---|
| `_settings` | Building=0, Prop=0.5 | タグと、遮っている間の `_DitherFade`。タグを増やしたい時はここに追加（Tag Manager にも追加） |
| `_targetHeights` | 0.3, 1.6 | カメラからプレイヤーのどの高さへ判定を飛ばすか（足元・頭） |
| `_castRadius` | 0.2 | 判定の太さ(m) |
| `_layerMask` | Everything | 判定するレイヤー |
| `_fadeSpeed` | 6 | 1秒あたりに `_DitherFade` が変わる量（6 なら約0.17秒で切り替わる） |

---

## 注意

- 透過は **自分の画面だけ** の演出です。通信はしません
- 透過中の Renderer は MaterialPropertyBlock を持つため SRP Batcher から外れます。元に戻ると外すので、普段の描画には影響しません
- 網目が目立つ場合は、カメラの Anti-aliasing を TAA にするとなじみます
