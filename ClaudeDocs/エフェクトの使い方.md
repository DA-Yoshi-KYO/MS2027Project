# エフェクトの使い方

アクションに合わせて、パーティクルなどのエフェクトを ID で出すしくみです。SE(`CSE_SeId` / `DB_SeDataBase` / `CS_SoundManager`)と同じ形にしています。
本番の素材ができたら、**`DB_EffectDataBase` の Prefab を差し替えるだけ**でゲーム中のエフェクトが入れ替わります。

```
アクション(CS_PlayerAttack など) ──イベント──▶ 演出クラス(CS_PlayerAttackEffect など)
                                                 │
                         自分の画面だけ ──────────┼──▶ CS_EffectManager.Play(ID, 位置, 向き)
                         全員の画面に出す ────────┘──▶ CS_NetworkEffectPlayer ─RPC─▶ 各クライアントの CS_EffectManager
                                                                                       │
                                                                     DB_EffectDataBase で ID → Prefab を引いて、プールから出す
```

- ロジック側(CS_PlayerAttack など)はエフェクトのことを知りません。演出クラスを外しても動きは変わりません
- 画面全体にかける効果(集中線など)は別のしくみです → `CS_PlayerScreenEffect`(画面効果)

## 登場するもの

| 名前 | 種類 | 役割 | SEでいうと |
|:--|:--|:--|:--|
| `CSE_EffectId` | enum | エフェクトのID。プレイヤー 200番台 / 警察 300番台 / 悪人 400番台 / アイテム 500番台 | `CSE_SeId` |
| `CS_EffectData` | データ | エフェクト1つ分の設定(Prefab・時間・大きさ・色・同時に出せる数) | `CS_SeData` |
| `CSO_EffectDataBase` / `DB_EffectDataBase.asset` | ScriptableObject | ID → 設定の一覧。`Assets/Programmer/Database/Effect/` | `CSO_SeDataBase` |
| `CS_EffectManager` / `EffectManager.prefab` | MonoBehaviour | Prefab をプールして、ID・位置・向きで出す。MainScene に置いてある | `CS_SoundManager` |
| `CS_NetworkEffectPlayer` | NetworkBehaviour | 全員の画面に出す。**キャラクターの Prefab に付ける** | `CS_NetworkSoundPlayer` |
| `CS_PooledEffect` | MonoBehaviour | プールしたエフェクト1つ分の再生・停止。マネージャーが自動で付ける | - |
| `IEffectPlayable` | interface | ParticleSystem・VFX Graph 以外で動く仮エフェクト用 | - |
| `CS_EffectBoneTrail` | MonoBehaviour | こぶしなどのボーンに付いていき、軌跡を描く仮エフェクト(TrailRenderer) | - |

## エフェクトを差し替える・調整する → `DB_EffectDataBase.asset`

| 項目 | 意味 | 初期値 |
|:--|:--|:--|
| Id | エフェクトのID | - |
| Prefab | 出す Prefab。ParticleSystem / VisualEffect(VFX Graph) / `IEffectPlayable` のどれでもよい(子に入っていてもよい) | - |
| Lifetime | 何秒で出すのをやめるか。**ループするエフェクトは必ず入れる**。0 はループしないエフェクト用(粒が消えたら終わる) | 1 |
| Scale | 出す時の大きさ(倍) | 1 |
| Override Color | オンにすると色を Color で上書きする | オフ |
| Color | 上書きする色(HDR) | 白 |
| Max Concurrent | 同じエフェクトを同時に出せる数。超えたら一番古いものを消して出し直す | 8 |

- 出すのをやめた後は、残っている粒が自然に消えてからプールに戻ります(最大5秒待つ)
- Prefab は **Play On Awake のままでよい**です(プールに入れる時は非表示なので勝手に再生されない。出す時に最初から再生し直す)
- **Scale を 1 以外にすると、ParticleSystem の Scaling Mode を Hierarchy に書き換えます**(Local のままだと大きさが効かないため)。本番の素材は Scale 1 のまま、Prefab 側で大きさを決めるのがおすすめです
- 色の上書きは ParticleSystem の Start Color を置き換えます(グラデーションやランダムの色は1色になります)。VFX Graph は「Color」という名前の Vector4 プロパティがあれば置き換えます
- 時間は `Time.timeScale` の影響を受けます(ゲームの速さに合わせて遅くなる)

### 出す位置を変えたい

| エフェクト | 位置の決め方 | 変える場所 |
|:--|:--|:--|
| 通常攻撃の殴り | こぶしのボーンに付いていく | `FX_PlayerPunchTrail〜` の Bone Name(見つからない時は Fallback Offset) |
| 通常攻撃の判定 | 攻撃判定(球)の中心と同じ。足元から正面へ Hit Range(各段の `DB_PlayerAttack〜`)の所 | `DB_PlayerAttack〜` の Hit Range(判定と一緒に動く) |
| 必殺技の発動 | プレイヤーの足元に付いていく | エフェクトの Prefab の中で位置をずらす |
| 必殺技の判定 | プレイヤーの足元(その場) | 同上 |
| HPが減った時 | 体の中心(Collider の中心。無ければ足元から Height)から、カメラの方へ Camera Offset(0.5m)近づけた所。体のモデルに隠れないように | `CS_PlayerDamageEffect` / `CS_VillainDamageEffect` の Height・Camera Offset |
| パリー成功 | 体の中心から、カメラの方へ Camera Offset(0.5m)近づけた所 | `CS_PlayerParrySuccessEffect` の Height・Camera Offset |
| スポーン・リスポーン | プレイヤーの足元に付いていく | エフェクトの Prefab の中で位置をずらす |
| 悪人の撃破 | 足元から Height の高さから、カメラの方へ Camera Offset(0.5m)近づけた所(倒れると Collider が無効になるため) | `CS_VillainDefeatEffect` の Height・Camera Offset |
| 悪人の攻撃 | 右手(`hand.r`)+ Offset | `CS_VillainAttackImpactEffect` の Bone・Offset |
| 警察の攻撃 | 攻撃判定(球)の中心、攻撃の向き | `CS_PoliceAttack` の Hitbox Forward Offset |

### こぶしの軌跡の仮エフェクト(`CS_EffectBoneTrail`)

| 項目 | 意味 |
|:--|:--|
| Bone Name | 付いていくボーンの名前(今は Mixamo の `mixamorig:RightHand` / `mixamorig:LeftHand`) |
| Fallback Offset | ボーンが見つからない時に出す位置(プレイヤーの向き基準。X: 右 / Y: 上 / Z: 前) |
| Material | 軌跡のマテリアル。頂点カラーを使うもの(今は Nova の `Glow_Additive`) |
| Color / Width / Trail Time | 軌跡の色・太さ(m)・残る時間(秒) |
| Emit Time | 軌跡を出す時間(秒)。殴るモーションの長さに合わせる |

- **どちらの手で殴るかは、`DB_EffectDataBase` で段ごとに右手用・左手用の Prefab を選んで決めます**(モーションが変わったら Prefab を入れ替える)
- ボーンはプレイヤーの一番上の親から名前で探します。モデルを差し替えてボーンの名前が変わったら Bone Name を直してください

## 新しいアクションにエフェクトを足す

例: アイテムを取った時に、プレイヤーの足元へエフェクトを出す

1. **ID を足す**: `CSE_EffectId` に追加する(**既存の値は変えない**。DBには数値で保存されているため)
   ```csharp
   ItemGet = 500,
   ```
2. **DB に登録する**: `DB_EffectDataBase.asset` の Effect List に1行足し、Id・Prefab・Lifetime を入れる
3. **演出クラスから呼ぶ**: どの画面に出すかで呼び方を変える

| 起きる場所 | 呼び方 |
|:--|:--|
| 全員に同期されている値(NetworkVariable)の変化を見て出す | 各クライアントで `CS_EffectManager.instance.Play(...)`(通信しない) |
| 操作しているクライアントだけで起きるイベント(攻撃など) | `CS_NetworkEffectPlayer` の `PlayForEveryone(...)` |
| サーバーだけで起きるイベント(警察の攻撃など) | `CS_NetworkEffectPlayer` の `PlayForEveryone(...)` |
| 自分の画面だけでよい(UIの近くの演出など) | `CS_EffectManager.instance.Play(...)` |

```csharp
// 自分の画面だけに出す
CS_EffectManager.instance.Play(CSE_EffectId.ItemGet, transform.position, transform.rotation);

// キャラクターに付いていくように出す(一緒に動く)
CS_EffectManager.instance.Play(CSE_EffectId.ItemGet, transform.position, transform.rotation, transform);

// 色を変えて出す(4色のカラーバリエーション用。付いていく先が無ければ null)
CS_EffectManager.instance.Play(CSE_EffectId.ItemGet, transform.position, transform.rotation, null, playerColor);

// 全員の画面に出す(この Prefab に CS_NetworkEffectPlayer を付けておく)
_effectPlayer.PlayForEveryone(CSE_EffectId.ItemGet, transform.position, transform.rotation);

// 全員の画面に、このキャラクターに付いていくように出す(位置・向きはキャラクターから見た値)
_effectPlayer.PlayForEveryoneAttached(CSE_EffectId.ItemGet, Vector3.zero, Quaternion.identity);
```

### `CS_NetworkEffectPlayer` の注意

- **Owner(またはオフライン)からだけ呼べます**。プレイヤーの攻撃のイベントは操作しているクライアント(NPCはホスト)、警察・悪人のイベントはサーバーで起きるので、どちらもそのまま呼べます
- 呼んだ本人はすぐ自分の画面に出し、他の全員には RPC(`SendTo.NotMe`)で送ります。自分のエフェクトが通信で遅れません
- SE の `CS_NetworkSoundPlayer` はシーンに1つ置く形ですが、こちらはキャラクターの Prefab に付けます(付いていく先を送らずに済み、シーンに NetworkObject を置かなくてよいため)
- NetworkVariable の変化を見て出すエフェクトで使うと、全員が送り合って二重に出ます。その場合は `CS_EffectManager` を直接呼んでください

### 仮エフェクトをスクリプトで作る(`IEffectPlayable`)

ParticleSystem や VFX Graph を作らずにコードで動かしたい時は、`IEffectPlayable` を実装した MonoBehaviour を Prefab に付けます(`CS_EffectBoneTrail` が例)。

| メンバー | いつ呼ばれるか |
|:--|:--|
| `Play()` | 出す時。プールで使い回すので、毎回最初の状態(元の色も)に戻す |
| `Stop()` | Lifetime が来た時。新しく出すのをやめる(出ている分は残してよい) |
| `SetColor(Color)` | 色を上書きする時だけ(Play の後に呼ばれる) |
| `isAlive` | false になったらプールに戻す |

## 未確認のこと

- Unity エディタでのコンパイル確認と、実際の見た目・マルチでの表示の確認はまだです
- 段階2(パリー成功・スポーン・リスポーン・悪人の撃破)も、エディタでの確認はまだです
- Player / Police / Villain / VillainBoss の Prefab、MainScene、`DB_EffectDataBase`・`EffectManager`・`FX_PlayerPunchTrailR / L / Finish`は手で書いたので、エディタで開いた時に警告が出ないか見てください
- こぶしの軌跡のマテリアル(Nova の `Glow_Additive`)が TrailRenderer で思った通りに出るかは未確認です。出ない時は Material を差し替えてください
- プレイヤーのボーン名が `mixamorig:RightHand` / `mixamorig:LeftHand` かは未確認です(違う時は Fallback Offset の位置に出ます)
