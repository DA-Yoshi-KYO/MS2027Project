# 📋 概要
悪人グループの巡回パターンを、Fieldプレハブ(またはシーン)のSceneビューで作るエディタ拡張です。
スポーン位置ごとに「どの悪人が、どのポイントを、どう回るか」「ポイントで何をするか」「隊列」を決められます。

- スクリプト: `Assets/Editor/Villain/Patrol/`(エディタ) / `CSO_VillainPatrolPattern`・`CS_VillainPatrolRoute`・`CS_VillainPatrolCrew`(ゲーム中)
- パターンのアセット: `Assets/Programmer/Database/Villain/Patrol/DB_VillainPatrol_○○.asset`

# ✅ 使い方(4手)
## 1. スポーン位置を選ぶ
Hierarchyでスポーン位置(`VillainSpawnPoint_○○`)を選ぶと、Sceneビューに **巡回** のツールバーが出ます。
(出ない時は、Sceneビュー右上の「︙」→ Overlays で「巡回」にチェック)

## 2. 悪人とポイントを置く
1. ツールバーの **悪人を置く** を押して、Sceneビューをクリックします。地面(NavMesh)の上に悪人が置かれ、そこがポイント1(スタート)になります
2. 置くと自動で **ポイントを置く** に切り替わります。クリックした順にポイント2、3…と増えます
3. 別の悪人を置く時は、もう一度 **悪人を置く** を押します

- ボタンが押されていない時は、Sceneビューは普段どおりのUnityの操作です(クリックしても何も置きません)。**Esc** でボタンを外せます
- ツールバーに、今どの悪人にポイントを足しているかが色付きで出ます。**悪人・ポイント・線をクリック** すると、その悪人に切り替わります
- ポイントは **ドラッグで動かせます**。**Ctrl+Z** で戻せます

## 3. ポイントでやることを決める
ポイントを選ぶと、Inspectorの **巡回(CS_VillainPatrolRoute)** に「やること」のリストが出ます。上から順に実行します(ドラッグで並べ替え、−で削除)。

| やること | 設定 | 初期値 |
| :--- | :--- | :--- |
| 停止 | 秒(0〜60) | 2秒 |
| 見回し | 左右の角度(0〜180°)・秒(0.5〜30)。秒数で左右を1往復 | 左右60°を3秒 |
| 向きを変える | 角度(−180〜180°、＋で右回り)。0.5秒かけて回る | 90° |

何も無ければ、止まらずに次のポイントへ向かいます。

悪人ごとに、Inspectorで次を決めます。

| 項目 | 意味 |
| :--- | :--- |
| 回り方 | **周回**: 最後の後にポイント1へ戻る / **往復**: ポイント1まで折り返す |
| 速さ(m/秒) | 巡回の速さ(0.5以上) |
| 最初の向き(°) | 湧いた時の向き。スポーン位置の向きからの角度 |
| 隊列 | 付いてくる人数・形(横一列/縦一列/斜め右/斜め左/V字)・間隔(m) |

## 4. 再生して確かめる
ツールバーの **▶ 再生** で、プレイせずにSceneビュー上で悪人が動きます(■ 停止で止める)。

- 線は、NavMeshで実際に通る道です。**通れない所は赤い線** になります(ポイントを動かして直してください)
- 隊列で付いてくる人は小さな丸で出ます

保存は **シーン(プレハブ)の保存(Ctrl+S)と一緒** です。

# 🔁 パターンの使い回し
- パターンはアセットなので、別のスポーン位置のInspectorで同じパターンを指定すれば使い回せます
- ポイントの位置はスポーン位置からの相対で持ち、スポーン位置の向きで回ります(同じ形のまま、スポーン位置を基準に回る)
- 同じパターンを複数の場所で使っている時は、ツールバーに「○か所で使っています」と出ます。**編集すると全部に反映** されます
- その場所だけ変えたい時は、ツールバーの **複製** で別のアセットにしてから編集します

# 🎮 ゲーム中の動き
- 湧く人数は **パターンの人数(悪人 + 付いてくる人)まで** です。それより多くは湧きません
- 湧いた人は、**悪人(先頭)を全員先に**、次に付いてくる人を悪人1の隊列 → 悪人2の隊列…の順に割り当てます(人数が少ない時は、割り当てられた所まで)
- 先頭はポイント1から、付いてくる人はポイント1の隊列の位置から巡回を始めます
- 付いてくる人は、先頭の向きに合わせて並び、先頭と一緒に止まる・見回します
- 先頭が倒されたら、隊列の次の人が先頭になり、続きから回ります
- 臨戦態勢 → 帰還の後は、ルートの続きから巡回を再開します
- 巡回パターンを置いていないスポーン位置は、今までどおり路地裏の両端を全員で往復します
