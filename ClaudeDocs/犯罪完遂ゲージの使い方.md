# 犯罪完遂ゲージの使い方（`CS_UICrimeGaugeModel`）

犯罪は **悪人グループ単位** で進むので、ゲージも **1グループにつき1本** 出します。
UI側は MVP 構成になっていますが、**使う側が触るのは Model だけ** です。
Presenter / View はゲージのプレハブに最初から付いているので、コードから触る必要はありません。

```
CS_VillainSpawner（サーバー）
   │ 毎フレーム group.crimeProgress（0〜1）を渡す
   ▼
CS_VillainCrimeGauge（スポーン位置に付ける / NetworkVariable で全員に同期）
   │ new / Bind / SetValue
   ▼
CS_UICrimeGaugeModel ──(自動で通知)──▶ Presenter ──▶ View（ゲージ・「75%」表示）
                         ↑ 子のゲージが「親の Transform」で Model を拾う
```

やることはこれだけです。

1. `VillainCrimeGaugeCanvas.prefab` を **各スポーン位置（`CS_VillainSpawnPoint`）の直下** に置く
2. スポーン位置に `NetworkObject` と `CS_VillainCrimeGauge`（下のコード）を付ける
3. `CS_VillainSpawner` から毎フレーム `SetProgress()` を呼ぶ

> ⚠ 現時点（2026-10-04）では、`CS_VillainCrimeGauge` はまだリポジトリにありません。
> 下のコードは、実装するときのお手本です。

---

## なぜスポーン位置に付けるのか

- `CS_VillainGroup` は GameObject ではない普通のクラスなので、ゲージをぶら下げる場所がない
- 1つのスポーン位置には **同時に1グループしかいない**（`isOccupied`）ので、「スポーン位置 = グループ」とみなせる
- 犯罪はスポーン位置で行われるので、その頭上にゲージを出すのが自然
- 悪人は撃退されると消えるが、スポーン位置は消えないので **ゲージが途中で消えない**

## なぜ同期が必要なのか

`CS_VillainGroup` と `crimeProgress` は **サーバーにしかありません**。
そのままクライアントで `crimeProgress` を読むことはできないので、サーバーで `NetworkVariable` に書き込み、全員がそれを読んで `SetValue()` します。

---

## 準備（シーン側）

1. シーン上の各 `CS_VillainSpawnPoint` に `NetworkObject` を追加する（シーン配置の NetworkObject はサーバー起動時に自動で Spawn されます）
2. 同じ GameObject に `CS_VillainCrimeGauge` を追加する
3. `Assets/Programmer/Prefab/UI/InGame/VillainCrimeGaugeCanvas.prefab` を **スポーン位置の直下** に置く
   - **World Space の Canvas** なので、悪人の頭より少し上などの位置に配置してください
   - Presenter はプレハブのルートに付いていて、`transform.parent`（＝スポーン位置）をキーに Model を探します。
     **孫や別の場所に置くと紐づきません**
4. `CS_VillainCrimeGauge` の `_gaugeCanvas` に、置いたゲージをセットする

---

## コード例：`CS_VillainCrimeGauge`（スポーン位置に付ける）

```csharp
using Unity.Netcode;
using UnityEngine;

/// <summary>
/// 悪人グループ1つ分の犯罪完遂ゲージ
/// ・CS_VillainSpawnPoint と同じ GameObject に付ける
/// ・サーバーが SetProgress で書き込み、全クライアントがゲージに反映する
/// </summary>
[RequireComponent(typeof(CS_VillainSpawnPoint))]
public class CS_VillainCrimeGauge : NetworkBehaviour
{
    [SerializeField] private GameObject _gaugeCanvas; // 直下に置いた VillainCrimeGaugeCanvas

    // 書き込みはサーバーのみ
    private readonly NetworkVariable<float> _progress = new NetworkVariable<float>();
    private readonly NetworkVariable<bool> _isVisible = new NetworkVariable<bool>();

    private CS_UICrimeGaugeModel _model;

    private void Awake()
    {
        // ① 最大値 1 で生成（crimeProgress が 0〜1 なので）
        _model = new CS_UICrimeGaugeModel(1f);

        // ② 自分の Transform で Bind → 直下のゲージが勝手に拾って表示する
        _model.Bind(transform);

        Apply();
    }

    public override void OnNetworkSpawn()
    {
        _progress.OnValueChanged += HandleChanged;
        _isVisible.OnValueChanged += HandleChanged;
        Apply(); // 途中参加したクライアントも今の値で表示する
    }

    public override void OnNetworkDespawn()
    {
        _progress.OnValueChanged -= HandleChanged;
        _isVisible.OnValueChanged -= HandleChanged;
    }

    /// <summary>進行度と表示/非表示を設定する（サーバー、またはオフライン）</summary>
    public void SetProgress(float progress, bool isVisible)
    {
        if (IsSpawned && !IsServer) return;

        _progress.Value = progress;
        _isVisible.Value = isVisible;

        // オフラインでは OnValueChanged が呼ばれないので、ここで直接反映する
        if (!IsSpawned) Apply();
    }

    private void HandleChanged<T>(T previous, T current) => Apply();

    // ③ 値をゲージに反映する（全クライアント）
    private void Apply()
    {
        _model.SetValue(_progress.Value);
        if (_gaugeCanvas != null) _gaugeCanvas.SetActive(_isVisible.Value);
    }

    public override void OnDestroy()
    {
        // ④ 後片付け（Bind も自動で外れる）
        _model?.Dispose();
        base.OnDestroy();
    }
}
```

## コード例：`CS_VillainSpawner` 側（サーバーで値を流す）

`Update()` の犯罪を進めているループに1行足すだけです。

```csharp
// 犯罪の進行は毎フレーム行う
foreach (CS_VillainGroup group in _groups)
{
    group.Tick(Time.deltaTime);

    // ★ 追加：グループの進行度をスポーン位置のゲージへ
    if (group.spawnPoint.TryGetComponent(out CS_VillainCrimeGauge gauge))
    {
        gauge.SetProgress(group.crimeProgress, !group.isCrimeCompleted);
    }
}
```

グループがいなくなったら非表示にして0に戻します（`RemoveDeadGroups()` の中）。

```csharp
group.spawnPoint.isOccupied = false;
group.spawnPoint.StartCooldown(_respawnCooldown);

// ★ 追加：ゲージを隠してリセット
if (group.spawnPoint.TryGetComponent(out CS_VillainCrimeGauge gauge))
{
    gauge.SetProgress(0f, false);
}
```

- 犯罪を完遂した瞬間（`isCrimeCompleted`）にゲージは消えます。100% を少し見せたい場合は、`!group.isCrimeCompleted` の代わりに `group.isAlive` を渡すと、逃走のフェードが終わるまで表示されたままになります
- 臨戦態勢中はグループの犯罪が止まるので、ゲージもその値のまま止まります（減りません）
- 毎フレーム `NetworkVariable` に書いても、値が変わったときだけ送信されます

## API 早見表（`CS_UICrimeGaugeModel`）

| メソッド / プロパティ | 説明 |
|---|---|
| `new CS_UICrimeGaugeModel(maxValue)` | 0 から始まる Model を生成。グループ用は `1f` を渡す |
| `new CS_UICrimeGaugeModel(maxValue, currentValue)` | 指定した値から始める |
| `Bind(transform)` | どのゲージの Model か公開する。直下のゲージが自動で紐づく |
| `Unbind()` | 公開をやめる（ゲージの更新が止まる） |
| `SetValue(value)` | 値を設定。0〜最大値に自動で丸められる |
| `AddValue(amount)` | 値を加算する |
| `SetMaxValue(max)` | 最大値を変更。現在値が超えていたら切り詰める |
| `Reset()` | 0 に戻す |
| `IsCompleted` | 最大値に達したか |
| `currentValue.CurrentValue` / `maxValue.CurrentValue` | 現在値・最大値を読む |
| `Dispose()` | 後片付け。Unbind も自動で行う |

- **犯罪が完遂したかの判定は `CS_VillainGroup` が行います。** Model の `IsCompleted` はゲージの表示上の値なので、ゲームの判定には使わないでください
- **Presenter / View のスクリプトは触らなくてOK**（プレハブに付いています）
