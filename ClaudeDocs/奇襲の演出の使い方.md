# 奇襲の演出の使い方

ペルソナ5の奇襲のような緩急をつける演出です。**押した瞬間に溜め → 飛び込みで一気に加速 → 命中で止めて弾けさせる**流れで、溜め(0.5 秒のスローモーション)のあと、飛び込みを速く(秒速 60m)して緩急をつけます(距離 6m で溜め+飛び込み 約 0.6 秒)。
奇襲のロジック(`CS_PlayerAmbush`)は演出のことを知りません。**`CS_PlayerAmbushEffect` を外しても奇襲は動きます**。

```
CS_PlayerAmbush ──イベント──▶ CS_PlayerAmbushEffect(Player に付いている)
  onAmbushWindupStarted(溜め開始)  │
  onAmbushStarted(飛び込み開始)    ├─ 自分の画面だけ ─▶ 画面効果 / 星マーク(UI) / カメラ揺れ / Animator停止
  onAmbushHitTiming(命中の瞬間)    │
  isLunging(飛び込み中)            └─ 全員の画面 ─────▶ CS_NetworkEffectPlayer ─▶ 軌跡 / 残像 / 命中Burst
```

---

## 流れ

| 場面 | いつ | 自分の画面だけ | 全員の画面 |
|:--|:--|:--|:--|
| 1 溜め | 押した瞬間〜0.5秒 | 星マークがパッと出る / 画面効果 `VO_AmbushWindupScreenEffect`(彩度を落としたモノクロ寄り・ビネットを強く。溜めの間だけかけ続ける)/ 自分と対象のAnimatorをスローモーションにする | - |
| 2 飛び込み | 溜め後〜当たる瞬間 | 画面効果 `VO_AmbushLungeScreenEffect`(赤系の集中線・ビネット・周りのぼかし)/ 細かいカメラ揺れ | 体の軌跡 `PlayerAmbushTrail` / 残像 `PlayerAmbushAfterimage` |
| 3 命中 | 当たる瞬間 | 星マークが弾ける / 画面効果 `VO_AmbushHitScreenEffect`(モーションブラー・色収差)/ 大きめのカメラ揺れ / ヒットストップ | 対象の位置に `PlayerAmbushBurst`(衝撃波・火花・星の破片) |

- 自分の画面だけのものは `CS_Player.isLocalPlayer` のプレイヤーでだけ動きます(NPC はホストで動くため、NPC の奇襲でホストの画面が変わらないように)
- `Time.timeScale` は触りません(マルチで全員止まるため)。遅くするのは自分と対象の Animator の速さだけです(溜めはスロー、命中はヒットストップ)
- 溜めが 0 秒の時は `onAmbushWindupStarted` が出ないので、星マークは飛び込み開始で出ます
- 奇襲が当たらずに中止された時は、星マークはすぐ消えます
- 連続奇襲の 2 体目以降は、溜めが短くなります(`_chainWindupRate`)

### グループの最後の1人を奇襲した時(フィニッシュカメラ。`CS_PlayerAmbushFinishCamera`)

悪人のグループの最後の1人を奇襲した時だけ、悪人の向こう側からプレイヤーの全身を映すカメラに切り替えます(奇襲した本人の画面だけ)。

1. 溜めの開始(溜めが 0 秒なら飛び込み開始)で、フィニッシュ用のカメラへ**カット**で切り替える。溜め〜飛び込みの間、カメラは動かさない
2. 命中で大きく揺らす(`_finishHitShakeForce`)。そのカメラのまま **0.25 秒**保つ(ゲームは止めない)
3. **0.25 秒**かけて、なめらか(イーズイン・アウト)にプレイヤー視点のカメラへ戻る

- 「最後の1人」は本人の手元で判定する(通信は足していない)。狙った悪人と同じ `CS_VillainCrime.groupId` で、倒れていない悪人が他にいなければ最後の1人。倒れているかは `CS_VillainHealth`(同期済みの `isDefeated`・`currentHp`)で見る。数えるのは溜めの開始時に 1 回だけ
- `groupId` が -1(グループに属さない悪人)は、`_includeUngrouped` がオンなら最後の1人として扱う
- カメラの位置は、プレイヤー→悪人の水平方向の延長上で悪人の向こう側。悪人からの距離は、**飛び込みで悪人の `_arrivalDistance`(1.2m)手前まで近づいた時(命中の瞬間)に、プレイヤーの全身(当たり判定の高さ × `_bodyMargin`)が画面に収まる距離**を FOV から計算し、`_minBehindDistance`〜`_maxBehindDistance` で挟んで決める(近づいても頭から足まで収まる)。**壁(建物)ではカメラを寄せない**(建物は透過する)。地面より下には行かないよう、カメラの高さを地面の上(`_groundClearance`)に保つ
- **映り込む建物の透過**: 切り替えている間、`CS_PlayerCameraOcclusion.SetExtraTarget` で、カメラ→プレイヤー・カメラ→悪人の線を太め(`_occlusionRadius` 1.0m)に調べて、間をさえぎる Building / Prop を透過する(画面に映る建物をすべて消すことはしない)。切り替えた瞬間から透過して見えるよう、判定にはフィニッシュカメラの位置を直接渡し(実際のカメラは Brain の更新後に動いて 1 フレーム遅れる)、透過の速さは `_extraFadeSpeed`(20)。戻りのブレンドの間は実際のカメラの位置から調べ、戻り終わり・中止・無効化でやめる
- フィニッシュ用の `CinemachineCamera` は、自分のプレイヤーの時だけ、使う時にシーン直下へ作る(プレイヤーの子にしない)。Lens と Impulse Listener はプレイヤーのカメラと同じ設定にする(揺れが乗る)。`Priority` の上げ下げで切り替える
- Brain の `DefaultBlend` は、切り替えの間だけコードで差し替えて元に戻す(切り替え・中止は Cut、戻る時だけイーズイン・アウト)。Prefab の値は書き換えない
- 当たる前に奇襲が中止された・動けなくなった・無効にされた時は、すぐ(カットで)元のカメラへ戻す
- 連続奇襲: 最後の1人の時だけ切り替わる。保つ・戻る間に次の奇襲が始まっても、その悪人が最後の1人でなければそのまま続ける

## 登場するもの

| 名前 | 種類 | 役割 |
|:--|:--|:--|
| `CS_PlayerAmbush`(変更) | MonoBehaviour | 溜め(`Phase.Windup`)と `onAmbushWindupStarted(悪人, 秒)` を追加。サーバーの予約・Freeze の時間にも溜めの分を足す |
| `CS_PlayerAmbushEffect` | MonoBehaviour | 演出をまとめる。Player に付いている |
| `CS_PlayerAmbushFinishCamera` | MonoBehaviour | グループの最後の1人を奇襲した時のカメラ。Player に付いている |
| `CS_PlayerDashScreenEffect`(変更) | MonoBehaviour | 奇襲の飛び込み中の効果を外した(専用の効果に移した)。ハイドの飛びつきはそのまま |
| `CS_EffectAfterimage` | MonoBehaviour(`IEffectPlayable`) | 体の SkinnedMeshRenderer を一定間隔で BakeMesh してその場に置き、薄くして消す仮エフェクト |
| `CS_UIAmbushMarkModel` / `Presenter` / `View` | UI(MVP) | 星マーク。`Script/UI/UI_AmbushMark/`。UI_LockOn と同じ形 |
| `FX_PlayerAmbushTrail` / `Afterimage` / `Burst` | Prefab | `Assets/Programmer/Effect/Placeholder/`。Trail は `CS_EffectBoneTrail` を流用、Burst は Nova の `03_Shockwave`・`04_Sparks` と星の破片 |
| `MT_AmbushStar` / `MT_AmbushAfterimage` | Material | 星の破片用 / 残像用(Nova の Spark_Additive・Glow_Additive を複製) |
| `VO_AmbushWindup / Lunge / HitScreenEffect` | Volume Profile | `Assets/Programmer/Volume/Postprocess/` |
| `AmbushStar.png` | 仮の星画像(白) | `PlaceholderAsset/UI/AmbushMark/`。色は UICanvas の Image で付ける |
| `CSE_EffectId` に 3 つ追加 | enum | `PlayerAmbushTrail = 214` / `PlayerAmbushAfterimage` / `PlayerAmbushBurst`。`DB_EffectDataBase` に登録済み |

本番の素材ができたら、**`DB_EffectDataBase` の Prefab・星の画像・Volume Profile を差し替えるだけ**で入れ替わります(エフェクトの仕組みは `エフェクトの使い方.md`)。

## 注意

- 星マークは UICanvas に `AmbushMark` が無いシーンでは出ません(ほかの演出は出ます)
- 星マークの Model は、最初に溜めが始まった時に作って Bind します(`SetLocalPlayerNumber` を先に呼ぶ。ロックオンと同じ)
- 残像はシーン直下の `AmbushAfterimages` に置きます(プレイヤーが動いてもその場に残すため)。マテリアルは Nova の UberUnlit(`_TintColor` で色と薄さを決める)
- 時間(溜め・ヒットストップ・画面効果・星のアニメ)は `Time.timeScale` の影響を受けない時間で数えます。軌跡・残像・Burst は `timeScale` の影響を受けます(エフェクトの仕組みと同じ)
- 飛び込みが速くなったので、`CS_PlayerAmbush.UpdateDash` で、飛び込みの 1 回の時間を物理の 1 ステップ(0.02 秒)より少し長くしています。`CS_Player.Lunge` は残り時間が 1 ステップ以下だと 1 歩も進まず、最後の短い距離で止まって `_maxDashTime`(1 秒)まで待ってしまうためです(速いほど起きやすい)
- 溜めの秒数は、サーバーの予約・悪人を止める時間にも足されます(RPC で送り、サーバー側の `_windupTime` を上限にする)

## 未確認のこと

- フィニッシュカメラは、MainScene(Solo)で、悪人を `groupId` -1 にして背後6mから奇襲させて確かめました。カットで切り替わる → 命中で保つ → 0.25 秒のブレンドで戻る → 元に戻る、の流れと、命中の瞬間にプレイヤーの全身が画面に収まること(頭から足まで縦の約 42%)は確認済みです。揺れの強さ・建物の透過・地面・壁際・グループの悪人が複数いる時の判定の見た目は未確認です
- フィニッシュカメラで、`CS_PlayerCameraOcclusion`(建物の透過)・ロックオンUI・星マークが切り替え中も正しく出るかは、コードを読んだ範囲では問題ありませんが、Play では未確認です
- 奇襲の巻き込み(`_splashRadius`)で一緒に倒れる悪人は、「最後の1人」の判定で数えません(今いるものは「生きている」として数える)。巻き込みで最後の2人が倒れる時は、フィニッシュカメラにならないことがあります

- 飛び込み 60m/秒で、壁際・段差・高さが違う悪人でも止まらず着くか、細い壁をすり抜けないか(今は壁越しの奇襲自体ができない条件のため大丈夫なはずだが、Play では見ていない)
- 実際に奇襲を出した時の見た目(溜め・集中線・残像・軌跡・Burst・星マーク・ヒットストップの手応え)は未確認です。Play でコンパイルエラー・例外が出ないことまでしか見ていません
- マルチ(他のプレイヤーの画面に軌跡・残像・Burst が出ること、NPC の奇襲でホストの画面が変わらないこと)は未確認です
- 溜めを足したことで、通信越しの奇襲(サーバーの予約・Freeze・ヒット判定)が今まで通り成功するかは未確認です
- 軌跡のボーン名 `mixamorig:Hips` が Player のモデルにあるかは未確認です(無い時は足元から 1m の位置を追います)
- 残像の Nova マテリアル(`_TintColor`)が MeshRenderer で思った通りの色・薄さで出るか、星の破片のマテリアルが出るかは未確認です。出ない時は `MT_AmbushAfterimage` / `MT_AmbushStar` を差し替えてください
- ヒットストップ中に対象の Animator を止めても、死亡モーション・吹き飛びが不自然にならないかは未確認です
- Player.prefab / UICanvas.prefab / `DB_EffectDataBase` は Unity のエディタスクリプトで組み込みました。Player.prefab には、組み込み時に保存し直されて他の既存項目の値(`_airControlAccel` など、既定値)も一緒に出ています
