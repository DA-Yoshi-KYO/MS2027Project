# 📋 概要
Confluenceの[データ表](https://summervacationgamejam.atlassian.net/wiki/spaces/20272/pages/21004355)と、プロジェクト内のステータス(ScriptableObjectやプレハブの値)を比べて、**違う所だけ**反映するエディタ拡張です。
企画が数値を変えた時に、どのアセットのどの項目を直せばいいか探さなくて済むようにするためのものです。

- 開き方：`Tools > 仕様データ同期`
- スクリプト：`Assets/Editor/SpecSync/`
- 対応表：`Assets/Editor/SpecSync/SpecSyncMapping.json`

# ✅ 使い方
## 1. データ表を読み込む
どちらかの方法で読み込みます。

**A. Confluenceから直接取得する(おすすめ)**
1. [APIトークンの作成ページ](https://id.atlassian.com/manage-profile/security/api-tokens)でトークンを作る
2. ウィンドウにAtlassianのメールアドレスとトークンを入れる(各自のPCのEditorPrefsに保存され、リポジトリには入りません)
3. `取得して比較` を押す

**B. 貼り付けで読み込む(トークンを使わない場合)**
1. ブラウザでデータ表のページを、見出しも含めて選んでコピーする
2. `貼り付けで読み込む` を開いて貼り付け、`貼り付けて比較` を押す

## 2. 差分を確認して適用する
| 表示 | 意味 |
| :--- | :--- |
| チェックボックス付き | 仕様とアセットの値が違う項目。`今の値 → 仕様の値` と書き込み先が出ます |
| 未対応 | 対応表に書かれていない列・行。必要なら対応表に追加してください |
| 同期しない | 対応表で、わざと同期しないと決めている列(理由も表示) |
| エラー | 表やアセット、項目が見つからない |

反映したい項目にチェックを入れて `選んだ○件を適用` を押すと、アセットに書き込まれます。
書き込み後はCtrl+Zで戻せます。**適用したアセットはいつも通りコミットしてください。**

# 🛠 対応表(SpecSyncMapping.json)の書き方
データ表に列や表が増えた時は、ここに1行足すだけで同期対象にできます。

| キー | 書く場所 | 意味 |
| :--- | :--- | :--- |
| `_heading` | 表 | 表の直前の見出し(例: `悪人データ`) |
| `_assetPath` | 表・行・列 | 書き込み先のアセット。列 → 行 → 表の順に、書いてある所が使われる |
| `_component` | 表・行・列 | 書き込み先がプレハブの場合、そのコンポーネント名(例: `CS_PlayerTransformation`) |
| `_arrayProperty` | 表 | 行を配列の要素に入れる場合の配列名。上の行から順に0番目,1番目...に入る |
| `_rowKey` | 行 | 1列目の値(例: `A`) |
| `_column` | 列 | 見出し行の文字。空白・全角半角・太字の違いは無視して比べる |
| `_property` | 列 | 書き込む変数名(例: `_maxHp`)。空にすると同期しない |
| `_scale` | 列 | `アセットの値 = 仕様の数値 × _scale`。倍率で書かれた移動速度や「○分」→秒の変換に使う |
| `_note` | 列 | 同期しない理由など |

セルの値は**最初に出てくる数値**を読みます(`10秒`→10、`×0.6`→0.6、`３m`→3)。数値が無いセル(`ー(不死)`など)は読み飛ばします。

# 📝 今の対応状況
| 表 | 書き込み先 | 備考 |
| :--- | :--- | :--- |
| プレイヤーデータ | `DB_PlayerStats` / `Player.prefab`の`CS_PlayerTransformation`(信号間隔) | 移動速度・ダッシュ・ジャンプは倍率×5で換算 |
| 悪人データ | `DB_VillainStatsA` / `B` | 撃破スコアは悪人側に項目がまだ無いので同期しない |
| 警察データ | `DB_PoliceA` / `B` | 攻撃力は一撃で倒すため10000以上で固定なので同期しない |
| 手配度データ | `DB_PoliceWantedLevel` | |
| 悪人の時間経過による変化データ | `DB_VillainTimeScaling` | 時間の列は「○分」×60で開始秒数に換算 |
