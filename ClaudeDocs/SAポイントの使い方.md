# 📋 概要
SA(ステルスアクション)で飛んで行ける場所(SAポイント)の作り方・置き方です。
SAポイントの共通部分は `CS_SAPoint`(基底クラス)にあり、種類ごとにこれを継承して作ります。

| 種類 | クラス | 内容 |
|:--|:--|:--|
| ハイドポイント | `CS_HidePoint` | 物陰・高所など。飛んで来た後、隠れられる箱(HideBox)の中にいる間は隠れている扱い |
| 信号機 | `CS_TrafficLightSAPoint` | 信号機の上など。飛ぶだけ(隠れている扱いにはならない) |
| グラップル | `CS_GrappleSAPoint` | ロープで的へ引っ張られる(鳴潮の鉤縄が参考)。飛び始めの距離の5割(既定)まで引っ張られるか、着いたら、早い方で自動で放して、勢いを残したまま自由落下する(着地はさせない)。飛ぶだけ(隠れている扱いにはならない) |

# ✍️ 置き方(共通)
プレハブをフィールドに置くだけです。置いた物の子に、次の空オブジェクトがあります。

| 子オブジェクト | 役割 |
|:--|:--|
| `StandPoint` | 着く位置と向き。着いた時の足元の位置(高さ込み)に置く |
| `SAReachBox` | SAできる範囲の箱。プレイヤーの足元がこの箱の中にある時だけSAでき、強調UIも出る。位置・回転・Scale(x: 幅, y: 高さ, z: 奥行 m)をそのまま箱にする |
| `HideBox`(ハイドポイントのみ) | 隠れられる箱 |

* SAできる範囲(SAReachBox)は、置いた物ごとに調整できます。シーンビューでSAポイントか子を選ぶと、箱が黄色の枠で見えます。
* 強調UIは、既存のハイドマーカーUI(`CS_PlayerHideMarkerUI`)をそのまま使います。種類ごとにUIは足しません。

# 🚦 信号機のプレハブ
`Assets/Programmer/Prefab/Field/FieldElement/TrafficLight/TrafficLight.prefab`
Cubeで作った仮の見た目です(柱 + 頭)。モデルができたら、`Pole`・`Head` を差し替えてください(`StandPoint` は頭の上、高さ8m)。

# 🪝 グラップル
`Assets/Programmer/Prefab/Field/FieldElement/GrapplePoint/GrapplePoint.prefab`
Cubeで作った仮の的です。操作はSAと同じで、飛べる時にダッシュボタンを押すとロープが飛び、的へ引っ張られます(スイング・ぶら下がりはありません)。

| 項目 | 内容 |
|:--|:--|
| `Target`(子) | 的。ロープの先になる(`_ropeEndPoint`) |
| `StandPoint`(子) | 引っ張られる先の位置。的の少し手前(既定は的から手前2m・下1m)に置く。着地はさせず、ここに着いた時点で放す |
| `SAReachBox`(子) | SAできる範囲。遠くから狙えるよう広めにしている(既定は 40×30×30) |

* 動き
  * 一定の速さで的(StandPoint)へ引っ張られる。放すボタンは無い(ジャンプボタンでは途中でやめられる。SA共通)
  * 飛び始めの距離の`_releaseDistanceRate`(既定0.5 = 5割)まで引っ張られるか、`StandPoint`に着いたら、早い方で自動でロープを放す(着いた時も、5割で放した時と同じ挙動)。放した後は飛んでいない。通常の状態に戻って自由落下する(位置は合わせない)。放した瞬間の速度(向き・高さ込み)をそのまま残す。水平の勢いは着地するまで続く(`CS_Player.EndSAMotion`)。入力がある間は、水平の速度が入力の移動速度へ加速度`_airControlAccel`(`CS_Player`。既定25m/秒²)で近づくので、空中で曲げられる(逆向きに押せば約1秒で止まる)。入力が無い間は勢いがそのまま続く(`_airDrag`を上げると弱まる。既定0)。着地・ダッシュ・倒れる・スタンで勢いは消える
  * 信号機・ハイドポイントは今まで通り、着いたら位置を合わせて速度を0にして、普通の状態に戻る(歩ける・ジャンプできる・重力あり)
  * SAで飛んでいる間の速度は、`Fly`/`Lunge`の残り時間とは別の、SA専用の速度(`CS_Player.SetSAVelocity`)で動かす。終わる時は`CS_Player.EndSAMotion(終わった時の速度)`で、専用の速度をクリアすると同時にその速度を通常の状態に渡す(着いた時は0、放した時は放した瞬間の速度)
  * 飛び始めの瞬間に重力と当たり判定を切って、すぐ動き出す。放した直後の約0.1秒(`CS_PlayerHide`の`_releaseGhostTime`)だけ当たり判定を切ったままにして、近くの物の角に引っかからないようにする(上向きに進んでいる時だけ・着く位置を通り過ぎない範囲だけ。壁抜け・床抜けはしない)
* ポイントごとに調整できる値(`CS_GrappleSAPoint`)
  * `_pullSpeed`: 引っ張られる速さ(m/秒。既定35。ふつうのSAは`CS_PlayerHide`の`_flySpeed`)
  * `_releaseDistanceRate`: 飛び始めの距離のこの割合まで引っ張られるか、着いたら放す(0.05〜1。既定0.5。1にすると着いた時に放す)
* 的(`Target`)には当たり判定を付けません(ロープの先を示すだけ)。
* ロープの表示は、プレイヤーに付ける `CS_PlayerGrappleRope` が行います(グラップルのポイントへ飛ぶ間だけ。仮の線)。**今は SATest の Player にだけ付けています。Player.prefab には付いていません**
* 飛ぶのは本人の手元だけなので、ロープも本人の画面にだけ出ます。

# 🆕 新しい種類を足す時
1. `CS_SAPoint` を継承したクラスを作る(`CS_TrafficLightSAPoint` が最小の例)。
2. 隠れられる箱を持たせたい時だけ、`hasHideBox`・`Contains`・`GetHideBoxPoint` を上書きする(`CS_HidePoint` を参照)。
3. プレハブを作り、`StandPoint` と `SAReachBox` を子に置いて、スクリプトに割り当てる。
`CS_PlayerHide`・ハイドマーカーUIは、`CS_SAPoint` の一覧を見ているため、変更は要りません。

* `GrapplePoint_2`(近い的。右へ8m・前へ4m・高さ8m): 5割で放す(遠い的と同じ挙動)
* 的は、ビル(`Building_1`・`Building_2`)や柱に重ならない位置に置いています

(新しい種類を足す時に、飛ぶ速さや放し方を変えたい場合は、`CS_SAPoint` の `pullSpeed`・`releaseDistanceRate` を上書きします。`CS_GrappleSAPoint` を参照)
