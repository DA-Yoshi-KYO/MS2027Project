# スキャンの強調表示の使い方（`CS_PlayerScanHighlight` / `SH_ScanHighlight`）

スキャン（`CS_PlayerScan`）で「見えている」悪人・警察・巡回ドローンのモデルを、次のように強調する仕組みです。

| 時間 | 壁などに隠れている部分 | 画面に映っている部分 |
|---|---|---|
| 見え始めてから `Flash Frames`（既定10フレーム） | 縁が光る半透明のシルエット | 同じシルエット（透過の見た目） |
| それ以降（見える時間が終わるまで） | 縁が光る半透明のシルエット | **アウトライン**（形の外側にだけ線。内側は元のモデルのまま） |

```
CS_PlayerScan（見えている悪人グループ・警察・ドローンの一覧を持つ）
        │ 毎フレーム読むだけ（CS_PlayerScanはこのクラスを知らない）
        ▼
CS_PlayerScanHighlight（Player.prefabに付いている。自分のプレイヤーだけ動く）
        │ 見えている相手の Renderer とマテリアルを、毎フレーム渡す（元のモデルのマテリアルは触らない）
        ▼
CS_ScanHighlightPass（HDRPのカスタムパス。渡された Renderer を全サブメッシュ分、見え始めてからの経過に合わせたパスで描き直す）
        ▼
SH_ScanHighlight（パス0: 隠れている部分のシルエット / パス1: どこでも描くシルエット / パス2: アウトライン用に映っている部分の形をマスクの画像へ描く / パス3: マスクの外側に線を重ねる）
```

3Dモデルの見た目の処理でUIではないため、MVPにはしていません（波の輪の `CS_PlayerScanEffect` と同じ扱い）。
目印のUIは今まで通り `CS_UIScanMarker*`（MVP）が出します。

---

## 描き直しの動き

- 描き直すのは、相手の下の **MeshRenderer / SkinnedMeshRenderer だけ**です（LineRenderer・パーティクル・UIには触りません）
- 相手のマテリアルは差し替えません。元のモデルの上に、強調が重なります
- 次の時は描き直しをやめます
  - 見える時間（`CS_PlayerScan._revealDuration`）が過ぎた
  - 倒された・消えた
  - `CS_PlayerScanHighlight` が無効になった
- アウトライン用のマスクの画像は、カスタムパスが自分で作って、使い終わると解放します
- 描き直すための `CustomPassVolume`（全体適用）は、`CS_PlayerScanHighlight` が自分のプレイヤーで動き始めた時に実行時に作り、無効になった時に消します。シーン・プレハブには置きません
- 悪人・警察・ドローンのプレハブは変更していません
- 自分のプレイヤーの画面だけの演出です。通信はしません

## マテリアル

| 相手 | マテリアル | 仮の色 |
|---|---|---|
| 悪人 | `MT_ScanHighlightVillain` | 赤 |
| 警察 | `MT_ScanHighlightPolice` | 青 |
| 巡回ドローン | `MT_ScanHighlightDrone` | 青 |

色・濃さを変えたい時は、**マテリアル**を触ってください（`Assets/Programmer/Material/`）。警察とドローンは今は同じ青ですが、分けられるようにマテリアルを別にしてあります。

| プロパティ | 内容 |
|---|---|
| `_ScanColor`（HDR） | 色。明るさ（Intensity）で縁の光り方も変わる |
| `_FillAlpha` | 内側の濃さ（0 = 透明、既定 0.15） |
| `_RimAlpha` | 縁の濃さ（既定 0.9） |
| `_RimPower` | 大きいほど縁が細くなる（既定 2.5） |
| `_OutlinePixels` | アウトラインの太さ（ピクセル。既定 3） |
| `_OutlineAlpha` | アウトラインの濃さ（既定 1） |
| `_HiddenMargin` | 手前の物がこの距離（m。既定 0.1）以上手前にあれば「隠れている」としてシルエットを出す |
| `_OutlineMargin` | 手前の物がこの距離（m。既定 0.05）以上手前にあれば、アウトラインを出さない |

アウトラインの色は `_ScanColor` の色味です（HDRの明るさは使わないので、光りません）。

## Player.prefab の設定

`CS_PlayerScanHighlight` の3つのマテリアル欄に、上の3つを入れてあります（空欄の種類は描き直しません）。シルエットを全体に出すフレーム数は `Flash Frames`（既定10）で変えられます。

## 注意

- シェーダーは元のマテリアルの `_BaseColor` などを使わないので、他のスクリプトの MaterialPropertyBlock（悪人の犯罪演出、警察のパトランプなど）とはぶつかりません
- 隠れているかどうかは、カメラの深度テクスチャを読んで決めます。手前の物が深度を書かない半透明の物（ガラスなど）の場合は、隠れている扱いになりません
- 相手自身の体の別の部分が手前にある時（腕が胴の後ろに回った時など）は、その部分が隠れている扱いになり、シルエットが出ることがあります
- アウトラインは、モデルを膨らませずに、画面上で形の外側へ足しています（角ばったモデルでも均一な太さになります）。画面の解像度が変わると、線の見た目の太さも変わります
- 強調表示をやめたい時は、Player.prefab から `CS_PlayerScanHighlight` を外すだけです（スキャンは今まで通り動きます）
