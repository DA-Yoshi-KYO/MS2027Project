# ✅ コーディングルール一覧
## **`重要度：⭐⭐⭐`**  
**`重要度：⭐⭐⭐`**  
- **各変数にはローワーキャメルケース(lowerCamelCase) を採用します。**  
各単語の頭文字を小文字にし、単語の区切りの頭文字を大文字するものです。([参考サイト](https://qiita.com/shota0616/items/4ac7a8696b3f6ccbe2bc))  
private変数、protected変数の場合は頭にアンダーバー(_)を付け、公開する時は式形式メンバー(=>)を使いバッキングフィールドを実装してください。  
変数に対して複雑な処理を行う時は別にメソッドを用意しましょう。  
```c#
private CS_PlayerMove _playerMove;  // 基本はローワーキャメルケース
private float _playerHP;  // private変数、protected変数の場合_を付ける
protected float _HPValue;  // private変数、protected変数の場合_を付ける
// 公開する場合のパターン
public float playerHP=>_playerHP; // getのみ
public float playerHP  // get,set
{
   get =>_playerHP;
   set => playerHP = value;
   // set => playerHP = Mathf.Clamp(value, 0f, 100f); // 制限をかける事も出来る
}
public void TakeDamage(float damage) // 複雑な処理の場合はメソッドで
{
   _playerHP -= damage;
   if (_playerHP <= 0f) Destroy(gameObject);
}
```

**`重要度：⭐⭐⭐`**  
- **ファイル名には接頭辞を付けましょう**  

| ファイルの種類 | 接頭辞 |
|:---| :--- |
| 継承なしのcs、MonoBehaviour継承のcs | CS_xxx |
| ScriptableObject継承のcs | CSO_xxx |
| VolumeComponent継承のcs | CSV_xxx |
| Editor用のcs | CSED_xxx |
| Enum用のcs | CSE_xxx |
| Material | MT_xxx |
| MaterialVariant | MTV_xxx |
| ScriptableObject | DB_xxx |
| HLSL | (X)S_xxx(Xにはシェーダの種類の頭文字を入れるように) |
| Shader | SH_xxx |
| ShaderGraph | SHG_xxx |
| その他(Prefab,Sceneなど) | ObjectA(アッパーキャメル) |

**`重要度：⭐⭐⭐`**  
- **Findの必要性を検討**  
GameObject.Find()は重い処理です。
Startのみにする、作成時に通知イベントを走らせる等、せめて毎フレーム行われないような処理を検討してください。

## **`重要度：⭐⭐　`**  
**`重要度：⭐⭐　`**  
- **AIコードについて** -
AI生成コードは、何故動くのか・何故そうしたのかを自分でしっかり説明できるようにしましょう。  
また、レビューも自分で行い、フローをコメントで分かりやすくしましょう。

**`重要度：⭐⭐　`**  
- **コメントアウトは簡潔に分かりやすく**  
何をするか、何のために使うかを簡潔に書きましょう。  

**`重要度：⭐⭐　`**  
- **Debug.Logの必要性を検討**  
毎フレーム呼び出されるようなLogはpush前に削除してください。

## **`重要度：⭐　　`**  
**`重要度：⭐　　`**  
- **クラス・メソッド内のコード量、ネストの量は法外な値にならないように**  
スパゲッティコードになるのは避けましょう。  
なるべく責任に応じて関数化すること、早期のreturnを心掛けてください。  
目安はクラス内に800行まで、メソッドには80行まで、ネストは3重までです。
