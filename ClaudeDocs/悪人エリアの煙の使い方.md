# 悪人エリアの煙の使い方（`CS_VillainAreaSmoke` / `VEG_VillainAreaSmoke.vfx`）

悪人の出現点から路地裏の入口まで、紫の瘴気を地面に這わせて流す仕組みです。瘴気は出現点のまわりで生まれ、路地の幅いっぱいに広がりながら一定の速さで入口まで流れ、入口で薄れて消えます。
その出現点に悪人グループがいる間だけ瘴気が出て、グループがいなくなると自然に消えます。
仕様: Confluence「フィールド > 悪人エリアの処理」

> **今は非表示です。** `VillainSpawnPoint.prefab` の子の `VillainAreaSmoke` を Active = false にしてあるので、悪人が湧いても瘴気は出ません。
> 見た目の値を調整したら、`VillainSpawnPoint.prefab` を開いて子の `VillainAreaSmoke` を Active = true にしてください（全部の出現点で出るようになります）。

```
Field.prefab
  └ VillainSpawnPoint_xx（VillainSpawnPoint.prefab）… CS_VillainAreaSmoke が瘴気を出す・止める。この位置が瘴気の出始め。入口の幅もここ
      └ VillainAreaSmoke（VisualEffect 1つ）… この Transform が路地裏の入口の位置と向き（赤い矢印の X 方向が入口の幅、青い矢印の Z 方向が大通り側）
```

- 瘴気を出す・止めるのは `CS_VillainSpawner`（サーバー）で、`NetworkVariable` で全クライアントに同期します
- VFX は `Assets/Programmer/Effect/VEG_VillainAreaSmoke.vfx` です
- 出現点から入口までの道は、ゲーム開始時に NavMesh で求めます（見つからなければ真っすぐ）。道の高さは地面に合わせ、路地の左右の壁までの幅も測ります

---

## 1. 手で置く

1. `Field.prefab` を開き、出現点（`VillainSpawnPoint_xx`）の子の `VillainAreaSmoke` を選ぶ
2. Scene ビューで **移動ツール** で路地裏の入口に、**回転ツール** で向きを変える（青い矢印の Z 方向を大通りの方へ向ける）
3. 親の出現点の **CS_VillainAreaSmoke** で Width・Height を変える

| 項目 | 意味 |
|---|---|
| Width | 入口の幅（m）。瘴気が横に広がる最大の幅（道の線から左右それぞれ Width の半分まで）。路地の幅はゲーム開始時に測るので、路地より広めでよい |
| Height | 入口の手前で瘴気が立ち上る高さ（m） |

- 瘴気の出始めは出現点（親）の位置です。出現点の位置を変えると、流れ始める場所も変わります
- 親の出現点を選択すると、Scene ビューに入口の幅と、出現点から入口への線が紫で表示されます（Play 中は求めた道も表示されます）
- 変更は `Field.prefab` に保存します。シーン上で動かしただけだと、シーンの上書きになります
- **VillainSpawnPoint.prefab に Apply しない** でください（全部の出現点が同じ場所になります）
- Y 軸だけ回してください

---

## 2. 全部の出現点の見た目を変える

`VEG_VillainAreaSmoke.vfx` を開き、Blackboard の値を変えます。

| 変えたいもの | パラメータ |
|---|---|
| 流れる速さ | Flow Speed（m/秒） |
| 流れている間の高さ | Flow Height（m。地面からこの高さまでに広がる） |
| 流れている間の粒の大きさ | Flow Particle Scale（倍率。入口に近づくと 1 に戻る） |
| 量 | Density（1 で生きている粒が約4500。重い時は下げる） |
| 出始めの円の大きさ | Spawn Radius（出現点の Group Radius が大きければそちらを使う） |
| 入口の手前で立ち上り始める距離 | Wall Blend（m） |
| 入口の前後の広がり | Depth（m）、Depth Fade |
| 入口の上の消え始める高さ | Top Fade |
| 明るさ | Glow |
| 脈動 | Pulse Speed（速さ）、Pulse Amount（強さ。0 で脈動なし） |
| 粒の大きさ（全体） | Size Over Life |

揺らぎは、Update にある **Turbulence** ブロックの Intensity で変えます。
粒が生まれる位置は Initialize の **Flow Spawn**、道に沿った流れは Update の **Flow Along Path**、発光・濃さ・入口での消え方は Output の **Glow Pulse**（どれも Custom HLSL）で決めています。

> Path Texture・Path Count・Path Length・Spawn Rate・Width・Height・Bounds は、ゲーム開始時に CS_VillainAreaSmoke が出現点ごとに上書きするので、VFX の値を変えても効きません。
> 量は Spawn Rate ではなく **Density** で変えます（道の長さと速さから、生きている粒が約4500 × Density になるように Spawn Rate を決めています）。
> 濃さは Color Over Life のアルファではなく、Glow Pulse の中で決めています（粒が入口まで流れ切るまで生きるので、寿命の割合で薄くすると道の途中から薄くなるため）。

カメラに映っていない間も瘴気が動くように、VFX の Culling Flags は「常に動かす」にしてあります（見た瞬間に瘴気が無い状態を防ぐため）。

---

## 3. エディタで確認する

道と路地の幅はゲーム開始時に求めるので、エディタ（Play していない時）では正しい形で表示されません。確認は Play で行います。
Scene ビューで見る時は、ライティングをオンにして、Always Refresh もオンにしてください（オフだと VFX が描画・更新されません）。

---

## 4. 瘴気が出ない時の確認

| 確認すること | 場所 |
|---|---|
| 子の `VillainAreaSmoke` が Active = true か（今は非表示にしてある） | VillainSpawnPoint.prefab |
| 出現点に `CS_VillainAreaSmoke` が付いていて、Smoke が設定されているか | 出現点の Inspector |
| その出現点に悪人グループがいるか（いない時は出ないのが正しい） | プレイ中のゲージの表示など |
| 入口（子の VillainAreaSmoke）が路地裏の入口に置いてあるか。出現点と入口の間に NavMesh があるか | 出現点を選択して Scene ビューで確認 |
| 路地の幅が狭く測られていないか（左右の建物のコライダー・NavMesh の端までを測る） | Play 中に出現点を選択すると道が表示される |
