# スコア・リザルトの修正ポイント

スコア UI と、MainScene → ResultScene へのスコアの受け渡しまわり（元浪さんの担当箇所）で、直すべきところのまとめです。
（2026-10-04 時点のコードを見て作成）

| # | 内容 | 優先度 |
|---|---|---|
| 1 | スコア UI が表示されない | 必須 |
| 2 | リザルトデータを1つのクラスにまとめる（順位・称号を含む） | 必須 |
| 3 | タイマー終了後、毎フレームシーン移動している | 必須 |
| 4 | リザルトに本物のスコアを渡す口がない | 必須 |
| 5 | 同点の順位 | 要相談 |
| 6 | シーン移動のネットワーク同期 | 要相談 |

## 1. スコア UI が表示されない【必須】

**対象**：`CS_UIScorePresenter.cs` / `CS_UIScoreView.cs`

### 問題

`OnEnable` で Model が見つからないと、`gameObject.SetActive(false)` で自分を無効化します。
無効化すると `OnDisable` で `OnBound` の購読も外れるので、**あとから Bind されても表示されません**。

ネットワークでは、プレイヤー（＝ Model を Bind する側）は UI より後に Spawn するので、ほぼ確実にこの状態になります。

### 直し方

`CS_UIPlayerHpPresenter` と同じく、**GameObject は有効のまま、見た目だけ隠す**。

- `CS_UIScoreView` に `CanvasGroup` と `SetVisible(bool)` を追加
- `CS_UIScorePresenter` の `gameObject.SetActive(...)` を、すべて `_view.SetVisible(...)` に置き換え

## 2. リザルトデータを1つのクラスにまとめる（順位・称号を含む）【必須】

**対象**：`CS_UIResultModel.cs`（`ResultData` / `PlayerResultData` / `CalcTotalScore`）、`CS_UIResultView.cs`、`CS_UIPlayerResultItemView.cs`、`CS_ResultController.cs`

### 問題

- **同じ項目のクラスが2つある**
  - `ResultData`（名前＋4項目）と `PlayerResultData`（名前＋4項目＋合計点・順位・称号）が、同じ5項目を別々に定義している
  - ソロではどちらも使わず、Model の ReactiveProperty 7個にばらして持っている → 同じデータが3通りの形で扱われている
- **合計点の計算がリザルト画面の Model の中にあって `private`**
  - ゲーム中のスコア表示から同じ計算を使えない（MainScene には `CS_UIResultModel` がない）
- **1項目の点数（100 / −50 / −80 / +50）が3か所に直接書かれている**
  - `CalcTotalScore`、`CS_UIResultView`、`CS_UIPlayerResultItemView`
  - 計算を変えると、「(+500点)」の表示と合計点が合わなくなる
- **称号を変えても画面が更新されない（バグ）**
  - `SetPlayerTitle` は、同じリストを `_playerResults.Value = list` で入れ直しているだけ
  - R3 は同じ値だと通知しないので、View に届かない

### 直し方

リザルトデータ用のクラス `CS_ResultData` を **1つだけ** 作る（Model とは別ファイル `CS_ResultData.cs`）。
**Player が番号と一緒に `new` して持ち、ゲーム中の UI とリザルトに渡す** 前提です。

- 中に同期用の struct `Score`（4つの数）を持つ。Player はこれを `NetworkVariable` で同期する
- 点数の定数と合計点（`totalScore`）の計算は `CS_ResultData` だけに書く
- 称号（`title`）も `CS_ResultData` が持つ → `SetPlayerTitle` は不要になる（上のバグも消える）
- 順位は Model が `totalScore` で並び替えたリストの「何番目か」で出す（どこかに保存しなくてよい）

```csharp
using Unity.Netcode;
using UnityEngine;

/// <summary>
/// プレイヤー1人分のリザルトデータ
/// ・Player が番号と一緒に new して持つ
/// ・4つの数(Score)は Player 側の NetworkVariable で同期し、届くたびに SetScore で入れ直す
/// </summary>
public class CS_ResultData
{
    // ---- 1項目あたりの点数（ここだけを見る） ----
    public const int DefeatVillainPoint  = 100;
    public const int FoundByPolicePoint  = -50;
    public const int CrimeCompletedPoint = -80;
    public const int DefeatPlayerPoint   = 50;

    // ---- 同期する4つの数 ----
    public struct Score : INetworkSerializable
    {
        public int defeatVillainCount;
        public int foundByPoliceCount;
        public int crimeCompletedCount;
        public int defeatPlayerCount;

        public void NetworkSerialize<T>(BufferSerializer<T> serializer) where T : IReaderWriter
        {
            serializer.SerializeValue(ref defeatVillainCount);
            serializer.SerializeValue(ref foundByPoliceCount);
            serializer.SerializeValue(ref crimeCompletedCount);
            serializer.SerializeValue(ref defeatPlayerCount);
        }
    }

    // ---- データ ----
    public int playerNumber { get; }
    public Score score { get; private set; }
    public string title { get; private set; } = "---";

    // 合計点（計算はここだけ）
    public int totalScore => Mathf.Max(0,
          score.defeatVillainCount  * DefeatVillainPoint
        + score.foundByPoliceCount  * FoundByPolicePoint
        + score.crimeCompletedCount * CrimeCompletedPoint
        + score.defeatPlayerCount   * DefeatPlayerPoint);

    public CS_ResultData(int playerNumber)
    {
        this.playerNumber = playerNumber;
    }

    public void SetScore(Score score) => this.score = score;
    public void SetTitle(string title) => this.title = title;
}
```

### NetworkVariable 同期について（Player 側の注意）

- 同期されるのは `NetworkVariable<CS_ResultData.Score>` の **4つの数だけ**。`CS_ResultData` 自体は同期されない
  → 各クライアントは、値が届いたとき（`OnValueChanged`）に自分の `CS_ResultData` へ `SetScore(current)` で入れ直す
- 書き込めるのは **サーバーだけ**
- struct は `_score.Value.defeatVillainCount++` のように直接書き換えても **同期されない**。
  「取り出す → 変える → `_score.Value = s` で入れ直す」で書く
- 途中で Spawn したプレイヤーも、最初に `_score.Value`（同期済みの値）を入れておけば 0 から始まらない
- 称号（`title`）は同期しない（リザルトで決める）

### 変更後

| 消すもの | 代わり |
|---|---|
| `ResultData` / `PlayerResultData` | `CS_ResultData` |
| `CS_UIResultModel.CalcTotalScore` | `CS_ResultData.totalScore` |
| Model のソロ用 ReactiveProperty 7個 | `ReactiveProperty<CS_ResultData>` 1個 |
| Model のマルチ用 `List<PlayerResultData>` | `List<CS_ResultData>`（並び順＝順位） |
| `CS_UIResultModel.SetPlayerTitle` / `SetTitle` | `CS_ResultData.SetTitle` |
| View 2つに直書きされた点数 | `CS_ResultData.DefeatVillainPoint` などの定数 |
| `CS_ResultController.SetSoloResult(ResultData)` など | `CS_ResultData` を受け取る形に |

ゲーム中のスコア表示（`CS_UIScoreModel`）には、今まで通り **合計点（`totalScore`）だけ** を `SetScore` で渡す（Model の変更は不要）。

## 3. タイマー終了後、毎フレームシーン移動している【必須】

**対象**：`CS_TimerController.cs`

### 問題

`Update` で、残り時間が 0 以下の間 **毎フレーム** `_sceneTransitioner.StartTransition()`（`SceneManager.LoadScene`）を呼んでいる。

### 直し方

終了フラグを持ち、1回だけ呼ぶ。

```csharp
private bool _isFinished;

void Update()
{
    if (_isFinished) return;
    // ...
    if (_timerModel.currentTime.CurrentValue <= 0.0f)
    {
        _isFinished = true;
        CS_ResultDataStore.Save(全プレイヤーの CS_ResultData); // 4：プレイヤーが消える前に保存
        _sceneTransitioner.StartTransition();
    }
}
```

## 4. リザルトに本物のスコアを渡す口がない【必須】

**対象**：`CS_ResultController.cs`（＋新規 `CS_ResultDataStore.cs`）

### 問題

`Start` で必ず `ShowDebugResult()`（ランダムな仮データ）を表示しており、MainScene のスコアを受け取る方法がない。

### 直し方

- シーンをまたいで値を運ぶ static クラス `CS_ResultDataStore` を作る
  - ゲーム終了時（3 のシーン移動の直前）に、全プレイヤーの `CS_ResultData` を保存
  - 4つの数は全クライアントに同期済みなので、**各クライアントが自分の画面のために全員分を集めれば足りる**（RPC 不要）
  - Domain Reload オフ対策に `RuntimeInitializeOnLoadMethod` でクリア
- `CS_ResultController.Start` で
  - 保存データがあれば → それを Model に渡す（1人ならソロ、複数ならマルチ）→ 渡したらクリア
  - なければ → 今まで通り `ShowDebugResult()`（ResultScene 単体で再生したとき用）

```csharp
public static class CS_ResultDataStore
{
    private static readonly List<CS_ResultData> _results = new();

    public static bool hasData => _results.Count > 0;
    public static IReadOnlyList<CS_ResultData> results => _results;

    public static void Save(IEnumerable<CS_ResultData> results)
    {
        _results.Clear();
        _results.AddRange(results);
    }

    public static void Clear() => _results.Clear();

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
    private static void ResetStatics() => _results.Clear();
}
```

（全プレイヤーの `CS_ResultData` の集め方は、Player 側の作りに合わせて決める）

## 5. 同点の順位【要相談】

**対象**：`CS_UIResultModel.SetMultiResultData`

今は並び替えた順番で 1位・2位… と付けるので、**合計点が同じでも別の順位** になる。
同点を同じ順位（1位・1位・3位）にするか決める。

## 6. シーン移動のネットワーク同期【要相談・ネットワーク担当と】

**対象**：`CS_SceneTransitioner.cs`

`SceneManager.LoadScene` を使っているので、**各クライアントが通信を続けたまま、それぞれ自分だけで** ResultScene に移動している。

どちらにするか決める。

- ホストが `NetworkManager.SceneManager.LoadScene` で全員をまとめて移動させる
- 通信を終了（`Shutdown`）してから、各自で移動する

どちらにしても、**移動を始める前に `CS_ResultDataStore` に保存する**（4）ことは変わらない。
