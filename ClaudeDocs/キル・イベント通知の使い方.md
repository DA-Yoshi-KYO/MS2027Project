# キル・イベント通知の使い方（`CS_NotificationController`）

画面に2秒ほど文章を出して知らせる通知 UI です。イベント発生・残り時間・キルログ・カウントダウンの4種類を扱います。
仕様の元：Confluence「UI」⑧イベント告知、時間告知、キルログ

UI 側（Model / Presenter / View / Controller）は実装済みです（作成：元浪）。
残り時間とカウントダウンはタイマー（`CS_TimerController`）から呼ばれていて表示されます。
**キル通知は `CS_PlayerScoring` から呼ばれています**（Issue #252）。**イベント発生通知は `CS_RandomEventManager` から呼ばれています**。このmdでは「誰が何を呼ぶか」を担当ごとに書いています。

```
プレイヤー(サーバー) ──Rpc──▶ 各クライアント ──ShowKill──▶ Controller ──▶ Model(3スロット) ──▶ Presenter ──▶ View(文章)
ランダムイベント(全員) ──onEventStarted──▶ 各クライアント ──ShowEvent──┘
タイマー(各クライアント) ──ShowTimeAlert / ShowCountdown──┘   ※つなぎ込み済み
```

---

## 仕様（表示ルール）

| 種類 | 表示する文章 | 消え方 |
|---|---|---|
| イベント | 渡した文章そのまま（例：「大量発生」） | 2秒後に消える |
| 残り時間 | 渡した文章そのまま（例：「残り1分！」） | 2秒後に消える |
| キル | 「{倒されたプレイヤー名}が倒された」 | 2秒後に消える |
| カウントダウン | 渡した文章（呼ぶたびに同じ枠で書き換え） | `HideCountdown()` で消える |

- 表示枠は **3つ固定**。空きが無い時は待機列に入り、枠が空いたら順番に出る
- **キルはまとめて表示**：キル通知の表示中にもう一度 `ShowKill` すると、同じ枠に「Player2・Player3が倒された」のようにつなげ、2秒をリセットする（同じ名前は重複しない）
- 消える前の最後の1秒でフェードアウト（View の `_fadeOutDuration`、既定1秒）
- 表示時間（2秒）と枠数（3）は `CS_UINotificationModel` の定数

---

## 仕組み（UI 側・実装済み）

| クラス | ファイル | 役割 |
|---|---|---|
| `CS_NotificationController` | `GameController/CS_NotificationController.cs` | **外から触るのはこれだけ**。Model を内部で1つ持ち、Presenter に渡す。GameControllerManager.prefab に付いている |
| `CS_UINotificationModel` | `UI/MVP(Model)/Notification/CS_UINotificationModel.cs` | 3つの枠・待機列・キルのまとめ・カウントダウンを管理 |
| `CS_NotificationData` / `CSE_NotificationType` | `UI/CS_NotificationData.cs` | 通知1件分のデータと種類 |
| `CS_UINotificationPresenter` | `UI/MVP(Presenter)/Notification/CS_UINotificationPresenter.cs` | 毎フレーム Model の時間を進め、View へ反映 |
| `CS_UINotificationRootView` / `CS_UINotificationView` | `UI/MVP(View)/Notification/` | 3つの枠の表示・フェード。UICanvas.prefab に付いている |

※ 警戒 UI と同じく、**Model を `new` して `Bind` する形ではありません**。外からは Controller のメソッド経由でしか触れません。

### Controller の API

| メソッド | 説明 |
|---|---|
| `ShowEvent(string message)` | イベント発生の通知を出す。**ランダムイベント担当が呼ぶ** |
| `ShowKill(string playerName)` | キル通知を出す。名前は **倒されたプレイヤー** の名前。**プレイヤー担当が呼ぶ** |
| `ShowTimeAlert(string message)` | 残り時間の通知を出す（タイマーが呼んでいる） |
| `ShowCountdown(string message)` / `HideCountdown()` | カウントダウンの表示・更新 / 終了（タイマーが呼んでいる） |

- **Controller は各クライアントの画面に出すもの**。サーバーで判定したことは、RPC などで各クライアントに届けてから呼ぶ
- Controller は `FindAnyObjectByType<CS_NotificationController>()` で探す（`CS_TimerController.Start` と同じ）

## プレイヤー担当（秋野さん向け）：キル通知 ※実装済み

他プレイヤーを倒した判定は `CS_PlayerScoring.HandleDefeated` にあり、**サーバー（またはオフライン）でしか動きません**。そのため、倒したことを全員に RPC で配り、各クライアントで `ShowKill` を呼びます。

### 1. 倒された相手の番号を全員に配る

`HandleDefeated` の「他プレイヤーを倒した」分岐で、倒された相手のプレイヤー番号を送ります（`CS_PlayerScoring.NotifyKill` / `NotifyKillRpc` として実装済み。下はその要点）。

```csharp
// 自分自身への攻撃は数えない
if (target is CS_PlayerHealth player && player != _health)
{
    _holder.AddDefeatPlayer(_defeatPlayerScore);

    int victimNumber = player.GetComponentInParent<CS_Player>().playerNumber;
    if (IsSpawned) NotifyKillRpc(victimNumber);
    else ShowKill(victimNumber);   // オフラインのテストシーン
}
```

```csharp
[Rpc(SendTo.Everyone)]
private void NotifyKillRpc(int victimNumber) => ShowKill(victimNumber);

private static void ShowKill(int victimNumber)
{
    FindAnyObjectByType<CS_NotificationController>()?.ShowKill($"Player{victimNumber + 1}");
}
```

- `SendTo.Everyone` の書き方は `CS_PlayerPowerUpPopup` と同じ
- 表示名は今のところ `Player{番号+1}`（仮）。NPC も同じプレハブなので同じ形で出る
- **キルログは「誰が誰を倒したか」なのか「誰が倒されたか」だけなのか、仕様書にはっきり書かれていない**。今の UI は倒された名前だけを出すので、倒した側も出したくなったら UI 担当（元浪さん）に相談

## ランダムイベント担当（中出さん向け）：イベント発生通知 ※実装済み

イベントの開始は **サーバーでもクライアントでも処理される**（クライアントには RPC で届く）ので、開始のタイミングで `ShowEvent` を呼ぶだけで全員の画面に出ます。RPC の追加は不要です。

`CS_RandomEventManager.NotifyStarted` で、`onEventStarted` を呼んだ後に `ShowEvent(displayName)` を呼んでいます（下はその要点）。

```csharp
// イベントが始まったことを購読側に知らせ、画面にイベント名を出す(サーバー・クライアントとも)
private void NotifyStarted(CS_RandomEventContext context)
{
    onEventStarted?.Invoke(context);

    if (_notification == null) _notification = FindAnyObjectByType<CS_NotificationController>();
    if (_notification != null) _notification.ShowEvent(context.randomEvent.displayName);
}
```

- 文章はイベントアセット（`CSO_RandomEvent`）の `displayName` をそのまま使う。「大量発生が発生！」のように飾りたい場合はここで組み立てる
- 途中参加したクライアントには、参加前に始まったイベントは通知されない（`CS_RandomEventManager` の仕様）
