# 📋 概要
悪人グループの巡回パターンを、Fieldプレハブ(またはシーン)のSceneビューで作るエディタ拡張です。
スポーン位置ごとに「どの悪人が、どのポイントを、どう回るか」「ポイントで何をするか」「隊列」「犯罪実行役(その場で犯罪をする悪人)」を決められます。

- スクリプト: `Assets/Editor/Villain/Patrol/`(エディタ) / `CSO_VillainPatrolPattern`・`CS_VillainPatrolRoute`・`CS_VillainPatrolCrew`(ゲーム中)
- パターンのアセット: `Assets/Programmer/Database/Villain/Patrol/DB_VillainPatrol_○○.asset`

# ✅ 使い方(4手)
## 1. スポーン位置を選ぶ
Hierarchyでスポーン位置(`VillainSpawnPoint_○○`)を選ぶと、Sceneビューに **巡回** のツールバーが出ます。
(出ない時は、Sceneビュー右上の「︙」→ Overlays で「巡回」にチェック)

## 2. 悪人とポイントを置く
1. ツールバーの **悪人を置く** を押して、Sceneビューをクリックします。地面(NavMesh)の上に悪人が置かれ、そこがポイント1(スタート)になります
2. 置くと自動で **ポイントを置く** に切り替わります。クリックした順にポイント2、3…と増えます
3. 別の悪人を置く時は、もう一度 **悪人を置く** を押します

- ボタンが押されていない時は、Sceneビューは普段どおりのUnityの操作です(クリックしても何も置きません)。**Esc** でボタンを外せます
- ツールバーに、今どの悪人にポイントを足しているかが色付きで出ます。**悪人・ポイント・線をクリック** すると、その悪人に切り替わります
- ポイントは **ドラッグで動かせます**。**Ctrl+Z** で戻せます

## 3. ポイントでやることを決める
ポイントを選ぶと、Inspectorの **巡回(CS_VillainPatrolRoute)** に「やること」のリストが出ます。上から順に実行します(ドラッグで並べ替え、−で削除)。

| やること | 設定 | 初期値 |
| :--- | :--- | :--- |
| 停止 | 秒(0〜60) | 2秒 |
| 見回し | 左右の角度(0〜180°)・秒(0.5〜30)。秒数で左右を1往復 | 左右60°を3秒 |
| 向きを変える | 角度(−180〜180°、＋で右回り)。0.5秒かけて回る | 90° |

何も無ければ、止まらずに次のポイントへ向かいます。

悪人ごとに、Inspectorで次を決めます。

| 項目 | 意味 |
| :--- | :--- |
| 回り方 | **周回**: 最後の後にポイント1へ戻る / **往復**: ポイント1まで折り返す |
| 速さ(m/秒) | 巡回の速さ(0.5以上) |
| 最初の向き(°) | 湧いた時の向き。スポーン位置の向きからの角度 |
| 隊列 | 付いてくる人数・形(横一列/縦一列/斜め右/斜め左/V字)・間隔(m) |

## 4. 再生して確かめる
ツールバーの **▶ 再生** で、プレイせずにSceneビュー上で悪人が動きます(■ 停止で止める)。

- 線は、NavMeshで実際に通る道です。**通れない所は赤い線** になります(ポイントを動かして直してください)
- 隊列で付いてくる人は小さな丸で出ます

保存は **シーン(プレハブ)の保存(Ctrl+S)と一緒** です。

# 🔢 位置を数値で調整する
ポイント・実行役を選ぶと、Inspectorに位置の数値が出ます(ポイント1が悪人の位置。運ぶ実行役は車の位置も)。
Inspectorの上の **位置の基準** で、数値の基準を切り替えます(覚えておくので、次からも同じ基準)。

| 位置の基準 | 数値 |
| :--- | :--- |
| スポーン位置(m) | スポーン位置からの距離。**右(X)**・**前(Z)**(スポーン位置の向き基準) |
| 路地裏(0〜1) | 路地裏の中の割合。**縦**(長い方向)・**横**(短い方向)。端が0と1、真ん中が0.5 |

- 路地裏は、スポーン位置の **Patrol Area**(空なら、スポーン位置の真下にある路地裏)です。見つからない時はスポーン位置の基準で表示します
- 「路地裏」にすると、Sceneビューに路地裏の枠(水色)と **縦0・横0 / 縦1 / 横1** の目印が出ます。数値の向きはこれで確かめてください
- 路地裏の外は、0未満・1より大きい値になります
- 高さは書きません(ゲーム中にNavMeshの上に合わせます)

# 🗺 真上から見る(2D)
ツールバーの **真上から見る** で、Sceneビューが真上からの2D表示になります(回転は固定)。もう一度押すと元の視点に戻ります。

- 路地裏・ルート・実行役が全部入る大きさに合わせます。動かした後は **合わせ直す** で合わせ直せます
- 画面の上は、位置の基準が「路地裏」なら路地裏の縦の方向、「スポーン位置」ならスポーン位置の前です
- 置く・動かす操作はそのまま使えます
- 入れたまま別のスポーン位置を選ぶと、そこに合わせ直します。スポーン位置以外を選ぶと元の視点に戻ります

# 🦹 犯罪実行役
巡回せず、決めた位置で犯罪モーションをし続ける悪人です。

1. ツールバーの **実行役を置く** を押して、Sceneビューをクリックします(黄色のひし形)。続けてクリックすると何人でも置けます
2. ひし形をクリックすると選べます。ドラッグで動かせます
3. Inspectorで **犯罪モーション** と **向き(°)** を決めます

| 犯罪モーション | 動き |
| :--- | :--- |
| エリアに合わせる(初期値) | スポーン位置のエリアのモーション(生活区域: 蹴る / インフラ区域: 運ぶ / エネルギー区域: いじる) |
| 蹴る | その場で蹴り続ける |
| 運ぶ | ひし形(貨物)と四角(車)の間を **拾う → 運ぶ → 置く → 戻る** と往復する。車の位置もドラッグで動かせる |
| いじる | その場で機械などをいじり続ける |

- エリアごとのモーションは `CS_CrimeArea` の **Crime Motion** で変えられます(Field_Solo1 > Villain > CrimeAreaLayout)
- ▶ 再生で、運ぶ実行役の往復も確かめられます(歩く速さ・拾う/置く時間は目安。ゲーム中は悪人のステータスと `CS_VillainPatrol` の値で決まります)
- モーションは仮です(Mannequinのモーション)。Animator Controllerへの追加は **Tools/Villain/犯罪モーションを追加** で行います

# 🔁 パターンの使い回し
- パターンはアセットなので、別のスポーン位置のInspectorで同じパターンを指定すれば使い回せます
- ポイントの位置はスポーン位置からの相対で持ち、スポーン位置の向きで回ります(同じ形のまま、スポーン位置を基準に回る)
- 同じパターンを複数の場所で使っている時は、ツールバーに「○か所で使っています」と出ます。**編集すると全部に反映** されます
- その場所だけ変えたい時は、ツールバーの **複製** で別のアセットにしてから編集します

# 🎮 ゲーム中の動き
- 湧く人数は **パターンの人数(実行役 + 悪人 + 付いてくる人)まで** です。それより多くは湧きません
- 湧いた人は、**犯罪実行役を全員先に**、次に悪人(先頭)、最後に付いてくる人を悪人1の隊列 → 悪人2の隊列…の順に割り当てます(人数が少ない時は、割り当てられた所まで)
- 犯罪実行役はプレイヤーを見つけると犯罪をやめて戦い、帰還した後は実行役の位置へ戻って犯罪を再開します(運んでいる途中なら車へ向かう)
- 先頭はポイント1から、付いてくる人はポイント1の隊列の位置から巡回を始めます
- 付いてくる人は、先頭が通った道をなぞって歩きます(縦一列ならルートの線の上。横にずれる形は、その場所の進む向きに対して横にずれる)。向きは先頭に合わせず、それぞれ自分の進む向きを向きます(先頭が止まると一緒に止まりますが、見回しは真似しません)
- 先頭が倒されたら、隊列の次の人が先頭になり、続きから回ります
- 臨戦態勢 → 帰還の後は、ルートの続きから巡回を再開します
- 巡回パターンを置いていないスポーン位置は、今までどおり路地裏の両端を全員で往復します
