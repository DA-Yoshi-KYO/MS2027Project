# 警戒状態 連携ガイド（警察・防犯装置・UI担当向け）

このドキュメントは、プレイヤーの**警戒状態**(`CS_PlayerAlert`)を使う担当者（とそのClaude）に向けた引き継ぎ資料です。
プレイヤー側は「警戒状態を持つ・同期する・知らせる」までを実装済みです。警察の動き・防犯装置・UIは、ここで説明する入口を使って各担当者が実装してください。

仕様の出典:
- [Confluence「警察」ページ → 警戒状態(旧手配度)](https://summervacationgamejam.atlassian.net/wiki/spaces/20272/pages/21004307)
- [Confluence「UI」ページ → ②警戒状態](https://summervacationgamejam.atlassian.net/wiki/spaces/20272/pages/21004323)

## 何が変わったか

| | 以前 | これから |
|---|---|---|
| 方式 | 手配度(0〜5の数値。グラセフ式) | 警戒状態(3つの状態。メタルギア式) |
| クラス | `CS_PlayerWantedLevel` | `CS_PlayerAlert` |
| 共有 | プレイヤーごと | プレイヤーごと(変わらず) |

- `CS_PlayerWantedLevel` は、警察側が警戒状態へ移った(Issue #271)ため削除しました(Issue #277)。

## 状態

`CSE_PlayerAlertState`([`CSE_PlayerAlertState.cs`](../Assets/Programmer/Script/Entity/Player/CSE_PlayerAlertState.cs))

| 状態 | 意味 | UI |
|---|---|---|
| `None`(なし) | 警察陣営に見つかっていない | 表示しない |
| `Detected`(発見中) | 警察陣営に今まさに見られている | 1段階目の表示 |
| `Searching`(捜索中) | 見失われてから解除されるまでの間 | 2段階目の表示 |

## 状態の変わり方

```
            NotifyDetected()
  なし ─────────────────────▶ 発見中 ◀───────────┐
   ▲                            │                 │ NotifyDetected()
   │                            │ 0.5秒呼ばれない  │
   │  最後に見つかってから20秒    ▼                 │
   └──────────────────────── 捜索中 ──────────────┘

  どの状態からでも: 警察に倒される → なし
```

- **発見中になる:** 警察陣営が `NotifyDetected()` を呼んだ時
- **捜索中になる:** `NotifyDetected()` が `Lost Delay` 秒(既定0.5秒)呼ばれなくなった時
- **なしに戻る:** 最後に見つかってから `Clear Time` 秒(既定20秒)、新たに見つからなかった時
- **すぐなしに戻る:** 警察に倒された時(倒した相手に `CS_PoliceAttack` が付いていれば警察とみなす)
  - 今の `CS_PoliceAttackHitbox` は、`CS_PoliceAttack` が付いた警察本体を攻撃者として `TakeDamage(damage, attacker)` に渡しているので、そのまま判定できます。攻撃者を渡さない攻撃を作る場合は、この解除が働かないので注意してください
- `Lost Delay` と `Clear Time` は `Player.prefab` の `CS_PlayerAlert` の Inspector で調整できます

## 公開しているもの

ファイル: [`CS_PlayerAlert.cs`](../Assets/Programmer/Script/Entity/Player/CS_PlayerAlert.cs)(`Player.prefab` に付いています)

| メンバー | 内容 | どこで使えるか |
|---|---|---|
| `void NotifyDetected()` | 警察陣営が見つけたことを知らせる | **サーバー(またはオフライン)のみ**。クライアントで呼んでも何もしない |
| `CSE_PlayerAlertState alertState` | 今の状態 | 全員 |
| `bool isAlerted` | 発見中か捜索中か(`None` 以外か) | 全員 |
| `bool isDetected` | 発見中か | 全員 |
| `float clearTime` | 解除までの秒数(Inspectorの値) | 全員 |
| `event Action<CSE_PlayerAlertState> onAlertChanged` | 状態が変わった時(引数は新しい状態) | 全員(全クライアントで発生) |

- 状態は `NetworkVariable` で同期しています(書き込みはサーバーのみ)
- オフライン(NetworkManagerが動いていない)のテストシーンでも単体で動きます

## 警察担当・防犯装置担当の方へ

### 見つけたことを知らせる

見えている間は、**`Lost Delay`(0.5秒)より短い間隔で呼び続けてください**。毎フレームでも構いません(同じ状態のままなら通信は発生しません)。
呼ばれなくなると、自動で捜索中 → なしへ進みます。見失ったことを知らせる必要はありません。

```csharp
// サーバー(またはオフライン)で、プレイヤーが見えている間に呼ぶ
if (target.TryGetComponent(out CS_PlayerAlert alert))
{
    alert.NotifyDetected();
}
```

- 死亡中のプレイヤーに呼んでも無視されます
- 「警察陣営」には警察だけでなく防犯装置も含まれます。防犯装置も同じように呼んでください

### 警戒状態を見て動く

```csharp
switch (alert.alertState)
{
    case CSE_PlayerAlertState.Detected:  /* 追跡 */ break;
    case CSE_PlayerAlertState.Searching: /* 最後に見つかった付近を捜索 */ break;
    case CSE_PlayerAlertState.None:      /* 巡回に戻る */ break;
}
```

- 最後に見つかった位置は、プレイヤー側では持っていません。警察側で `NotifyDetected()` を呼んだ時の位置を覚えておいてください
- プレイヤーの一覧が必要な場合は、`CS_Player.activePlayers`(出現中のプレイヤーの一覧)を使ってください(各プレイヤーから `GetComponent<CS_PlayerAlert>()` で取れます)

## UI担当の方へ

```csharp
private void OnEnable()
{
    _alert.onAlertChanged += HandleAlertChanged;
    HandleAlertChanged(_alert.alertState);  // 途中参加などに備えて、今の状態に合わせる
}

private void OnDisable()
{
    _alert.onAlertChanged -= HandleAlertChanged;
}

private void HandleAlertChanged(CSE_PlayerAlertState state)
{
    // None: 非表示 / Detected: 発見中の表示 / Searching: 捜索中の表示
}
```

- 自分の画面に出すのは、自分のプレイヤー(`CS_Player.isLocalPlayer`)の警戒状態だけです
- 手配度UIの時と同じように、プレイヤー側でUIのModelにつなぐこともできます。必要ならプレイヤー担当(秋野)に連絡してください
