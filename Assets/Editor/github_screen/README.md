# Gitツールバー表示（Unity 6.3以降）

## 作業禁止ブランチの警告

`ProtectedBranches.json` の `protectedBranches` に、警告対象のブランチ名を完全一致で指定します（初期値: `develop`、`main`）。
Unity起動後、またはブランチ切り替え後の最初のEditor内クリックで「作業禁止のブランチですがよろしいでしょうか？」を1回表示します。
再コンパイルでは繰り返しません。別ブランチを経由して戻った場合は再び表示します。
警告を出したクリックは実行せず、続行する場合はもう一度クリックしてください。
これは注意喚起であり、以後の編集操作をロックする機能ではありません。JSONの変更は自動反映されます。

## 表示

Unity上部のツールバー左側に現在のブランチ、右側にdevelopの最新状況を省略せず表示します。
再生・一時停止・ステップのボタンはウィンドウ中央に配置します。
表示されない場合はツールバーの空白を右クリックし、`Git` 内の表示項目を有効にしてください。

- `develop: 最新（取り込み済み）`（緑）: 現在の作業ブランチに、直近の通信で確認したorigin/developの履歴がすべて含まれる状態。作業ブランチ独自のコミットがあっても最新と判定します。
- `develop: 未取り込み N件（最新ではありません）`（黄）: 現在の作業ブランチに取り込まれていないdevelopのコミットがあります。
- `ネットワークがありません。`（黄）: ネットワーク切断、名前解決・接続失敗、通信タイムアウトで最新か確認できない状態。
- 認証やリモート設定の問題、developが存在しない場合は、それぞれ別の警告を表示します。

比較対象はローカルのdevelopではなく、現在の作業ブランチとリモートのdevelopです。
未取り込みの表示は、競合なくマージできることを保証するものではありません。
浅いクローンで取り込み済みか判断できない場合は、履歴不足と表示します。
ブランチを約5秒、リモートを約60秒ごとにバックグラウンドで確認します。
確認時刻はマウスを重ねると表示されます。通信のタイムアウトは約15秒です。
比較に必要なコミットがローカルにない場合のみ、履歴オブジェクトをfetchします。
作業ファイル、ブランチ、リモート追跡参照、FETCH_HEADは変更せず、pull・merge・checkoutも行いません。

GitはPATH、Windowsの標準／ユーザー別インストール先、macOS／Linuxの一般的な配置先から検出します。
特殊な配置は `Tools > Git表示 > Gitの実行ファイルを指定…` で設定できます。
この設定は各PCのEditorPrefsに保存し、チームには共有しません。
`Gitの自動検出に戻す` で解除できます。
`今すぐ再確認` と設定項目は表示部分の右クリックにもあります。

表示の幅制限解除と中央配置はUnity 6.3のツールバー構造に合わせて調整しています。
非常に狭いウィンドウでは、すべての標準ツールと長いブランチ名を同時に配置できない場合があります。

認証は各PCの既存のGit設定を使用します。自動確認でログイン画面は開きません。
SSH接続の場合は既存の鍵と登録済みホストが必要です。
